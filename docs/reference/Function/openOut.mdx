# openOut

**openOut  -- open an output file**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

A filename starting with `~/`  will have the tilde replaced by the user's home directory.

## Examples

```macaulay2
openOut fn
```

```macaulay2
g = openOut "test-file"

```

```text
test-file

File
```

## Additional Information

- Inputs:
- `fn` a [ string](../Type/op_Coredollar_String.mdx)
- Outputs:
- a [ file](../Type/op_Coredollar_File.mdx) an open output file whose filename is `fn`. Filenames starting with `!` or with `$` are treated specially see [openInOut](../Function/op_Coredollar_openInOut.mdx).
