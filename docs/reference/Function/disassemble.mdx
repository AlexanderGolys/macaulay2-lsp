# disassemble

**disassemble  -- disassemble a pseudocode or function**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

It may be useful to disassemble code during debugging as in the following demonstration.

## Examples

```macaulay2
disassemble c
```

```macaulay2
disassemble (() -> 1/(1-1))

```

```text
(function restargs: false numparms: 0 framesize: 0 frameID: 12878 (2-OP
     / 1 (2-OP - 1 1)))
```

```macaulay2
disassemble functionBody (() -> 1/(1-1))

```

```text
(2-OP / 1 (2-OP - 1 1))
```

## Additional Information

- Inputs:
- `c` a [ function](../Type/Function.mdx) or an instance of the type [Pseudocode](../Type/op_Coredollar_Pseudocode.mdx)
- Outputs:
- a [ string](../Type/op_Coredollar_String.mdx) the disassembled form of `c`
