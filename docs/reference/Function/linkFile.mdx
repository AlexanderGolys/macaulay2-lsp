# linkFile

**linkFile  -- make a new link to a file**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

linkFile  -- make a new link to a file

## Examples

```macaulay2
linkFile(on)
```

## Additional Information

- Inputs:
- `o` a [ string](../Type/op_Coredollar_String.mdx) the path to an existing file
- `n` a [ string](../Type/op_Coredollar_String.mdx) a new path to the file
- Consequences:
- a new link `n` is made to the existing file reachable using the path `o`
