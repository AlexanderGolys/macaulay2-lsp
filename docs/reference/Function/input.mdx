# input

**input  -- read Macaulay2 commands and echo**

**Type:** [FunctionClosure](../Type/FunctionClosure.mdx)

## Description

The file is sought in the directory containing the file currently being loaded if any and then along the [path](../Instance/path.mdx)  unless the name of the file begins with `/`  `~/`  `$`  or `!` . If the file begins with `./`  or `../`  then it looks instead in the directory of the file currently being loaded (see [currentFileDirectory](../Instance/currentFileDirectory.mdx) ).  If no file is being loaded it will look in the current directory (see [currentDirectory](../Function/currentDirectory.mdx) ).If one of the top level expressions in the file evaluates to the symbol [end](../Method/op_Coredollar_end.mdx)  the reading of the file is stopped at that point.If an error occurs while evaluating the expressions in the file reading is stopped.

## Examples

```macaulay2
input fn
```

## Additional Information

- Inputs:
- `fn` a [ string](../Type/op_Coredollar_String.mdx)
- Consequences:
- reads and executes the commands found in the file whose name is contained in the string `fn` echoing the input printing the values and incrementing the line number
