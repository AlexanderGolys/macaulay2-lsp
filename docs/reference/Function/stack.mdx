# stack

**stack  -- join nets or string vertically**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

`stack(mn...)`  -- joins nets or strings by concatenating them vertically.  The baseline of the result is the baseline of the first argument. Nested sequences among the arguments are first spliced together. If there are no arguments then the net returned has zero height and zero depth.  This might be unexpected. Tab characters in any of the strings are first expanded into spaces assuming tab stops at every eighth column. Null arguments are allowed and ignored.
