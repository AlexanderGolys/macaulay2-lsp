# getGlobalSymbol

**getGlobalSymbol  -- create a global symbol in a global dictionary**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

If `dict`  is omitted then the first symbol found in the dictionaries listed in [dictionaryPath](../Instance/dictionaryPath.mdx)  will be returned. If none is found one will be created in the first dictionary listed in [dictionaryPath](../Instance/dictionaryPath.mdx)  unless it is not mutable in which case an error will be signalled; perhaps that behavior should be changed.

## Examples

```macaulay2
getGlobalSymbol(dictnam)
getGlobalSymbol nam
```

```macaulay2
sym = getGlobalSymbol(d"foo")

```

```text
foo

Symbol
```

## Additional Information

- Inputs:
- `dict` an instance of the type [GlobalDictionary](../Type/op_Coredollar_GlobalDictionary.mdx)
- `nam` a [ string](../Type/op_Coredollar_String.mdx)
- Outputs:
- a global symbol in the dictionary `dict` whose name is the string `nam` which will be created if necessary
- Consequences:
- if a new symbol is created it is stored under the name `nam` in the dictionary `dict`
