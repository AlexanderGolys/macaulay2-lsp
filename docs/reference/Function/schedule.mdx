# schedule

**schedule  -- schedule a task for execution**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

The computation proceeds in the background in a thread.  The status of the task can be observed by printing `t` .  When the computation is finished as can be detected with [isReady(Task)](../Instance/isReady(Task).mdx) the final value can be retrieved with [taskResult(Task)](../Instance/taskResult(Task).mdx).If [notify](../Instance/notify.mdx) is set to [true](../Instance/op_Coredollar_true.mdx) then useful messages are printed when the task changes state.

## Examples

```macaulay2
schedule(fx)
schedule f
schedule t
```

```macaulay2
schedule t

```

```text
Task
```

```macaulay2
u = schedule(f4)
```

```text
<<task created>>

Task
```

## Additional Information

- Inputs:
- `f` a [ function](../Type/Function.mdx)
- `x` a [ thing](../Type/Thing.mdx)
- `t` a [ task](../Type/op_Coredollar_Task.mdx)
- Outputs:
- a new task computing the value of the `f(x)` or if `x` is not provided then of `f()`. Alternatively the task `t` created previously with [createTask](../Function/op_Coredollar_createTask.mdx) is scheduled for execution.
