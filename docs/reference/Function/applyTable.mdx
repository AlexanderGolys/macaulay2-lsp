## Additional Information

- Inputs:
- `T` a [ list](../Type/op_Coredollar_List.mdx) a table (list of lists of the same length)
- `f` a [ function](../Type/Function.mdx)
- Outputs:
- `A` a [ list](../Type/op_Coredollar_List.mdx) a table of the same shape as $T$ where the function $f$ has been applied elementwise
