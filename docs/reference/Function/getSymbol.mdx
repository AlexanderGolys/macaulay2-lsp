# getSymbol

**getSymbol  -- make a global user symbol from a string**

**Type:** [FunctionClosure](../Type/FunctionClosure.mdx)

## Description

getSymbol  -- make a global user symbol from a string

## Examples

```macaulay2
getSymbol s
```

```macaulay2
s = getSymbol x

```

```text
aaaa

Symbol
```

```macaulay2
s === getSymbol x

```

```text
true
```

## Additional Information

- Inputs:
- `s` a [ string](../Type/op_Coredollar_String.mdx)
- Outputs:
- a [ symbol](../Type/op_Coredollar_Symbol.mdx) a global symbol whose name is provided by the string `s` in the private dictionary for the package [User](../Instance/op_Coredollar_currentPackage.mdx).


### Caveat

 The old behavior up to version 1.3.1 was to provide a previously existing global symbol if one exists and is visible in one of the dictionaries in [dictionaryPath](../Instance/dictionaryPath.mdx)  or if not to create a new global symbol in the first mutable dictionary listed in [dictionaryPath](../Instance/dictionaryPath.mdx) .
