# frames

**frames  -- get the frames associated to a closure**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

 This function is occasionally useful as a debugging tool.

## Examples

```macaulay2
frames f
```

```macaulay2
frames g

```

```text
{MutableList{...3...}, MutableList{}}

List
```

## Additional Information

- Inputs:
- `f` () or a [ symbol](../Type/op_Coredollar_Symbol.mdx) a [ function](../Type/Function.mdx) or an instance of the type [PseudocodeClosure](../Type/PseudocodeClosure.mdx)
- Outputs:
- a list of mutable lists the frames attached to the closure `f` or if `f` is `()` then the frames attached to the current lexical scope
