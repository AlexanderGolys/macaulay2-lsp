# uniform

**uniform  -- whether all elements of a list are the same class**

**Type:** [FunctionClosure](../Type/FunctionClosure.mdx)

## Description

The second list is not uniform because 0/2 is represented as a rational number (of class [QQ](../Type/op_x226_x132_x154.mdx)) while 2*0.5 and 5*0.5 are represented as real numbers (of class [RR](../Type/op_x226_x132_x157.mdx)).

## Examples

```macaulay2
uniform L
```

```macaulay2
uniform {2, 5, 0}

```

```text
true
```

```macaulay2
uniform {2*0.5, 5*0.5, 0/2}

```

```text
false
```

```macaulay2
uniform {hi, "hello"}

```

```text
false
```

```macaulay2
uniform {"hi", "hello"}

```

```text
true
```

```macaulay2
uniform {x^2*y*z, 5*y, 12/7}

```

```text
false
```

```macaulay2
uniform {x^2*y*z, 5*y, (12/7)_R}

```

```text
true
```

```macaulay2

```

```text

```

```text

```

```macaulay2

```

```text
true
```
