# commandInterpreter

**commandInterpreter  -- the top level command interpreter**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

 One more `i`  will be added to prompt each time the command interpreter is entered.  To leave it type `end`  or the end of file character. This facility is useful as a debugging tool and is used by the standard debugger.

## Examples

```macaulay2
commandInterpreter f
```

```macaulay2
commandInterpreter f
```

## Additional Information

- Inputs:
- `f` `()` or a [ dictionary](../Type/op_Coredollar_Dictionary.mdx) a [ symbol](../Type/op_Coredollar_Symbol.mdx) an instance of the type [Pseudocode](../Type/op_Coredollar_Pseudocode.mdx) or a [ function](../Type/Function.mdx)
- Consequences:
- the top level command interpreter will be called with the symbols in the lexical scope of `f` visible to the user.
