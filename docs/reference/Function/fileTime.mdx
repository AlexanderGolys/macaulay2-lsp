# fileTime

**fileTime  -- get or set file modified time**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

 The value is the number of seconds since 00:00:00 1970-01-01 UTC the beginning of the epoch so the number of seconds ago a file or directory was modified may be found by using the following code.

## Examples

```macaulay2
fileTime s  or  fileTime(ts)
```

```macaulay2
currentTime() - fileTime "."

```

```text
30
```

## Additional Information

- Inputs:
- `t` an [ integer](../Type/ZZ.mdx) if present the file-modified-time will be set to this value
- `s` a [ string](../Type/op_Coredollar_String.mdx) the name of a file
- Outputs:
- an [ integer](../Type/ZZ.mdx) the last modified date of the file with name `s`
- Consequences:
- `fileTime(ts)` sets the last modified time for the file `s` to `t` and returns `null` if no error occurs
