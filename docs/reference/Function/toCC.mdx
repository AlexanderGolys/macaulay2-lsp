# toCC

**toCC  -- convert to high-precision complex number**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description


### Synopsis


- Inputs:
- `prec` an [ integer](../Type/ZZ.mdx) the number of bits of precision desired
- `x` an [ integer](../Type/ZZ.mdx) a [ rational number](../Type/op_x226_x132_x154.mdx) or a [ real number](../Type/op_x226_x132_x157.mdx)
- `y` an [ integer](../Type/ZZ.mdx) a [ rational number](../Type/op_x226_x132_x154.mdx) or a [ real number](../Type/op_x226_x132_x157.mdx)
- Outputs:
- a [ complex number](../Type/op_x226_x132_x130.mdx) the complex number with real part `x` and complex part `y`. If `y` is omitted the imaginary part is zero.


### Synopsis


- Inputs:
- `x` a [ real number](../Type/op_x226_x132_x157.mdx)
- `y` a [ real number](../Type/op_x226_x132_x157.mdx)
- Outputs:
- a [ complex number](../Type/op_x226_x132_x130.mdx) the complex number with real part `x` and complex part `y`. If `y` is omitted the imaginary part is zero. The precision of the result is the minimum precision of the arguments.
