# applyPairs

**applyPairs  -- apply a function to each pair in a hash table**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

If `H` is not a hash table then `apply(pairs H f)` is called.

## Examples

```macaulay2
applyPairs(H f)
```

```macaulay2
applyPairs(H (kv) -> (k+1
```

```macaulay2
applyPairs(H (kv) -> (v
```

```macaulay2
applyPairs({4, 5, 6} (i x) -> i * x)

```

```text
{0, 5, 12}

List
```

## Additional Information

- Inputs:
- `H` a [ hash table](../Type/op_Coredollar_HashTable.mdx) a [ basic list](../Type/op_Coredollar_BasicList.mdx) or a [ dictionary](../Type/op_Coredollar_Dictionary.mdx) or any instance of a class with an [iterator](../Method/iterator.mdx) method installed
- `f` a [ function](../Type/Function.mdx) of two arguments returning a pair or [null](../Instance/null.mdx)
- Outputs:
- a [ hash table](../Type/op_Coredollar_HashTable.mdx) obtained by applying `f` to each key/value pair in `H`


### Caveat

It is an error for the function `f`  to return two pairs with the same key.
