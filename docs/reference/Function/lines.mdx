# lines

**lines  -- split a string into lines**

**Type:** [FunctionClosure](../Type/FunctionClosure.mdx)

## Description

The form `lines s` is designed to break lines correctly when the file follows the Unix or MS-DOS convention. In other words it will break a line at `\r\n` or `\n`.

## Examples

```macaulay2
lines s
lines(nl s)
```

```macaulay2
lines "a\nb\nc\n"

```

```text
{a, b, c}

List
```

```macaulay2
lines "a\nb\nc\nd"

```

```text
{a, b, c, d}

List
```

```macaulay2
lines( "\\." "a.b.c." )

```

```text
{a, b, c}

List
```

```macaulay2
lines( "\\." "a.b.c.d" )

```

```text
{a, b, c, d}

List
```

## Additional Information

- Inputs:
- `s` a [ string](../Type/op_Coredollar_String.mdx)
- `nl` a [ string](../Type/op_Coredollar_String.mdx)
- Outputs:
- a [ list](../Type/op_Coredollar_List.mdx) an array of strings obtained from the string `s` by breaking it at the characters specified by the string `nl`


### Caveat

For backwards compatibility if the pattern is a single character and it is an unescaped special character such as `+``*` or `.` then it is treated as a literal character. In future code the pattern must be escaped.
