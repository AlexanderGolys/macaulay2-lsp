# get

**get  -- get the contents of a file**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

get  -- get the contents of a file

## Examples

```macaulay2
get f
```

```macaulay2
get "test-file"

```

```text
hi there
```

```macaulay2
get "!date"

```

```text
Wed Jan  7 03:50:53 PM CET 2026
```

## Additional Information

- Inputs:
- `f` a [ file](../Type/op_Coredollar_File.mdx) or a [ string](../Type/op_Coredollar_String.mdx). If `f` is a string then it is opened as with [openIn](../Function/op_Coredollar_openIn.mdx). Filenames starting with `!` or with `$` are treated specially see [openInOut](../Function/op_Coredollar_openInOut.mdx).
- Outputs:
- a string containing the contents of the file. If the file was already open and partially read the remainder of the contents of the file are returned.
- Consequences:
- In the case where `f` is a file its input side is closed.
