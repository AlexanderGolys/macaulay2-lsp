# subtable

**subtable  -- extract a subtable from a table**

**Type:** [FunctionClosure](../Type/FunctionClosure.mdx)

## Description

subtable  -- extract a subtable from a table

## Examples

```macaulay2
subtable(a b T)
```

```macaulay2
s1 = subtable({0,2} {1,3} t);
```

```macaulay2
s2 = subtable(toList(0..3) {1} t);
```

## Additional Information

- Inputs:
- `a` a [ list](../Type/op_Coredollar_List.mdx) of rows to extract
- `b` a [ list](../Type/op_Coredollar_List.mdx) of columns to extract
- Outputs:
- `S` the subtable of $T$ defined by restricting to rows in the list $a$ and columns in the list $b$
