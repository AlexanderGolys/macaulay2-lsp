# pairs

**pairs  -- list the pairs in a hash table dictionary or basic list**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description


### Synopsis


- Inputs:
- `x` a [ hash table](../Type/op_Coredollar_HashTable.mdx) a [ dictionary](../Type/op_Coredollar_Dictionary.mdx) or a [ basic list](../Type/op_Coredollar_BasicList.mdx)
- Outputs:
- `L` a [ list](../Type/op_Coredollar_List.mdx) of all pairs `(k x#k)`;


### Synopsis


- Inputs:
- `x` a [ thing](../Type/Thing.mdx) an instance of a class with an [iterator](../Method/iterator.mdx) method installed;
- Outputs:
- an [ iterator](../Type/Iterator.mdx)

If `x`  is a hash table or dictionary the pairs consist of each key along with its associated value.A dictionary is a special hash table whose keys are strings and whose values are the corresponding symbols.If `x`  is a basic list the pairs consist of each index along with the element at that index in the list.If `x` belongs to any other class then [iterator](../Method/iterator.mdx) is called on it and if successful an [Iterator](../Type/Iterator.mdx) object is returned.
