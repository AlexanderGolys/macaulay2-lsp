# merge

**merge  -- merge two hash tables**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

Key-value pairs whose keys appear in only one of the input tables appear unchanged in the output table. If the key `k`  appears in both `x`  and `y`  then `f(x#k y#k)`  is the value associated to `k`  in the output hash table.For example we could take the max of the two values their average or make a list containing both.If the function `f(x#k y#k)`  returns [continue](../Method/continue.mdx) then the key `k`  is omitted from the merged table.Here is a simple implementation of the free abelian group on four letters where each element is represented as a hash table that associates coefficients to strings.If `x`  and `y`  have the same [class](../Function/op_Coredollar_class.mdx) and have the same [parent](../Function/op_Coredollar_parent.mdx) as in the previous example then so will `z` .The function [combine](../Function/combine.mdx) allows much greater control when combining two hash tables: you can give functions for how to handle every key and value of the input tables not just the duplicates. The function [mergePairs](../Function/op_Coredollar_mergePairs.mdx) is similar to `merge`  but works on lists of pairs rather than hash tables.

## Additional Information

- Inputs:
- `x` a [ hash table](../Type/op_Coredollar_HashTable.mdx)
- `y` a [ hash table](../Type/op_Coredollar_HashTable.mdx)
- `f` a [ function](../Type/Function.mdx) of two variables specifying how to handle duplicate keys
- Outputs:
- `z` a [ hash table](../Type/op_Coredollar_HashTable.mdx) a new hash table whose keys are the union of the keys of `x` and the keys of `y`
