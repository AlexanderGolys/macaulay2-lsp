# isGlobalSymbol

**isGlobalSymbol  -- whether a global symbol with a given name exists**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

 The search for the symbol runs through the dictionaries in the list [dictionaryPath](../Instance/dictionaryPath.mdx) .

## Examples

```macaulay2
isGlobalSymbol s
```

```macaulay2
isGlobalSymbol "res"

```

```text
true
```

```macaulay2
isGlobalSymbol "resres"

```

```text
false
```

## Additional Information

- Inputs:
- `s` a [ string](../Type/op_Coredollar_String.mdx)
- Outputs:
- a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) whether a global symbol with the name contained in the string
- `s`
- has been defined
