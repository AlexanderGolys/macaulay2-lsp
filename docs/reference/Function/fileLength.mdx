# fileLength

**fileLength  -- the length of a file**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

The length of an open output file is determined from the internal count of the number of bytes written so far.

## Examples

```macaulay2
fileLength f
```

```macaulay2
fileLength f

```

```text
8
```

```macaulay2
fileLength filename

```

```text
8
```

## Additional Information

- Inputs:
- `f` a [ string](../Type/op_Coredollar_String.mdx) or a [ file](../Type/op_Coredollar_File.mdx)
- Outputs:
- an [ integer](../Type/ZZ.mdx) the length of the file `f` or the file whose name is `f`
