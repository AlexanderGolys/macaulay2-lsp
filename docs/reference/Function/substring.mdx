# substring

**substring  -- extract part of a string**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

The expressions `substring(i n s)`  `substring(s i n)`  and `substring((i n) s)`  all return the substring that starts at index `i`  and has `n`  characters.In other words if $s=s_0s_1s_2\ldots s_k$ then the substring returned is $s_i s_{i+1}\ldots s_{i+n-1}$.Indices begin at zero and a negative index is counted from the end of the string. Requests for out-of-bound character positions are silently ignored.The expressions `substring(i s)`  and `substring(s i)`  return the substring that starts at index `i`  and continues to the end of the string.In other words if $s=s_0s_1s_2\ldots s_k$ then the substring returned is $s_i s_{i+1}\ldots s_k$.
