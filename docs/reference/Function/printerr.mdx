# printerr

**printerr  -- print something to stderr**

**Type:** [FunctionClosure](../Type/FunctionClosure.mdx)

## Description

Print `x` each line prepended with `--` to [stderr](../Instance/stderr.mdx).  This is useful for displaying warning messages and verbose logs.If `x` is a [ basic list](../Type/op_Coredollar_BasicList.mdx) then its elements are first joined with [horizontalJoin](../Function/horizontalJoin.mdx).

## Examples

```macaulay2
printerr x
```

```macaulay2
printerr "Hello world!"
 -- Hello world!
```

```macaulay2
printerr("foo" || "bar")
 -- foo
 -- bar
```

```macaulay2
printerr("foo" "bar")
 -- foobar
```

## Additional Information

- Inputs:
- `x` a [ string](../Type/op_Coredollar_String.mdx) a [ net](../Type/op_Coredollar_Net.mdx) or a [ basic list](../Type/op_Coredollar_BasicList.mdx)
