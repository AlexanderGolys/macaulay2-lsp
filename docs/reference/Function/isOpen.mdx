# isOpen

**isOpen  -- whether a file or database is open**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

An open file is either an input file an output file an input output file or a listener.

## Examples

```macaulay2
isOpen f
```

```macaulay2
isOpen f

```

```text
true
```

```macaulay2
isOpen f

```

```text
false
```

## Additional Information

- Inputs:
- `f` a [ file](../Type/op_Coredollar_File.mdx) or a [ database](../Type/Database.mdx)
- Outputs:
- a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) whether `f` is an open file or open database
