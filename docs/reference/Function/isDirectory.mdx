# isDirectory

**isDirectory  -- whether a file is a directory**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

isDirectory  -- whether a file is a directory

## Examples

```macaulay2
isDirectory fn
```

```macaulay2
isDirectory "."

```

```text
true
```

```macaulay2
isDirectory fn

```

```text
false
```

## Additional Information

- Inputs:
- `fn` a [ string](../Type/op_Coredollar_String.mdx) a filename or path
- Outputs:
- a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) whether `fn` is the path to a directory
