# GCstats

**GCstats  -- information about the status of the garbage collector**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

Macaulay2 uses the Hans Boehm [ garbage collector](../Instance/GC garbage collector.mdx)  to reclaim unused memory.  The function `GCstats`  provides information about its status such as the total number of bytes allocated the current heap size the number of garbage collections done the number of threads used in each collection the total cpu time spent in garbage collection etc.The value returned is a hash table from which individual bits of information can be easily extracted as follows.Any entries whose keys are all upper case give the values of environment variables affecting the operation of the garbage collector that have been specified by the user.For further information about the individual items in the table we refer the user to the source code and documentation of the garbage collector.
