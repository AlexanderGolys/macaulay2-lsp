# removeFile

**removeFile  -- remove a file**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

Under a unix system such as GNU/Linux what really happens is that the link to the file specified by `f`  is removed.  The file itself disappears after all the links to it are removed.  See [linkFile](../Function/linkFile.mdx) .

## Examples

```macaulay2
removeFile f
```

## Additional Information

- Inputs:
- `f` a [ string](../Type/op_Coredollar_String.mdx)
- Consequences:
- the file reachable by the path `f` is removed
