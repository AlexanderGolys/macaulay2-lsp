# isRegularFile

**isRegularFile  -- whether a file is a regular file**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

 In UNIX a regular file is one that is not special in some way.  Special files include symbolic links and directories.  A regular file is a sequence of bytes stored permanently in a file system.

## Examples

```macaulay2
isRegularFile fn
```

```macaulay2
isRegularFile fn

```

```text
true
```

## Additional Information

- Inputs:
- `fn` a [ string](../Type/op_Coredollar_String.mdx) a filename or path
- Outputs:
- a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) whether `fn` is the path to a regular file
