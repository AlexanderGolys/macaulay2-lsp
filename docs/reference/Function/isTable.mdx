# isTable

**isTable  -- whether something is a list of lists of equal length**

**Type:** [FunctionClosure](../Type/FunctionClosure.mdx)

## Description

isTable  -- whether something is a list of lists of equal length

## Examples

```macaulay2
isTable t
```

```macaulay2
isTable {{1,2,3},{4,5,6}}

```

```text
true
```

```macaulay2
isTable {{1,2,3},{4,5}}

```

```text
false
```

## Additional Information

- Inputs:
- `t` a [ thing](../Type/Thing.mdx)
- Outputs:
- `b` a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) whether or not $t$ is a table


### Caveat

It is intrinsically impossible to represent a $0\times k$ matrix as a list of lists.
