# globalAssignFunction

**globalAssignFunction  -- the standard method for the global assignment hook**

**Type:** [FunctionClosure](../Type/FunctionClosure.mdx)

## Description

`globalAssignFunction`  -- the standard function that can be used as a method for [GlobalAssignHook](../Method/op_Coredollar_GlobalAssignHook.mdx)  so that certain types of things when assigned to a global variable will acquire the name of the global variable as their name.  The companion function [globalReleaseFunction](../Function/op_Coredollar_globalReleaseFunction.mdx)  is used to release the name when the global variable gets reassigned. Another thing done by this function is to apply [use](../Method/op_Coredollar_use.mdx)  to the thing. This is used for polynomial rings to assign values to the symbols representing the variables (indeterminates) in the ring.
