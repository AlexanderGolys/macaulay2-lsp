# scanPairs

**scanPairs  -- apply a function to the pairs in a hash table**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

`scanPairs(t f)`  applies the function `f`  to each pair `(k t#k)`  in the hash table `t` . In other words `f`  is applied to each key `k`  paired with its corresponding value `t#k` .If `t` is not a hash table then `scan(pairs t f)` is called.

## Examples

```macaulay2
scanPairs(t f)
```

```macaulay2
scanPairs(t (kv) -> print (k+v))
9
22
7
24
```

```macaulay2
scanPairs(t (kv) -> if v==20 then print k)
2
4
```

```macaulay2
scanPairs({4, 5, 6} print)
(0 4)
(1 5)
(2 6)
```

## Additional Information

- Inputs:
- `t` a [ hash table](../Type/op_Coredollar_HashTable.mdx) a [ basic list](../Type/op_Coredollar_BasicList.mdx) or a [ dictionary](../Type/op_Coredollar_Dictionary.mdx) or any instance of a class with an [iterator](../Method/iterator.mdx) method installed
- `f` a [ function](../Type/Function.mdx)


### Caveat

This function requires an immutable hash table.  To scan the pairs in a mutable hash table use `scan(pairs t f)` .
