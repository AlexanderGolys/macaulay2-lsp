# number

**number  -- count how many elements of a list satisfy a condition**

**Type:** [FunctionClosure](../Type/FunctionClosure.mdx)

## Description

To find the first or last index of an element satisfying the condition see [position](../Method/position.mdx). For all indices that match the condition see [positions](../Method/op_Coredollar_positions.mdx). To return the elements rather than their indices see [select](../Method/select.mdx).

## Examples

```macaulay2
number(A f)
```

```macaulay2
number(0..100 isPrime)

```

```text
25
```

```macaulay2
number(0..100 odd)

```

```text
50
```

```macaulay2
number(0..100 i -> i==17)

```

```text
1
```

## Additional Information

- Inputs:
- `A` a list or sequence
- `f` a boolean function
- Outputs:
- `c` an integer the number of elements of `A` that satisfy `f`
