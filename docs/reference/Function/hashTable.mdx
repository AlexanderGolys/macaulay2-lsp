# hashTable

**hashTable  -- make a hash table**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

`hashTable(hv)`  -- produce a hash table from a list `v`  of key-value pairs with an optional collision handler function `h` . The pairs may be of the form ``  `{a,b}`  or `(ab)` . Missing entries in the list represented by [null](../Instance/null.mdx)  will be silently ignored.
