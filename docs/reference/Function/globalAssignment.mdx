# globalAssignment

**globalAssignment  -- install standard global assignment method**

**Type:** [FunctionClosure](../Type/FunctionClosure.mdx)

## Description

 One type for which this has been done is [Ring](../Type/Ring.mdx)  as illustrated in the following example.

## Examples

```macaulay2
globalAssignment X
```

## Additional Information

- Inputs:
- `X` a [ type](../Type/op_Coredollar_Type.mdx)
- Consequences:
- the functions [globalAssignFunction](../Function/globalAssignFunction.mdx) and [globalReleaseFunction](../Function/op_Coredollar_globalReleaseFunction.mdx) are installed in the type `X` under [GlobalAssignHook](../Method/op_Coredollar_GlobalAssignHook.mdx) and [GlobalReleaseHook](../Instance/GlobalReleaseHook.mdx) respectively. The effect is that when an object of type `X` is assigned to a global variable the function [use](../Method/op_Coredollar_use.mdx) is called on it and thereafter that object will print out as the name of the variable.
