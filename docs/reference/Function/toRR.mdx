# toRR

**toRR  -- convert to high-precision real number**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

toRR  -- convert to high-precision real number

## Examples

```macaulay2
toRR(precx)
```

```macaulay2
toRR(2001/7)

```

```text
.1428571428571428571428571428571428571428571428571428571428571

RR (of precision 200)
```

## Additional Information

- Inputs:
- `prec` an [ integer](../Type/ZZ.mdx) the number of bits of precision desired
- `x` a [ real number](../Type/op_x226_x132_x157.mdx) an [ integer](../Type/ZZ.mdx) or a [ rational number](../Type/op_x226_x132_x154.mdx)
- Outputs:
- a [ real number](../Type/op_x226_x132_x157.mdx) the result of converting `x` to a high-precision real number
