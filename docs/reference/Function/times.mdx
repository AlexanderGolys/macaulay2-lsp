# times

**times  -- multiplication**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

`times(xy ...)`  yields the product of its arguments. If there are no arguments the value is the integer 1.

## Examples

```macaulay2
times(xy ...)
```
