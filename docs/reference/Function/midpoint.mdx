# midpoint

**midpoint  -- midpoint of an interval**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

Returns the midpoint (the average of the endpoints) of the input interval.

## Examples

```macaulay2
x = midpoint I
```

## Additional Information

- Inputs:
- `I` a [ real interval](../Type/RRi.mdx)
- Outputs:
- `x` a [ real number](../Type/op_x226_x132_x157.mdx)
