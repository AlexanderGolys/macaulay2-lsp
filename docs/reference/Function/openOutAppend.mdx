# openOutAppend

**openOutAppend  -- open an output file for appending**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

A filename starting with `~/`  will have the tilde replaced by the user's home directory.

## Examples

```macaulay2
openOutAppend fn
```

```macaulay2
h = openOutAppend "test-file"

```

```text
test-file

File
```

## Additional Information

- Inputs:
- `fn` a [ string](../Type/op_Coredollar_String.mdx)
- Outputs:
- a [ file](../Type/op_Coredollar_File.mdx) an open output file whose filename is `fn`
