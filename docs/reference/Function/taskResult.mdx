# taskResult

**taskResult  -- retrieve the value returned by a task**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

taskResult  -- retrieve the value returned by a task

## Examples

```macaulay2
taskResult t
```

## Additional Information

- Inputs:
- `t` a [ task](../Type/op_Coredollar_Task.mdx)
- Outputs:
- the value returned by the function provided to [schedule(Function)](../Instance/schedule(Function).mdx) when the task was started. [taskResult(Task)](../Instance/taskResult(Task).mdx) will first wait for the task to finish if necessary. If the task is cancelled an error will be signaled.
- Consequences:
- The field in `t` where the return value is stored is set to [null](../Instance/null.mdx) and the task is considered to have completely terminated. Attempting to fetch the return value a second time will signal an error.
