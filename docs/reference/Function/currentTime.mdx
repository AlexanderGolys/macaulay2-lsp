# currentTime

**currentTime  -- get the current time**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

We can compute roughly how many years ago the epoch began as follows.We can also compute how many months account for the fractional part of that number.Compare that to the current date available from a standard Unix command.

## Examples

```macaulay2
currentTime()
```

```macaulay2
currentTime()

```


```macaulay2
currentTime() /( (365 + 97./400) * 24 * 60 * 60 )

```

```text
56.01927201334274

RR (of precision 53)
```
