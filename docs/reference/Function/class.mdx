# class

**class  -- class of an object**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

 Every object in Macaulay2 has a class see [what a class is](../Instance/what a class is.mdx)  for more details. Use strict equality `===`  to test the exact class of an object. However each PolynomialRing is a Ring by inheritance so a more useful test uses [instance](../Function/instance.mdx) .

## Examples

```macaulay2
class x
```

```macaulay2
class {1,2,3}

```

```text
List

Type
```

```macaulay2
class R

```

```text
PolynomialRing

Type
```

```macaulay2
class R === PolynomialRing

```

```text
true
```

```macaulay2
class R === Ring

```

```text
false
```
