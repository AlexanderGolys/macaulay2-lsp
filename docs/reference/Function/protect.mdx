# protect

**protect  -- protect a symbol**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

There is no function for unprotecting symbols.

## Examples

```macaulay2
protect s
```

```macaulay2
protect symbol s

```

```text
s

Symbol
```

## Additional Information

- Inputs:
- `s` a [ symbol](../Type/op_Coredollar_Symbol.mdx)
- Outputs:
- `s` a [ symbol](../Type/op_Coredollar_Symbol.mdx)
- Consequences:
- the symbol `s` is protected from having its value changed
