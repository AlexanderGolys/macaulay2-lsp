# setIOExclusive

**setIOExclusive  -- exclusive I/O for the current thread**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

setIOExclusive  -- exclusive I/O for the current thread

## Examples

```macaulay2
setIOExclusive()

```

## Additional Information

- Inputs:
- `f` a [ file](../Type/op_Coredollar_File.mdx)
- Consequences:
- the current thread becomes the only one permitted to use the file f or if no file is given the files [stdio](../Instance/op_Coredollar_stdio.mdx) and [stderr](../Instance/stderr.mdx).
