# isPrimitive

**isPrimitive  -- whether an element is a primitive element of a finite field**

**Type:** [FunctionClosure](../Type/FunctionClosure.mdx)

## Description

`isPrimitive(f)`  -- Given an element `f`  in a quotient of a polynomial ring `R`  over a finite field `K` which is itself a finite field with the ring being finite dimensional over the field determine if `f`  generates the multiplicative group of this field.

## Examples

```macaulay2
isPrimitive t

```

```text
false
```

```macaulay2
isPrimitive (t-1)

```

```text
true
```
