# same

**same  -- whether everything in a list is the same**

**Type:** [FunctionClosure](../Type/FunctionClosure.mdx)

## Description

The comparison is done with "===" which is quick but not always intuitive. Here is a simple example of what can go wrong:We can see the problem by asking `Macaulay2`  to display the class of each element of `L` . (Or use the function [uniform](../Function/op_Coredollar_uniform.mdx) which returns whether or not the elements of a list are all of the same class.)The first `1`  is an element of the ring `R`  the second `1`  is an element of the fraction field of `R`  and the third `1`  is an integer. Thus `Macaulay2`  thinks of these three elements as being pairwise unequal with respect to the operator "===".

## Examples

```macaulay2
same L
```

```macaulay2
same {1, 1, 1, 1}

```

```text
true
```

```macaulay2
same {1, 2, 1, 1}

```

```text
false
```

```macaulay2
same L

```

```text
false
```

- Outputs:
