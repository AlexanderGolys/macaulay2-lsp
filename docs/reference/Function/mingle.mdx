# mingle

**mingle  -- mingle elements of several lists**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

The output list `M`  takes the first element of each `Li i=1...n`  followed by the second element of `Li i=1...n`  and so forth.The lists can have different lengths. After a list is exhausted it will be silently ignored.To transpose a nested list (thinking of it as a matrix) try using `mingle`  with [pack](../Method/op_Coredollar_pack.mdx).Notice from the previous example that `mingle`  accepts sequences and other types of [BasicList](../Type/op_Coredollar_BasicList.mdx)s as input but the output will always be a [List](../Type/op_Coredollar_List.mdx).Further examples:

## Additional Information

- Inputs:
- `L` a [ basic list](../Type/op_Coredollar_BasicList.mdx) a list of lists `L=\{L1, L2,..., Ln\}`
- Outputs:
- `M` a [ list](../Type/op_Coredollar_List.mdx) a new list mingling the elements of all lists in `L`
