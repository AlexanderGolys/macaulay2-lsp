# synonym

**synonym  -- synonym for members of a class**

**Type:** [FunctionClosure](../Type/FunctionClosure.mdx)

## Description

 A synonym can be installed with the assignment statement `X.synonym=t` .  The synonym is used by [ofClass](../Method/op_Coredollar_ofClass.mdx) .

## Examples

```macaulay2
synonym X
```

```macaulay2
synonym ZZ

```

```text
integer
```

```macaulay2
synonym Stack

```

```text
object of class Stack
```

```macaulay2
Stack.synonym = "Deligne-Mumford stack"

```

```text
Deligne-Mumford stack
```

## Additional Information

- Inputs:
- `X` a [ type](../Type/op_Coredollar_Type.mdx)
- Outputs:
- a [ string](../Type/op_Coredollar_String.mdx) a synonym for members of the class `X`
