# take

**take  -- take some elements from a list or sequence**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

The pair $\{j,k\}$ must be given with both entries non-negative and $j\le k$. Otherwise an empty list is returned.If `x` is any object belonging to a class with the [iterator](../Method/iterator.mdx) method installed then a list containing the first $i$ (or the $(j+1)$th through $(k+1)$th) objects returned when [next](../Method/op_Coredollar_next.mdx) is called on the output of `iterator x` is returned.  If fewer than $i$ (or $k+1$) objects are returned before the [StopIteration](../Method/op_Coredollar_StopIteration.mdx) symbol is encountered then the list will have shorter than expected length.

## Additional Information

- Inputs:
- `L` a [ basic list](../Type/op_Coredollar_BasicList.mdx)
- `x` a [ thing](../Type/Thing.mdx)
- `i` an [ integer](../Type/ZZ.mdx)
- `j` an [ integer](../Type/ZZ.mdx)
- `k` an [ integer](../Type/ZZ.mdx)
- Outputs:
- `L2` a [ basic list](../Type/op_Coredollar_BasicList.mdx) the list or sequence containing the first `i` elements of `L` (if `i` positive) or the last `i` elements of `L` (if `i` negative) or if given the pair `jk` the list or sequence containing the elements of `L` with indices `j` through `k`
