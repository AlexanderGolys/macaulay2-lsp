# toSequence

**toSequence  -- convert to sequence**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

`toSequence x` yields the elements of a `x` as a sequence.If `x` is already a sequence then `x` is returned.

## Examples

```macaulay2
toSequence x
```

```macaulay2
toSequence {1, 2, 3}

```

```text
(1 2 3)

Sequence
```

```macaulay2
toSequence "foo"

```

```text
(f o o)

Sequence
```

```macaulay2
toSequence iterator {1, 2, 3}

```

```text
(1 2 3)

Sequence
```

```macaulay2
toSequence (1 2 3)

```

```text
(1 2 3)

Sequence
```

## Additional Information

- Inputs:
- `x` a [ basic list](../Type/op_Coredollar_BasicList.mdx) or a [ string](../Type/op_Coredollar_String.mdx) or an instance of a class with the [iterator](../Method/iterator.mdx) method installed
- Outputs:
- a [ sequence](../Type/Sequence.mdx)
