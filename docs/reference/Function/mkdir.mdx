# mkdir

**mkdir**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

Only one directory will be made so the components of the path p other than the last must already exist.A filename starting with `~/`  will have the tilde replaced by the home directory.

## Examples

```macaulay2
mkdir p
```

```macaulay2
mkdir p
```

## Additional Information

- Inputs:
- `p` a [ string](../Type/op_Coredollar_String.mdx) a path to a directory to be made
- Consequences:
- a directory will be created at the path `p`
