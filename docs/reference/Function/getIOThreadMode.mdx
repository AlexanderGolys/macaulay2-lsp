# getIOThreadMode

**getIOThreadMode  -- get I/O thread mode**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

getIOThreadMode  -- get I/O thread mode

## Examples

```macaulay2
getIOThreadMode()
getIOThreadMode f
```

## Additional Information

- Inputs:
- `f` a [ file](../Type/op_Coredollar_File.mdx)
- Consequences:
- returns the I/O thread mode for the file f or if no file is given[stdio](../Instance/op_Coredollar_stdio.mdx) as an integer: 
- 0 for unsynchronized
- 1 for synchronized
- 2 for exclusive
