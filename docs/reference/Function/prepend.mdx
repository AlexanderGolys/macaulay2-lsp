# prepend

**prepend  -- add an element to the beginning of a list**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

The new list will be of the same [class](../Function/op_Coredollar_class.mdx) as `L` .Only a single element can be prepended with this function. To prepend the elements of a list use [join](../Function/join.mdx). To add the new element to the end of the list or at a particular index use [append](../Function/op_Coredollar_append.mdx) or [insert](../Method/op_Coredollar_insert.mdx) respectively.Prepend always returns a *new*  list rather than modifying the input list even if `L`  is a [MutableList](../Type/op_Coredollar_MutableList.mdx).Notice that the order of the arguments is switched in `prepend`  versus `append` : we write `prepend(x L)`  and `append(L x)` . A good way to remember this is that the new element is visually placed *before*  or *after*  the list depending on where we want it to appear in the output.

## Examples

```macaulay2
prepend(x L)
```

```macaulay2
prepend(3 {1, 7, 8, 3})

```

```text
{3, 1, 7, 8, 3}

List
```

```macaulay2
prepend("new" L)

```

```text
{new, old, old, old}

List
```

```macaulay2
prepend(z K)

```

```text
(z a b c)

Sequence
```

```macaulay2
peek prepend(7 L)

```

```text
MutableList{7, 2, 3, 5}
```

## Additional Information

- Inputs:
- `L` a [ basic list](../Type/op_Coredollar_BasicList.mdx)
- `x` a [ thing](../Type/Thing.mdx)
- Outputs:
- a [ basic list](../Type/op_Coredollar_BasicList.mdx) the list obtained by adding the element `x` to the beginning of list `L`
