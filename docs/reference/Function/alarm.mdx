# alarm

**alarm  -- set an alarm**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

 If `n`  is zero then no alarm is scheduled and any previously scheduled alarm is cancelled. Any pending alarm will be cancelled when any other error occurs or when the top level loop offers an input prompt to the user. The value returned is the number of seconds remaining until any previously scheduled alarm was due to be delivered or zero if there was no previously scheduled alarm. This command may interfere with [time](../Method/op_Coredollar_time.mdx)  or [sleep](../Function/op_Coredollar_sleep.mdx)  on some systems.

## Examples

```macaulay2
alarm n
```

## Additional Information

- Inputs:
- `n` an [ integer](../Type/ZZ.mdx)
- Consequences:
- the alarm will be sounded after `n` seconds; it can be intercepted with [try](../Method/op_Coredollar_try.mdx)
