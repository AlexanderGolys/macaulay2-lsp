# applicationDirectory

**applicationDirectory  -- the path to the user's application directory**

**Type:** [FunctionClosure](../Type/FunctionClosure.mdx)

## Description

The function [installPackage](../Method/installPackage.mdx)  by default installs packages under the application directory.  At program startup unless the `-q`  option is provided on the command line an entry will be added to the [path](../Instance/path.mdx)  so packages can be loaded from there by [loadPackage](../Method/loadPackage.mdx)  and [needsPackage](../Method/op_Coredollar_needsPackage.mdx) .  Moreover the [initialization file](../Instance/initialization file.mdx)  if found there will be run.The function [applicationDirectorySuffix](../Instance/applicationDirectorySuffix.mdx)  determines the value of `applicationDirectory`  and can be modified by the user.
