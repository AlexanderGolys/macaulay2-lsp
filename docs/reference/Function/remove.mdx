# remove

**remove  -- remove an entry from a mutable hash table list or database**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

`remove(T k)`  removes and returns the entry of `T`  stored under the key `k` .If `T`  is not a mutable hash table an error is thrown. One way to remove an entry from an immutable hash table is with the function [applyPairs](../Function/op_Coredollar_applyPairs.mdx):`remove` works similarly when `T` is a database.  See [Database](../Type/Database.mdx) for more information.If `T` is a mutable list then `k` gives the index of the element to be removed.If `k` is negative then the index is determined by counting backwards from the end of `T`.

## Examples

```macaulay2
remove(T k)
```

```macaulay2
remove(T a)

```

```text
1
```

```macaulay2
remove(T 0)

```

```text
1
```

```macaulay2
remove(T -1)

```

```text
4
```

## Additional Information

- Inputs:
- `T` a [ hash table](../Type/op_Coredollar_HashTable.mdx) a [ mutable list](../Type/op_Coredollar_MutableList.mdx) or a [ database](../Type/Database.mdx)
- `k` the key to remove (must be an [ integer](../Type/ZZ.mdx) if `T` is a mutable list or a [ string](../Type/op_Coredollar_String.mdx) if it is a database)
- Outputs:
- a [ thing](../Type/Thing.mdx) the removed value;
