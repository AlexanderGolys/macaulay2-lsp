# instance

**instance  -- whether something has a certain type**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

`instance(xX)`  -- tells whether `x`  is an instance of the type `X` . We say that x is an instance of X if X is the class of x or a parent of the class of x or a grandparent and so on.
