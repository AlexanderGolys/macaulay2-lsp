# currentDirectory

**currentDirectory  -- current working directory**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

If a component of the path to the current directory no longer exist an error will be signalled.

## Examples

```macaulay2
currentDirectory()
```

```macaulay2
currentDirectory()

```

```text
/usr/share/Macaulay2/
     Macaulay2Doc-temporary/
```

## Additional Information

- Outputs:
- the complete path to the current directory together with an extra slash
