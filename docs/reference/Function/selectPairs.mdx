# selectPairs

**selectPairs  -- select a part of a hash table by pairs**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

If `x` is not a hash table then `select(pairs x f)` (or `select(n pairs x f)`) is called.

selectPairs(n x f)

## Additional Information

- Inputs:
- `n` an [ integer](../Type/ZZ.mdx)
- `x` a [ hash table](../Type/op_Coredollar_HashTable.mdx) or a [ basic list](../Type/op_Coredollar_BasicList.mdx)
- `f` a [ function](../Type/Function.mdx)
- Outputs:
- a [ hash table](../Type/op_Coredollar_HashTable.mdx) or a [ basic list](../Type/op_Coredollar_BasicList.mdx) containing all (or n if it is given) key-value pairs (kv) from x for which `f(kv)` evaluates to true.


### Caveat

If `x` is a hash table then it must be immutable.
