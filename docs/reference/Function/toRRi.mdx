# toRRi

**toRRi  -- construct an interval**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

Returns an interval as small as possible containing `n`  or from `l`  to `r` .  Note that if `l`  is to the right of `r`  the constructed interval is empty.  This is a more low-level function and [interval](../Method/interval.mdx) or span should be used instead.

## Examples

```macaulay2
I = toRRi(n)
I = toRRi(lr)
I = toRRi(preclr)
```

## Additional Information

- Inputs:
- `n` a [ number](../Type/op_Coredollar_Number.mdx)
- `l` a [ number](../Type/op_Coredollar_Number.mdx)
- `r` a [ number](../Type/op_Coredollar_Number.mdx)
- `prec` an [ integer](../Type/ZZ.mdx)
- Outputs:
- `I` a [ real interval](../Type/RRi.mdx)
