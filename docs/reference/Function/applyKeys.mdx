# applyKeys

**applyKeys  -- apply a function to each key in a hash table**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

applyKeys  -- apply a function to each key in a hash table

## Examples

```macaulay2
applyKeys(H f)
applyKeys(H f g)
```

```macaulay2
applyKeys(H
```

```macaulay2
applyKeys(H k -> k//2
```

```macaulay2
applyKeys(H k -> k//2
```

## Additional Information

- Inputs:
- `H` a [ hash table](../Type/op_Coredollar_HashTable.mdx)
- `f` a [ function](../Type/Function.mdx) of one argument
- `g` a [ function](../Type/Function.mdx) of two arguments for collision handling
- Outputs:
- a [ hash table](../Type/op_Coredollar_HashTable.mdx) obtained by applying `f` to each key in `H`


### Caveat

It is an error for the function `f`  to return two pairs with the same key. When this is a possibility use the function `g`  to specify how the two pairs should be reconciled.
