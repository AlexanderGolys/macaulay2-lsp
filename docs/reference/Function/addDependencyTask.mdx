# addDependencyTask

**addDependencyTask  -- schedule a task but ensure that it will not run until another task finishes**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

addDependencyTask  -- schedule a task but ensure that it will not run until another task finishes

## Examples

```macaulay2
addDependencyTask(tu)
```

```macaulay2
for i from 1 to 5 do addDependencyTask(t_i t_(i - 1))
```

## Additional Information

- Inputs:
- `t` a [ task](../Type/op_Coredollar_Task.mdx)
- `u` a [ task](../Type/op_Coredollar_Task.mdx)
- Consequences:
- the task `t` will be scheduled for execution but execution will not begin until the task `u` finishes
