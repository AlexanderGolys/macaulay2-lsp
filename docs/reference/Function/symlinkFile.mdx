# symlinkFile

**symlinkFile  -- make a symbolic link to a file**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

symlinkFile  -- make a symbolic link to a file

## Examples

```macaulay2
symlinkFile(srcdst)
```

```macaulay2
symlinkFile("qwert" fn)
```

## Additional Information

- Inputs:
- `src` a [ string](../Type/op_Coredollar_String.mdx)
- `dst` a [ string](../Type/op_Coredollar_String.mdx)
- Consequences:
- a symbolic link at the location in the directory tree specified by `dst` is created pointing to `src`
