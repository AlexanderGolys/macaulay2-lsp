# userSymbols

**userSymbols  -- a list of the user's symbols**

**Type:** [FunctionClosure](../Type/FunctionClosure.mdx)

## Description

`userSymbols ()`  provides a list of symbols defined by the user.`userSymbols X`  limits the list to those symbols whose values are instances of the [class](../Function/op_Coredollar_class.mdx)  `X` . Protected symbols are excluded from the list.

## Examples

```macaulay2
userSymbols ()
```

## Additional Information

- Outputs:
- a [ list](../Type/op_Coredollar_List.mdx) a list of symbols
