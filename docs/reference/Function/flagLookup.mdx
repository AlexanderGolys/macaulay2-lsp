# flagLookup

**flagLookup  -- flag a symbol**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

To get access to a flagged symbol without signalling an error use [getGlobalSymbol](../Function/getGlobalSymbol.mdx) .

## Examples

```macaulay2
flagLookup x
```

## Additional Information

- Inputs:
- `x` a [ symbol](../Type/op_Coredollar_Symbol.mdx)
- Outputs:
- a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) whether each subsequent reference to the symbol `x` will result in an error message
- Consequences:
- The first use arranges for each subsequent reference to the symbol `x` to result in an error message. The second use cancels the arrangement. Each subsequent use toggles the state.
