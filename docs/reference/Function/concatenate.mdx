# concatenate

**concatenate  -- join strings**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

`concatenate(st...u)`  yields the concatenation of the strings st...u. The arguments may also be lists or sequences of strings and symbols in which case they are concatenated recursively.  Additionally an integer may be used to represent a number of spaces and [null](../Instance/null.mdx)  will be represented by the empty string.

## Examples

```macaulay2
concatenate {"a",("s",3,"d",),"f"}

```

```text
as   df
```
