# benchmark

**benchmark  -- accurate timing of execution**

**Type:** [FunctionClosure](../Type/FunctionClosure.mdx)

## Description

 Produces an accurate timing for the code contained in the string `s` .  The value returned is the number of seconds. The snippet of code provided will be run enough times to register meaningfully on the clock and the garbage collector will be called beforehand.

## Examples

```macaulay2
benchmark s
```

```macaulay2
benchmark "sqrt 2p100000"

```

```text
.0002988441948638351

RR (of precision 53)
```

## Additional Information

- Inputs:
- `s` a [ string](../Type/op_Coredollar_String.mdx) a string containing Macaulay2 code
- Outputs:
- a [ real number](../Type/op_x226_x132_x157.mdx) the number of seconds it takes to evaluate the code in `s`
