# needs

**needs  -- read Macaulay2 commands if necessary**

**Type:** [FunctionClosure](../Type/FunctionClosure.mdx)

## Description

If the variable [notify](../Instance/notify.mdx)  is set to true then an informational message is displayed after the file is loaded.

## Examples

```macaulay2
needs "f"
```

## Additional Information

- Consequences:
- The file named `f` is loaded with [load](../Function/op_Coredollar_load.mdx) if it hasn't been loaded yet; if it has changed since the last time it was loaded it will be loaded again from the same location as the time before without searching along the [path](../Instance/path.mdx).
