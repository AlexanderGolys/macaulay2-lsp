# print

**print  -- print something**

**Type:** [FunctionClosure](../Type/FunctionClosure.mdx)

## Description

`print x`  prints `x`  on the standard output followed by a new line. The return value is [null](../Instance/null.mdx) .

## Examples

```macaulay2
print x
```

```macaulay2
print "Hello world!"
Hello world!
```
