# isANumber

**isANumber  -- whether a number is not not-a-number**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

For a discussion of the notion of not-a-number in floating point arithmetic see http://en.wikipedia.org/wiki/NaN .

## Examples

```macaulay2
isANumber x
```

```macaulay2
isANumber 3.

```

```text
true
```

```macaulay2
isANumber inf

```

```text
true
```

```macaulay2
isANumber nan

```

```text
false
```

## Additional Information

- Inputs:
- `x` a [ number](../Type/op_Coredollar_Number.mdx)
- Outputs:
- a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) whether `x` is not *not a number*.
