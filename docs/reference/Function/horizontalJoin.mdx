# horizontalJoin

**horizontalJoin  -- join nets or strings horizontally**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

If the list `L`  contains only strings then `horizontalJoin`  acts like the command [concatenate](../Function/concatenate.mdx).Unlike `concatenate`  `horizontalJoin`  can also be used on [Net](../Type/op_Coredollar_Net.mdx)s.As the previous example shows null arguments are allowed and ignored.Nets and strings can be mixed in the input list. In this case a string is interpreted as a net of height one with baseline below the string. The operator [Net ^ ZZ](../Instance/Net ^ ZZ.mdx) can be used to lower or raise the baseline of a string or net.In the next example we use `horizontalJoin`  to concatenate the display of two random integer matrices. The matrices are converted to nets first with the command [net](../Method/op_Coredollar_net.mdx).Nested sequences in the input are automatically spliced. For instance in the next example the input is interpreted as `\{A, B, A, B, A\}` .However the command `horizontalJoin \{\{A, B\}, \{A, B, \{A\}\}\}`  will throw an error because nested lists are not automatically flattened.

```text
1|x     ||x        |4|x              |
      +------++---------+ +---------------+
      |2x    ||3x       | |5x             |
      +------++---------+ +---------------+
      |(x x)||(x x x)| |(x x x x x)|
      +------++---------+ +---------------+
      |2     ||3        | |5              |
      +------++---------+ +---------------+
```

```macaulay2
horizontalJoin N2

       +------++---------+ +---------------+
       | 2    || 3       | | 5             |
```

```text
|x     ||x        | |x              |
       +------++---------+ +---------------+

       |(x x)||(x x x)| |(x x x x x)|
       +------++---------+ +---------------+
      1|2     ||3        |4|5              |
       +------++---------+ +---------------+
```

```text
      | 7 8 3 || 8 5 2 || 7 8 3 || 8 5 2 || 7 8 3 |

```

## Additional Information

- Inputs:
- `L` a [ basic list](../Type/op_Coredollar_BasicList.mdx) a list or sequence containing nets and/or strings
- Outputs:
- a [ net](../Type/op_Coredollar_Net.mdx) or string obtained by concatenating the elements of `L`


### Caveat

This command will work with no arguments or all null arguments. The net returned has zero [height](../Method/op_Coredollar_height.mdx) and zero [depth](../Method/op_Coredollar_depth.mdx) which might be unexpected.
