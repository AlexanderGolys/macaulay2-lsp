# getNonUnit

**getNonUnit  -- retrieve a previously discovered non-unit**

**Type:** [FunctionClosure](../Type/FunctionClosure.mdx)

## Description

 If a ring has been declared to be a field using [toField](../Method/op_Coredollar_toField.mdx)  or [frac](../Method/op_Coredollar_frac.mdx)  but a nonzero element is found to not be a unit this routine will return that element otherwise [null](../Instance/null.mdx)  is returned. Warning: this function does not work yet for divisions attempted in the course of computing a Gröbner basis or resolution.

## Examples

```macaulay2
getNonUnit R
```

```macaulay2
getNonUnit A
```

## Additional Information

- Inputs:
- `R` a [ ring](../Type/Ring.mdx) in which division by a non-unit may have been attempted
- Outputs:
- a [ ring element](../Type/RingElement.mdx) the non-unit if any or [null](../Instance/null.mdx)
