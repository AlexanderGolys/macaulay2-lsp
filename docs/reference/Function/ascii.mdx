# ascii

**ascii  -- ASCII character conversion**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description


### Synopsis


- Inputs:
- `v` containing small integers
- Outputs:
- the string whose characters have the https://en.wikipedia.org/wiki/ASCII ASCII codes listed in `v`


### Synopsis


- Inputs:
- `s`
- Outputs:
- the list of (small integer) https://en.wikipedia.org/wiki/ASCII ASCII codes of the characters of `s`



## Examples

```macaulay2
ascii "abcdef"

```

```text
{97, 98, 99, 100, 101, 102}

List
```

```macaulay2

```
