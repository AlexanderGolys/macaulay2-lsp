# changeDirectory

**changeDirectory  -- change the current working directory**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

Change the current working directory to dir.If dir is omitted then the current working directory is changed to the user's home directory.

## Examples

```macaulay2
changeDirectory dir
```

```macaulay2
changeDirectory dir

```

```text
/tmp/M2-705221-0/0/
```

## Additional Information

- Inputs:
- `dir` a [ string](../Type/op_Coredollar_String.mdx)
- Outputs:
- a [ string](../Type/op_Coredollar_String.mdx) the new working directory;
