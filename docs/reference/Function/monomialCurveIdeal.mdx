# monomialCurveIdeal

**monomialCurveIdeal  -- make the ideal of a monomial curve**

**Type:** [FunctionClosure](../Type/FunctionClosure.mdx)

## Description

The ideal is defined in the polynomial ring $R$ which must have at least $n+1$ variables preferably all of equal degree. The first $n+1$ variables in the ring are used.
### A plane quintic curve of genus 6


### A genus 2 curve with one singular point


### A genus 7 curve with two singular points


### The smooth rational quartic in $\PP^3$

## Additional Information

- Inputs:
- `R` a [ polynomial ring](../Type/PolynomialRing.mdx) over a field
- `a` a [ list](../Type/op_Coredollar_List.mdx) containing integers to be used as exponents in the parametrization of a rational curve
- Outputs:
- `I` an [ ideal](../Type/op_Coredollar_Ideal.mdx) corresponding to the projective curve given parametrically on an affine piece by $t \mapsto (t^{a_0} \dots t^{a_n})$
