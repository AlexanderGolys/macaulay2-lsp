# load

**load  -- read Macaulay2 commands**

**Type:** [FunctionClosure](../Type/FunctionClosure.mdx)

## Description

`load "f"`  -- reads and executes Macaulay2 expressions found in the file named `f` .The file is sought in the directory containing the file currently being loaded if any and then along the [path](../Instance/path.mdx)  unless the name of the file begins with `/`  `$`  or `!` . If the file begins with `./`  or `../`  then it looks instead in the directory of the file currently being loaded (see [currentFileDirectory](../Instance/currentFileDirectory.mdx) ).  If no file is being loaded it will look in the current directory (see [currentDirectory](../Function/currentDirectory.mdx) ).The file is read without echoing the input printing the values or incrementing the line number.If one of the top level expressions in the file evaluates to the symbol [end](../Method/op_Coredollar_end.mdx)  the reading of the file is stopped at that point.If the variable [notify](../Instance/notify.mdx)  is set to true then an informational message is displayed after the file is loaded.
