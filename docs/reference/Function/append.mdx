# append

**append  -- add an element to the end of a list**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

The new list will be of the same [class](../Function/op_Coredollar_class.mdx) as `L` .Only a single element can be appended with this function. To append the elements of a list use [join](../Function/join.mdx). To add the new element to the beginning of the list or at a particular index use [prepend](../Function/op_Coredollar_prepend.mdx) or [insert](../Method/op_Coredollar_insert.mdx) respectively.Append always returns a *new*  list rather than modifying the input list even if `L`  is a [MutableList](../Type/op_Coredollar_MutableList.mdx).Notice that the order of the arguments is switched in `prepend`  versus `append` : we write `prepend(x L)`  and `append(L x)` . A good way to remember this is that the new element is visually placed *before*  or *after*  the list depending on where we want it to appear in the output.

## Examples

```macaulay2
append(L x)
```

```macaulay2
append({1, 7, 8, 3} 3)

```

```text
{1, 7, 8, 3, 3}

List
```

```macaulay2
append(L "new")

```

```text
{old, old, old, new}

List
```

```macaulay2
append(K z)

```

```text
(a b c z)

Sequence
```

```macaulay2
peek append(L 7)

```

```text
MutableList{2, 3, 5, 7}
```

## Additional Information

- Inputs:
- `L` a [ basic list](../Type/op_Coredollar_BasicList.mdx)
- `x` a [ thing](../Type/Thing.mdx)
- Outputs:
- a [ basic list](../Type/op_Coredollar_BasicList.mdx) the list obtained by adding the element `x` to the end of list `L`
