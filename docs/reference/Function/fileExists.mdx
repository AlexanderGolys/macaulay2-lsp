# fileExists

**fileExists  -- whether a file exists**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

 If `fn`  refers to a symbolic link then whether the file exists is determined by the content of the link and whether there is a file with the new path determined by it.  The presence of a symbolic link can be detected with [readlink](../Function/readlink.mdx) .

## Examples

```macaulay2
fileExists fn
```

```macaulay2
fileExists fn

```

```text
false
```

```macaulay2
fileExists fn

```

```text
true
```

## Additional Information

- Inputs:
- `fn` a [ string](../Type/op_Coredollar_String.mdx)
- Outputs:
- a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) whether a file with the filename or path `fn` exists
