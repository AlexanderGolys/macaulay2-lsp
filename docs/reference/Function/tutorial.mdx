# tutorial

**tutorial  -- convert documentation from tutorial format**

**Type:** [FunctionClosure](../Type/FunctionClosure.mdx)

## Description

Some of the Macaulay2 documentation is written in this format.

## Examples

```macaulay2
tutorial x
```

```macaulay2
tutorial oo

                                            +---------------+
```

```text
{We can compute $(x+y)^3$ as follows., |  R = QQ[x,y]  |}
                                            +---------------+
                                            |  (x+y)^3      |
                                            +---------------+

List
```

## Additional Information

- Inputs:
- `x` a [ string](../Type/op_Coredollar_String.mdx) documentation in tutorial format
- Outputs:
- documentation in hypertext format
