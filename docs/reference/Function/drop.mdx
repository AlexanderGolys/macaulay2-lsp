# drop

**drop  -- drop some elements from a list or sequence**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

The pair `\{j,k\}`  must be given with both entries non-negative and $j\le k$. Otherwise the original list is returned.

## Examples

```macaulay2
drop(L i)
drop(L {j,k})
```

```macaulay2
drop({a,b,c,d,e,f,g} 3)

```

## Additional Information

- Inputs:
- `L` a [ basic list](../Type/op_Coredollar_BasicList.mdx)
- `i` an [ integer](../Type/ZZ.mdx)
- `j` an [ integer](../Type/ZZ.mdx)
- `k` an [ integer](../Type/ZZ.mdx)
- Outputs:
- `L2` a [ basic list](../Type/op_Coredollar_BasicList.mdx) the list or sequence obtained by dropping the first `i` elements of `L` (if `i` positive) or the last `i` elements of `L` (if `i` negative) or if given the pair `jk` the list or sequence obtained by dropping the elements of `L` with indices `j` through `k`
