# End

**End  -- module of endomorphisms**

**Type:** [FunctionClosure](../Type/FunctionClosure.mdx)

## Description

Constructs the module of endomorphisms of $M$.

## Options

- [Strategy](../Option/Strategy.mdx) => null
- [DegreeLimit](../Option/DegreeLimit.mdx) => null
- [MinimalGenerators](../Option/MinimalGenerators.mdx) => true

## Examples

```macaulay2
End M
```

```macaulay2
End M

```
