# demark

**demark  -- insert a string between elements of a list of strings**

**Type:** [FunctionClosure](../Type/FunctionClosure.mdx)

## Description

To achieve a similar insertion while keeping the output as a list see [mingle](../Function/op_Coredollar_mingle.mdx).

## Examples

```macaulay2
demark(d L)
```

```macaulay2
demark("+" a..f)

```

```text
a+b+c+d+e+f
```

```macaulay2
demark(" and " 6:"more")

```

```text
more and more and more and more and more and more
```

## Additional Information

- Inputs:
- `d` a [ string](../Type/op_Coredollar_String.mdx)
- `L` a [ list](../Type/op_Coredollar_List.mdx) of strings
- Outputs:
- `s` a [ string](../Type/op_Coredollar_String.mdx) the string obtained by concatenating the elements of `L` with copies of the string `d` inserted between each pair
