# pseudocode

**pseudocode  -- produce the pseudocode for a function**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

One can look at specific part of the code by using `_` :It may be useful to look at code during debugging as in the following demonstration.

## Examples

```macaulay2
pseudocode f
```

```macaulay2
pseudocode(() -> 2+4*3)

```

```text
function restargs false
              numparms 0
              framesize 0
              frameID 12878
              body 2-OP + 2
                          2-OP * 4
                                 3

PseudocodeClosure
```

```macaulay2
pseudocode functionBody(() -> 2+4*3)

```

```text
2-OP + 2
            2-OP * 4
                   3

Pseudocode
```

```macaulay2
pseudocode resolution

```

```text
function restargs true
              numparms 1
              framesize 1
              frameID 199
              body adjacent global-fetch 414
                            sequence local-fetch 1 1
                                     adjacent global-fetch 360
                                              sequence local-fetch 0 1
                                                       local-fetch 0 0

PseudocodeClosure
```

## Additional Information

- Inputs:
- `f` a [ function closure](../Type/op_Coredollar_FunctionClosure.mdx)
- Outputs:
- an instance of the type [PseudocodeClosure](../Type/PseudocodeClosure.mdx) the pseudocode of the function `f`
