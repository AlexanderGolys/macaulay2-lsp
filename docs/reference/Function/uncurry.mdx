# uncurry

**uncurry  -- uncurry a function**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

`uncurry(f (ab))`      -- computes `((f a) b)` .`uncurry(f (abc))`    -- computes `(((f a) b) c)` .`uncurry(f (abcd))`  -- computes `((((f a) b) c) d)` . ... and so on.

## Examples

```macaulay2
uncurry(f (123))

```

```text
[1 2 3]

Array
```
