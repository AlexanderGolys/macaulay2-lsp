# getc

**getc  -- get a byte**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

`getc f`  obtains one byte from the input file f and provides it as a string of length 1.  On end of file an empty string of is returned. Bug: the name is cryptic and should be changed.
