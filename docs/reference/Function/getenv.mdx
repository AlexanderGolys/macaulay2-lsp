# getenv

**getenv  -- get value of environment variable**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

`getenv s`  yields the value associated with the string s in the environment.

## Examples

```macaulay2
getenv "HOME"

```

```text
/home/m2user
```
