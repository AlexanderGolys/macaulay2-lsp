# scan

**scan  -- apply a function to each element in a list or sequence**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

`scan(L f)`  applies the function `f`  to each element of the list `L` . The function values are discarded.`scan(n f)`  applies the function `f`  to each element of the list 0 1 ... n-1The keyword [break](../Method/break.mdx) can be used to terminate the scan prematurely and optionally to specify a return value for the expression. Here we use it to locate the first even number in a list.If `L` is an instance of a class with the [iterator](../Method/iterator.mdx) method installed (e.g. a string) then `f` is applied to the values obtained by repeatedly calling [next](../Method/op_Coredollar_next.mdx) on the output of `iterator L` until [StopIteration](../Method/op_Coredollar_StopIteration.mdx) is returned.

## Examples

```macaulay2
scan(L f)
scan(L L' f)
scan(n f)
```

```macaulay2
scan({a, 4, "George", 2^100} print)
a
4
George
1267650600228229401496703205376
```

```macaulay2
scan("foo" print)
f
o
o
```

```macaulay2
scan(4 print)
0
1
2
3
```

```macaulay2
v = {a,b,c}; scan(#v i -> print(iv#i))
(0 a)
(1 b)
(2 c)
```

```macaulay2
scan({3,5,7,11,44,55,77} i -> if even i then break i)

```

```text
44
```

```macaulay2
scan("foo" print)
f
o
o
```

## Additional Information

- Inputs:
- `L` a [ basic list](../Type/op_Coredollar_BasicList.mdx) or instance of a class with the [iterator](../Method/iterator.mdx) method installed
- `n` an [ integer](../Type/ZZ.mdx)
- `f` a [ function](../Type/Function.mdx)
