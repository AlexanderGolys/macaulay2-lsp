# ancestor

**ancestor  -- whether one type is an ancestor of another**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

The ancestors of `y`  are `y`  `parent y`  `parent parent y`  and so on.If `x`  is an ancestor of `y`  then we also say that `y`  is a *specialization*  of `x` .

## Examples

```macaulay2
ancestor(xy)
```

## Additional Information

- Inputs:
- `x` a [ type](../Type/op_Coredollar_Type.mdx)
- `y` a [ type](../Type/op_Coredollar_Type.mdx)
- Outputs:
- a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) whether `x` is an ancestor of `y`
