# lookupCount

**lookupCount  -- reference count for a symbol**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

`lookupCount s`  -- the number of times the symbol `s`  has been encountered in source code presented to the interpreter.
