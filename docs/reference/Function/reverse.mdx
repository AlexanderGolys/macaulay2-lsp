# reverse

**reverse  -- reverse a list sequence or string**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

The output will be the same type as the input.

## Examples

```macaulay2
reverse(L)
```

```macaulay2
reverse {5, 7, 2, 8}

```

```text
{8, 2, 7, 5}

List
```

```macaulay2
reverse (5 7 2 8)

```

```text
(8 2 7 5)

Sequence
```

```macaulay2
reverse "Hello world!"

```

```text
!dlrow olleH
```

## Additional Information

- Inputs:
- `L` a [ basic list](../Type/op_Coredollar_BasicList.mdx) or a [ string](../Type/op_Coredollar_String.mdx)
- Outputs:
- `R` a [ basic list](../Type/op_Coredollar_BasicList.mdx) or a [ string](../Type/op_Coredollar_String.mdx) containing the elements of `L` in reverse order
