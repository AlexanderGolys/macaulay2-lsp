# peek

**peek  -- examine contents of an object**

**Type:** [FunctionClosure](../Type/FunctionClosure.mdx)

## Description

This function is used during debugging Macaulay2 programs to examine the internal structure of objects.

## Examples

```macaulay2
peek o
```

## Additional Information

- Inputs:
- `o` a [ thing](../Type/Thing.mdx) any Macaulay2 object
- Outputs:
- a [ net](../Type/op_Coredollar_Net.mdx) laying out the internal contents of `o` to depth 1 bypassing installed methods for displaying the object
