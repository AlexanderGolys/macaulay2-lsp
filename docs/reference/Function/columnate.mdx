# columnate

**columnate  -- arrange strings in columns**

**Type:** [FunctionClosure](../Type/FunctionClosure.mdx)

## Description

`columnate(ws)`  -- arranges the strings in the list `s`  in columns returning a [Net](../Type/op_Coredollar_Net.mdx)  suitable for output to a terminal with a linewidth of `w` .

## Examples

```macaulay2
columnate(12 characters ascii (65 .. 90))

```

```text
A F K P U Z
     B G L Q V
     C H M R W
     D I N S X
     E J O T Y
```
