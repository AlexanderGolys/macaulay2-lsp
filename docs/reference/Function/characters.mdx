# characters

**characters  -- get characters from a string**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

 The characters are represented by strings. utf8 characters are correctly treated: To get the one-byte characters of the string use [toList](../Method/toList.mdx)  instead.

## Examples

```macaulay2
characters s
```

```macaulay2
characters "asdf"

```

```text
{a, s, d, f}

List
```

```macaulay2
characters "π ≈ 3.14159"

```

```text
{π,  , ≈,  , 3, ., 1, 4, 1, 5, 9}

List
```

## Additional Information

- Inputs:
- `s` a [ string](../Type/op_Coredollar_String.mdx)
- Outputs:
- a [ list](../Type/op_Coredollar_List.mdx) of the characters in the string `s`
