# sequence

**sequence  -- make a sequence**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

Such a function is needed occasionally to restore uniformity because a nonempty parenthesized expression with no commas is not parsed as a sequence.

## Examples

```macaulay2
sequence v
```

```macaulay2
sequence()

```

```text
()

Sequence
```

```macaulay2
sequence(4)

```

```text
1 : (4)

Sequence
```

```macaulay2
sequence(45)

```

```text
(4 5)

Sequence
```

## Additional Information

- Inputs:
- `v` a [ thing](../Type/Thing.mdx)
- Outputs:
- a [ sequence](../Type/Sequence.mdx) `v` if `v` is a sequence otherwise a sequence of length 1 containing `v`
