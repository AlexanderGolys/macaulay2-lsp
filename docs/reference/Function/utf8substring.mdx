# utf8substring

**utf8substring  -- extract part of a utf8 string**

**Type:** [CompiledFunction](../Type/CompiledFunction.mdx)

## Description

Returns the substring of `s`  that starts at index `i`  and has `n`  characters both measured in utf8 characters.

## Examples

```macaulay2
utf8substring(s i n)
```

```macaulay2
utf8substring(s 4 4)

```

```text
3.14
```

## Additional Information

- Inputs:
- `s` a [ string](../Type/op_Coredollar_String.mdx)
- `i` an [ integer](../Type/ZZ.mdx) starting index of substring
- `n` an [ integer](../Type/ZZ.mdx) length of substring
- Outputs:
- a [ string](../Type/op_Coredollar_String.mdx)
