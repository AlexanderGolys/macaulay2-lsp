# temporaryFileName

**temporaryFileName  -- make a temporary file name**

**Type:** [FunctionClosure](../Type/FunctionClosure.mdx)

## Description

 The file name is so unique that even with various suffixes appended no collision with existing files will occur.  The files will be removed when the program terminates unless it terminates as the result of an error.This function will work under Unix and also under Windows if you have a directory on the same drive called `/tmp` .If the name of the temporary file will be given to an external program it may be necessary to concatenate it with [rootPath](../Instance/rootPath.mdx)  or [rootURI](../Instance/rootURI.mdx)  to enable the external program to find the file.The temporary file name is derived from the value of the environment variable `TMPDIR`  if it has one.If [fork](../Function/op_Coredollar_fork.mdx)  is used then the parent and child Macaulay2 processes will each remove their own temporary files upon termination with the parent removing any files created before [fork](../Function/op_Coredollar_fork.mdx)  was called.

## Examples

```macaulay2
temporaryFileName()
```

```macaulay2
temporaryFileName () | ".tex"

```

```text
/tmp/M2-710672-0/0.tex
```

```macaulay2
temporaryFileName () | ".html"

```

```text
/tmp/M2-710672-0/1.html
```

## Additional Information

- Outputs:
- a unique temporary file name.
