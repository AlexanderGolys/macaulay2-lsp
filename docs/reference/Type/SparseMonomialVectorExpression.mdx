# SparseMonomialVectorExpression

**SparseMonomialVectorExpression  -- the class of all sparse monomial vector expressions**

## Description

`SparseMonomialVectorExpression`  is a type of [Expression](../Type/op_Coredollar_Expression.mdx)  representing a sparse monomial vector. The difference between this and [SparseVectorExpression](../Type/op_Coredollar_SparseVectorExpression.mdx)  is that the basis vectors are treated like variables for printing purposes.
