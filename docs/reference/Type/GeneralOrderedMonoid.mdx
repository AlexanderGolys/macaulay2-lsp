# GeneralOrderedMonoid

**GeneralOrderedMonoid  -- the class of all ordered free commutative monoids**

## Description

 This is the class of free monoids that can be handled by the [the engine of Macaulay2](../Instance/the engine of Macaulay2.mdx) .  Elements of such monoids are implemented as instances of [MonoidElement](../Type/op_Coredollar_MonoidElement.mdx) .
