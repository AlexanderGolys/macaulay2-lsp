# String

**String  -- the class of all strings**

## Description

A string is thing that contains a sequence of characters (bytes). A string is normally entered as a sequence of characters surrounded by quotation marks.Strings involving special characters can be entered by using the backslash as an escape character see ["](../Instance/".mdx) .  For an alternate method of entering strings with fewer escape sequences see [///](../Instance////.mdx) .A net is a two-dimensional array of characters and strings are regarded as a type of [ net](../Type/op_Coredollar_Net.mdx) .
