# Time

**Time  -- the class of all timing results**

## Description

`Time`  is the class of all timing results.  Each timing result is a [ basic list](../Type/op_Coredollar_BasicList.mdx)  of the form `{t,v}`  where `t`  is the number of seconds of cpu time used and `v`  is the value of the expression.
