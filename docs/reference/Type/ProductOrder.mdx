# ProductOrder

**ProductOrder  -- product ordering**

## Description

`ProductOrder` {n1, ..., nr} -- an optional argument of [MonomialOrder](../Instance/MonomialOrder.mdx)  to indicate that the monomial order is the product of r graded reverse lex orders each with n1 n2 ... nr variables. This syntax is left here for compatibility with previous Macaulay2 versions. The new syntax is `R = ZZ[a..e` .
