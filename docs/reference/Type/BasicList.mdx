# BasicList

**BasicList  -- the class of all basic lists**

## Description

For an overview of lists and sequences see [lists and sequences](../Instance/lists and sequences.mdx) . A basic list is a sequence of expressions indexed by a sequence of consecutive integers of the form `0`  `1`  ... `N-1` .  The number `N`  is called the length of the list. There are various types of basic lists depending on the application and they are displayed in different ways. The types first encountered are those of type [VisibleList](../Type/VisibleList.mdx)  but new types are easy to introduce. In the following example we introduce a new type of basic list called `L` .
