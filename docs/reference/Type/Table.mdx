# Table

**Table  -- the class of all table expressions**

## Description

`Table`  -- a type of [Expression](../Type/op_Coredollar_Expression.mdx)  representing a table i.e. a list of lists of the same length.

## Examples

```macaulay2
Table {{a,b,c},{a,bb,ccc}}

```

```text
a   b   c 
            
     a  bb  ccc

Expression of class Table
```
