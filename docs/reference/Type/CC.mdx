# CC

**CC  -- the class of all complex numbers**

## Description

 In Macaulay2 complex numbers are represented as floating point numbers and so are only approximate.  The symbol [ii](../Instance/ii.mdx)  represents the square root of -1 in many numeric contexts.  A complex number is obtained by using the symbolic constant [ii](../Instance/ii.mdx)  or the conversion functions [toCC](../Function/op_Coredollar_toCC.mdx)  and [numeric](../Method/op_Coredollar_numeric.mdx)  in combination with real numbers (see [RR](../Type/op_x226_x132_x157.mdx) ). It is stored internally as a pair of arbitrary precision floating point real numbers using the [MPFR](../Instance/MPFR.mdx)  library. Complex numbers are ordered lexicographically mingled with real numbers. The precision is measured in bits is visible in the ring displayed on the second of each pair of output lines and can be recovered using [precision](../Method/op_Coredollar_precision.mdx) . For complex numbers the functions [class](../Function/op_Coredollar_class.mdx)  and [ring](../Method/op_Coredollar_ring.mdx)  yield different results.  That allows numbers of various precisions to be used without creating a new ring for each precision. A computation involving numbers of different precisions has a result with the minimal precision occurring. Numbers that appear alone on an output line are displayed with all their meaningful digits. (Specifying 100 bits of precision yields about 30 decimal digits of precision.) Numbers displayed inside more complicated objects are printed with the number of digits specified by [printingPrecision](../Instance/printingPrecision.mdx) . Use [toExternalString](../Method/op_Coredollar_toExternalString.mdx)  to produce something that when encountered as input will reproduce exactly what you had before.

## Additional Information

### Caveat

 Currently most transcendental functions are not implemented for complex arguments.
