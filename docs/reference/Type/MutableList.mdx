# MutableList

**MutableList  -- the class of all mutable lists**

## Description

For an overview of lists and sequences see [lists and sequences](../Instance/lists and sequences.mdx) . Normally the entries in a mutable list are not printed to prevent infinite loops in the printing routines.  To print them out use [peek](../Function/op_Coredollar_peek.mdx) .

## Examples

```macaulay2
s = new MutableList from {a,b,c};
```
