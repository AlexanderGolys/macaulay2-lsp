# Matrix

**Matrix  -- the class of all matrices**

## Description

 A matrix is a homomorphism between two modules together with an integer (or vector of integers) called its degree which is used when determining whether the map is homogeneous.  The matrix is stored in the usual way as a rectangular array of ring elements. When the source or target modules are not free the matrix is interpreted as a linear transformation in terms of the generators of the modules. A matrix `f`  is an immutable object so if you want to cache information about it put it in the hash table `f.cache` . Common ways to make a matrix:
- Macaulay2Doc:: map
- Macaulay2Doc:: matrix

 Common ways to get information about matrices:
- Macaulay2Doc:: degree(Matrix)
- Macaulay2Doc:: isHomogeneous(Matrix)
- Macaulay2Doc:: matrix(Matrix)

 Common operations on matrices:
- Macaulay2Doc:: Matrix + Matrix
- Macaulay2Doc:: Matrix - Matrix
- Macaulay2Doc:: RingElement * Matrix
- Macaulay2Doc:: Matrix * Matrix
- Macaulay2Doc:: Matrix == Matrix
- Macaulay2Doc:: Matrix ++ Matrix
- Macaulay2Doc:: Matrix ** Matrix
- Macaulay2Doc:: Matrix % Matrix
- Macaulay2Doc:: Matrix // Matrix
- Macaulay2Doc:: Matrix | Matrix
- Macaulay2Doc:: Matrix || Matrix
- Macaulay2Doc:: Matrix ^ List
- Macaulay2Doc:: Matrix _ List

 Common ways to use a matrix:
- Macaulay2Doc:: cokernel(Matrix)
- Macaulay2Doc:: image(Matrix)
- Macaulay2Doc:: kernel(Matrix)
- Macaulay2Doc:: homology(MatrixMatrix)
