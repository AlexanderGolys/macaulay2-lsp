# Set

**Set  -- the class of all sets**

## Description

 Elements of sets may be any immutable object such as integers ring elements and lists of such.  Ideals may also be elements of sets. Set operations such as [Set)](../Instance/isMember(Thing.mdx)  [ union](../Instance/Set + Set.mdx)  [ intersection](../Instance/Set * Set.mdx)  [ difference](../Instance/Set - Set.mdx)  [ Cartesian product](../Instance/Set ** Set.mdx)  [ Cartesian power](../Instance/VirtualTally ^** ZZ.mdx)  and [Set)](../Instance/isSubset(Set.mdx)  are available. For example[ Ideals](../Type/op_Coredollar_Ideal.mdx)  in Macaulay2 come equipped with a specific sequence of generators so the following two ideals are not considered strictly equal and thus the set containing them will appear to have two elements. However if you [trim](../Method/op_Coredollar_trim.mdx)  the ideals then the generating sets will be the same and so the set containing them will have one element. A set is implemented as a [HashTable](../Type/op_Coredollar_HashTable.mdx)  whose keys are the elements of the set and whose values are all 1.  In particular this means that two objects are considered the same exactly when they are strictly equal according to [===](../Method/op_Coredollar_eq_eq_eq.mdx) .
