# Program

**Program  -- external program object**

## Description

A hash table returned by [findProgram](../Method/findProgram.mdx) with the following strings as keys:
- `"name"` the name of the loaded program. This comes from the first argument passed to [findProgram](../Method/findProgram.mdx). It is also what is displayed when printing a Program.
- `"path"` the path to the program as determined by [findProgram](../Method/findProgram.mdx).
- `"prefix"` a sequence of two strings identifying the prefix prepended to the binary executables. See [findProgram](../Method/findProgram.mdx) specifically the description of the `Prefix` option for more.
- `"version"` a string containing the version number of the program. Only present if [findProgram](../Method/findProgram.mdx) was called with the `MinimumVersion` option.
