# VerticalList

**VerticalList  -- a type of visible self-initializing list that prints vertically**

## Description

 All operations on lists apply to vertical lists since they inherit from the type [VisibleList](../Type/VisibleList.mdx) .  The only difference is the way that a vertical list is displayed vertically. One may get a normal list back from a vertical list as follows.

## Examples

```macaulay2
VerticalList x
```

```macaulay2
v = VerticalList oo

```

```text
{a}
     {b}
     {c}
     {d}
     {e}

VerticalList
```

## Additional Information

- Inputs:
- `x` a [ list](../Type/op_Coredollar_List.mdx)
- Outputs:
- a [ vertical list](../Type/VerticalList.mdx)
