# IndexedVariable

**IndexedVariable  -- the class of all indexed variables**

## Description

 Indexed variables provide the possibility of producing polynomial rings `R[x_0 x_1 ... x_(n-1)]`  in n variables where n is not known in advance.  If `x`  is an symbol and i is an integer then `x_i`  produces an indexed variable. After this has been done an assignment `x_i=v`  will assign another value to it.  A new sequence of indexed variables of length n assigned to the symbol `x`  can be produced with `x_1 .. x_n`  and that sequence can be used in constructing a polynomial ring. Warning: the values of the indexed variables `t_i`  are stored in a global location behind the scenes so may not get garbage collected even if `t`  is a local variable.
