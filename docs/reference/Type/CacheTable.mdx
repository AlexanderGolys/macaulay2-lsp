# CacheTable

**CacheTable  -- hash tables for caching**

## Description

A cache table is a type of mutable hash table designed for caching computed values that may be recalled later. Cache tables are designed so their contents will not participate in any comparisons by the strict comparison operator `===`.To that end any two cache tables with the same class and parent are considered equal to each other and have hash code equal to 0.
