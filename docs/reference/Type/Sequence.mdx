# Sequence

**Sequence  -- the class of all sequences -- (...)**

## Description

A sequence is an ordered collection of things enclosed by parentheses and separated by commas.  Use [#](../Method/op_Coredollar_hash.mdx)  to get the length of a sequence of to get one of the elements.To convert sequences to and from other types of [BasicList](../Type/op_Coredollar_BasicList.mdx)  in addition to [toSequence](../Function/toSequence.mdx)  one may use [new](../Method/op_Coredollar_new.mdx) .For an overview of lists and sequences see [lists and sequences](../Instance/lists and sequences.mdx) .

## Examples

```macaulay2
new Sequence from [abc]

```

```text
(a b c)

Sequence
```
