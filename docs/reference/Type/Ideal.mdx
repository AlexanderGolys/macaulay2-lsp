# Ideal

**Ideal  -- the class of all ideals**

## Description

 For basic information about ideals in *Macaulay2*  see [ideals](../Instance/ideals.mdx) . Common ways to make an ideal:
- Macaulay2Doc:: ideal
- Saturation:: annihilator
- Macaulay2Doc:: content
- Macaulay2Doc:: fittingIdeal
- Macaulay2Doc:: kernel(RingMap)
- Macaulay2Doc:: minors
- Macaulay2Doc:: pfaffians

 Common ways to get information about an ideal:
- Macaulay2Doc:: generators(Ideal)
- Macaulay2Doc:: Ideal _*
- Macaulay2Doc:: isSubset(IdealIdeal)
- MinimalPrimes:: isPrime(Ideal)

 Common operations on ideals:
- Macaulay2Doc:: Ideal + Ideal
- Macaulay2Doc:: Ideal * Ideal
- Macaulay2Doc:: Ideal == Ideal
- Macaulay2Doc:: Ideal == ZZ
- Macaulay2Doc:: Ideal ^ ZZ
- Macaulay2Doc:: trim(Ideal)

 Gröbner bases normal forms free resolutions
- Macaulay2Doc:: gb
- Macaulay2Doc:: leadTerm
- Macaulay2Doc:: codim
- Macaulay2Doc:: dim
- Macaulay2Doc:: Matrix % Ideal
- Complexes:: freeResolution
- Macaulay2Doc:: betti

 Numeric information about homogeneous ideals
- Macaulay2Doc:: degree
- Macaulay2Doc:: poincare
- Macaulay2Doc:: hilbertFunction
- Macaulay2Doc:: hilbertPolynomial
- Macaulay2Doc:: hilbertSeries
- Macaulay2Doc:: genera
- Macaulay2Doc:: euler

 Primary decomposition and components of an ideal
- MinimalPrimes:: minimalPrimes
- MinimalPrimes:: radical
- PrimaryDecomposition:: associatedPrimes
- PrimaryDecomposition:: primaryDecomposition
- PrimaryDecomposition:: topComponents
- Saturation:: saturate(IdealIdeal)
- Saturation:: Ideal: Ideal
- Macaulay2Doc:: intersect

 Ideals from geometry
- Macaulay2Doc:: Fano
- Macaulay2Doc:: Grassmannian
- Macaulay2Doc:: monomialCurveIdeal
- Macaulay2Doc:: singularLocus

 Common ways to use an ideal:
- Macaulay2Doc:: Ring / Ideal

 An ideal `I`  is an immutable object so if you want to cache information about it put it in the hash table `I.cache` .
