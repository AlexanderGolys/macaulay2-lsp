# Ring

## Description

- Macaulay2Doc:: Ring / Ideal

 Common functions for accessing the variables or elements in a ring:
- Macaulay2Doc:: use(Ring)
- Macaulay2Doc:: generators(Ring)
- Macaulay2Doc:: numgens(Ring)
- Macaulay2Doc:: Ring _ ZZ

 Common ways to get information about a ring:
- Macaulay2Doc:: char(Ring)
- Macaulay2Doc:: coefficientRing(Ring)
- Macaulay2Doc:: dim(Ring)

- Macaulay2Doc:: Ring ^ ZZ
