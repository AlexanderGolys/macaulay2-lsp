# Thing

**Thing  -- the class of all things**

## Description

 Everything in Macaulay2 is a thing .  This includes numbers strings and lists.  More complicated things such as polynomials groups rings and chain complexes are implemented as hash tables .  See [Type](../Type/op_Coredollar_Type.mdx)  for information about what types of things there are.
