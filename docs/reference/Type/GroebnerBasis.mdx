# GroebnerBasis

**GroebnerBasis  -- the class of all Gröbner bases**

## Description

 A Gröbner basis in Macaulay2 consists of a Gröbner basis computation and several associated matrices. Normally you don't need to refer to these objects directly as many operations on matrices and modules create them and refer to them.  For more information see [Gröbner bases](../Instance/Gröbner bases.mdx) .
