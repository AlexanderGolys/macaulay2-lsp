# Package

**Package  -- the class of all packages**

## Description

See [packages](../Instance/packages.mdx) for an overview about using and writing Macaulay2 packages.Available packages:
- Macaulay2Doc:: packages provided with Macaulay2
- The directory containing the packages is common/share/Macaulay2/ common/share/Macaulay2/

Functions useful when [using packages](../Instance/using packages.mdx):
- Macaulay2Doc:: needsPackage
- Macaulay2Doc:: loadPackage
- Macaulay2Doc:: installPackage
- Macaulay2Doc:: check
- Macaulay2Doc:: debug
- Macaulay2Doc:: importFrom

Functions useful when [creating a package](../Instance/creating a package.mdx):
- Macaulay2Doc:: newPackage
- Macaulay2Doc:: export
- Macaulay2Doc:: exportMutable
- Macaulay2Doc:: beginDocumentation
- Macaulay2Doc:: document
- Macaulay2Doc:: TEST

Functions useful when debugging a package:
- Macaulay2Doc:: debugging
- Macaulay2Doc:: debug
- Macaulay2Doc:: check

Functions that are only rarely used:
- Macaulay2Doc:: use
- Macaulay2Doc:: dismiss
- Macaulay2Doc:: exportFrom
- Macaulay2Doc:: endPackage
- Macaulay2Doc:: readPackage
- Macaulay2Doc:: uninstallPackage
- Macaulay2Doc:: makePackageIndex
- Macaulay2Doc:: loadedPackages
