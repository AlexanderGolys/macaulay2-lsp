# WrapperType

**WrapperType  -- a class of lists with abbreviated constructors**

## Description

 These are the types `X`  of lists that can be constructed by expressions of the form `abc...`  or for lists of length one by an expression of the form `X a` .  They also act on sequences.

## Examples

```macaulay2
X = new WrapperType of BasicList

```
