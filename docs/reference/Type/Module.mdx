# Module

**Module  -- the class of all modules**

## Description

 For basic information about modules in *Macaulay2*  see [modules](../Instance/modules.mdx) . Common ways to make a module:
- Macaulay2Doc:: Ring ^ ZZ
- Macaulay2Doc:: Ring ^ List
- Macaulay2Doc:: cokernel(Matrix)
- Macaulay2Doc:: image(Matrix)
- Macaulay2Doc:: kernel(Matrix)

 Common ways to get information about modules:
- Macaulay2Doc:: ring(Module)
- Macaulay2Doc:: numgens(Module)
- Macaulay2Doc:: degrees(Module)
- Macaulay2Doc:: generators(Module)
- Macaulay2Doc:: relations(Module)
- Macaulay2Doc:: isFreeModule
- Macaulay2Doc:: isHomogeneous(Module)

 Numerical information about a module:
- Macaulay2Doc:: codim(Module)
- Macaulay2Doc:: dim(Module)
- Macaulay2Doc:: rank(Module)

 Submodules quotients and subquotient modules:
- Macaulay2Doc:: ambient(Module)
- Macaulay2Doc:: cover(Module)
- Macaulay2Doc:: super(Module)
- Macaulay2Doc:: Module / Module
- Macaulay2Doc:: subquotient(MatrixMatrix)
- Macaulay2Doc:: isSubset(ModuleModule)

 Common operations on modules:
- Macaulay2Doc:: Module + Module
- Macaulay2Doc:: Module == Module
- Macaulay2Doc:: Module ++ Module
- Macaulay2Doc:: Module ^ List
- Macaulay2Doc:: Module ** Module
- Macaulay2Doc:: Module ^** ZZ
- Macaulay2Doc:: Module _ List

 Minimalization:
- Macaulay2Doc:: mingens(Module)
- Macaulay2Doc:: trim(Module)
- Macaulay2Doc:: minimalPresentation(Module)

 Graded modules:
- Macaulay2Doc:: basis
- Truncations:: truncate(ZZModule)
- Macaulay2Doc:: degree(Module)
- Varieties:: genera(Module)
- Macaulay2Doc:: hilbertSeries(Module)
- Macaulay2Doc:: hilbertFunction(ZZModule)
- Macaulay2Doc:: poincare(Module)
- Macaulay2Doc:: regularity(Module)

 Annihilators quotients and Gröbner bases:
- Macaulay2Doc:: gb(Module)
- Saturation:: Ideal: Ideal
- Saturation:: annihilator(Module)
- Saturation:: saturate(ModuleIdeal)

 Common homological computations:
- OldChainComplexes:: resolution(Module)
- Macaulay2Doc:: pdim(Module)
- Macaulay2Doc:: Hom
- Macaulay2Doc:: homomorphism(Matrix)
- Macaulay2Doc:: Ext^ZZ(ModuleModule)
- Macaulay2Doc:: Tor_ZZ(ModuleModule)
- Macaulay2Doc:: HH^ZZ Module
- Macaulay2Doc:: homology(MatrixMatrix)
- Macaulay2Doc:: fittingIdeal(ZZModule)

 Multilinear algebra:
- Macaulay2Doc:: exteriorPower(ZZModule)
