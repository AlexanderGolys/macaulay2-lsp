# Power

**Power  -- the class of all power expressions**

## Description

`Power`  is a type of [Expression](../Type/op_Coredollar_Expression.mdx)  representing a power. Normally power expressions with an exponent equal to 1 will not be produced.  But it is desirable for [factor](../Method/factor.mdx)  to return a product of powers and some of them will have 1 as exponent.  The routines for printing of expressions will take this into account suppress exponents equal to 1 and arrange for parenthesization correctly.
