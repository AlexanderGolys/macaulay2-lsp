# MatrixExpression

**MatrixExpression  -- the class of all matrix expressions**

## Description

`MatrixExpression`  is a type of [Expression](../Type/op_Coredollar_Expression.mdx)  representing a matrix.

## Examples

MatrixExpression {{a,b,c},{a,bb,ccc}}

```

     | a bb ccc |

```

MatrixExpression append(applyTable({{x^2-y^2,x^3-y^3},{x^2-4*y^2,x^3+y^3}}factor)
