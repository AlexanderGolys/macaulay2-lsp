# MutableMatrix

**MutableMatrix  -- the class of all mutable matrices**

## Description

 A mutable matrix in Macaulay2 is a rectangular array of elements of a specific ring whose entries can be modified. A mutable matrix is different from a [Matrix](../Type/op_Coredollar_Matrix.mdx)  in that a matrix contains degree information for the target and source of the matrix while a mutable matrix has no such information.  Also more operations are provided for matrices. For an overview of mutable matrices see [mutable matrices](../Instance/mutable matrices.mdx) . Mutable matrices can either be encoded in a sparse manner (the matrix only encodes the non-zero elements) or in a dense manner (all elements are stored -- even zeros).  The distinction is an option to several of the routines that create mutable matrices ([mutableMatrix](../Method/op_Coredollar_mutableMatrix.mdx)  [mutableIdentity](../Method/op_Coredollar_mutableIdentity.mdx) ). Certain operations over RR or CC are performed using the LAPACK library and require dense encoding of matrices: [LUdecomposition](../Method/LUdecomposition.mdx)  [SVD](../Method/op_Coredollar_SVD.mdx)  [solve](../Method/op_Coredollar_solve.mdx)  [eigenvalues](../Method/eigenvalues.mdx)  [eigenvectors](../Method/eigenvectors.mdx) .
#### row and column operations


- Macaulay2Doc:: rowAdd
- Macaulay2Doc:: rowSwap
- Macaulay2Doc:: rowPermute
- Macaulay2Doc:: rowMult
- Macaulay2Doc:: columnAdd
- Macaulay2Doc:: columnSwap
- Macaulay2Doc:: columnPermute
- Macaulay2Doc:: columnMult


#### matrix arithmetic

 Many matrix arithmetic routines are only available for immutable matrices not mutable matrices.  It is necessary to use [matrix](../Method/matrix.mdx)  to make an immutable matrix first.
