# NumberedVerticalList

**NumberedVerticalList  -- a type of visible self-initializing list that prints vertically**

## Description

 All operations on lists apply to numbered vertical lists since they inherit from the type [VisibleList](../Type/VisibleList.mdx) .  The only difference is the way that a numbered vertical list is displayed vertically with index numbers labelling the entries. One may get a normal list back from a vertical list as follows.

## Examples

```macaulay2
NumberedVerticalList x
```

## Additional Information

- Inputs:
- `x` a [ list](../Type/op_Coredollar_List.mdx)
- Outputs:
- a [ numbered vertical list](../Type/NumberedVerticalList.mdx)
