# TestInput

**TestInput  -- locate a package's tests**

## Description

When an integer is not provided this returns all the tests for the given package.  The position of each element would be passed as the first argument of [check](../Method/op_Coredollar_check.mdx) to run the test. Each value is a `TestInput` object.  These are printed with the location of the file so that you may quickly jump to the source code of the test when using Emacs.If the test number is also provided then the corresponding `TestInput` object is returned.The [locate](../Method/op_Coredollar_locate.mdx) and [code](../Method/op_Coredollar_code.mdx) functions do the expected thing when given a `TestInput` object.Passing only the key of the desired test to [code](../Method/op_Coredollar_code.mdx) is supported as well.You may also pass a `TestInput` object to [edit](../Instance/op_Coredollar_edit.mdx) to open the code in your favorite editor.

## Examples

```macaulay2
tests pkg
tests(i pkg)
```

## Additional Information

- Inputs:
- `i` an [ integer](../Type/ZZ.mdx)
- `pkg` a [ package](../Type/op_Coredollar_Package.mdx) or a [ string](../Type/op_Coredollar_String.mdx)
- Outputs:
- a [ numbered vertical list](../Type/NumberedVerticalList.mdx) or a [ test input](../Type/op_Coredollar_TestInput.mdx)
