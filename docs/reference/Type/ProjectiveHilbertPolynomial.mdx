# ProjectiveHilbertPolynomial

**ProjectiveHilbertPolynomial  -- the class of all Hilbert polynomials**

## Description

 For convenience these polynomials are expressed in terms of the Hilbert polynomials of projective space. The functions [degree](../Method/op_Coredollar_degree.mdx)  and [dim](../Method/op_Coredollar_dim.mdx)  are designed so they correspond the degree and dimension of the algebraic variety that may have been used to produce the Hilbert polynomial.
