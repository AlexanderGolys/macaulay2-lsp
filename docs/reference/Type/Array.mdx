# Array

**Array  -- the class of all arrays -- [...]**

## Description

An array can be created by enclosing elements of any type in brackets.To convert arrays to and from other types of [BasicList](../Type/op_Coredollar_BasicList.mdx)  one may use [new](../Method/op_Coredollar_new.mdx) .For an overview of lists and sequences see [lists and sequences](../Instance/lists and sequences.mdx) .

## Examples

```macaulay2
new Array from {a,b,c}

```

```text
[a b c]

Array
```
