# AngleBarList

**AngleBarList  -- the class of lists delimited by <| ... |>**

## Description

An angle bar list can be created by enclosing elements of any type between angle bars.To convert angle bar lists to and from other types of [BasicList](../Type/op_Coredollar_BasicList.mdx)  one may use [new](../Method/op_Coredollar_new.mdx) .For an overview of lists and sequences see [lists and sequences](../Instance/lists and sequences.mdx) .

## Examples

```macaulay2
new AngleBarList from {a,b,c}

```

```text
<|a b c|>

AngleBarList
```
