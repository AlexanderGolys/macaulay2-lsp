# Eliminate

**Eliminate  -- elimination order**

## Description

 The option ``  is a shortcut for ``  The remaining variables are given weight 0. The monomial order is the elimination order eliminating the first n variables refined by the graded reverse lexicographic order. This order enables intersections with the subring consisting of all but the first 3 variables. For this use the command [selectInSubring](../Method/selectInSubring.mdx) . Eliminate may be combined with block orders as well. In the last example the order is block order: the first four variables are in the first block the subsequent two variables are in the second block the remaining variables are in the third block and the weights of the variables are 1110... 0.
