# Manipulator

**Manipulator  -- the class of all file manipulators**

## Description

 A file manipulator is a type of list that when put out to a file with [<<](../Method/op_Coredollar_lt_lt.mdx)  causes a chosen function to be applied to the file.  Alternatively a manipulator can be used the way a function is used.

## Examples

```macaulay2
f = new Manipulator from identity

```

```text
f

Manipulator
```
