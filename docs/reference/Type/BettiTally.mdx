# BettiTally

**BettiTally  -- the class of all Betti tallies**

## Description

A Betti tally is a special type of [Tally](../Type/Tally.mdx) that is printed as a display of graded Betti numbers. The class was created so the function [betti](../Method/op_Coredollar_betti.mdx) could return something that both prints nicely and from which information can be extracted.  The keys are triples `(idh)` encoding:`i` the column labels representing the homological degree;`d` a list of integers giving a multidegree; and`h` the row labels representing the dot product of a weight covector and `d`.Only `i` and `h` are used in printing and the weight covector can be modified by specifying the [betti(...](../Instance/betti(....mdx) option to [betti(BettiTally)](../Instance/betti(BettiTally).mdx).For convenience the operations of direct sum ([++](../Method/op_Coredollar_plus_plus.mdx)) tensor product ([**](../Method/op_Coredollar_star_star.mdx))[codim](../Method/op_Coredollar_codim.mdx)[degree](../Method/op_Coredollar_degree.mdx)[dual](../Method/dual.mdx)[pdim](../Method/op_Coredollar_pdim.mdx)[poincare](../Method/op_Coredollar_poincare.mdx)[regularity](../Method/op_Coredollar_regularity.mdx) and degree shifting (numbers in brackets or parentheses) have been implemented for Betti tallies.  These operations mimic the corresponding operations on chain complexes.If the Betti tally represents the Betti numbers of a resolution of a module $M$ on a polynomial ring $R = K[x_0...x_n]$ then while the data does not uniquely determine $M$ it suffices to compute the [ Hilbert polynomial](../Method/hilbertPolynomial.mdx) and [ Hilbert series](../Method/op_Coredollar_hilbertSeries.mdx) of $M$.A Betti tally can be multiplied by an integer or by a rational number and the values can be lifted to integers when possible.
