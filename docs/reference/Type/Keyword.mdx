# Keyword

**Keyword  -- the class of all keywords**

## Description

Keywords are symbols that are treated specially by the system while parsing user input.  Some of them such as [and](../Method/and.mdx)  consist of alphanumeric characters and look just like ordinary symbols.  Others such as [](../Instance/.mdx)  consist of special characters and are called operators.
