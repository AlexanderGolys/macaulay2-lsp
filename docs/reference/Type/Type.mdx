# Type

**Type  -- the class of all mutable types**

## Description

 Everything in the system is classified and the class that a thing belongs to is a type.  A type is implemented as a [ mutable hash table](../Type/MutableHashTable.mdx)  containing method functions for its instances. The list of types known to the system is displayed below.
