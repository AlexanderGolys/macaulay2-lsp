# List

**List  -- the class of all lists -- {...}**

## Description

 Lists in Macaulay2 consist of elements of any type enclosed in braces and separated by commas. The length of a list has two notations the version with the `#`  is faster when writing programs. The first entry of the list has index 0.  Indexing is performed using [#](../Method/op_Coredollar_hash.mdx) .Lists in Macaulay2 are immutable. See [MutableList](../Type/op_Coredollar_MutableList.mdx)  for making and using lists that you may modify.To convert lists to and from other types of [BasicList](../Type/op_Coredollar_BasicList.mdx)  in addition to [toList](../Method/toList.mdx)  one may use [new](../Method/op_Coredollar_new.mdx) .For an overview of lists and sequences see [lists and sequences](../Instance/lists and sequences.mdx) .

## Examples

```macaulay2
new List from [abc]

```

```text
{a, b, c}

List
```
