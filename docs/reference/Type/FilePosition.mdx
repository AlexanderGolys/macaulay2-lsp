# FilePosition

**FilePosition  -- the class of all file positions**

## Description

`FilePosition`  -- a type of list designed to represent a position in a file. It's implemented as a list with 3 5 or 7 elements. The first part is the file name then each pair is a row/column position. A single pair is a position two form a range. The last pair is the central point of interest in that range.
