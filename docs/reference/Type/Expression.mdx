# Expression

**Expression  -- the class of all expressions**

## Description

 An *expression*  is a symbolic representation of a mathematical expression.  It retains some of the semantics of the mathematical expression as well as enough information to print the expression nicely.  In Macaulay2 expressions have two main functions: they are an intermediate phase in the conversion of a mathematical object to a [net](../Method/op_Coredollar_net.mdx)  that can be printed; and they are a way of holding and displaying a mathematical expression in an unevaluated form that can be both printed and evaluated. Internally each expression is a basic list whose elements may also be expressions.  The elements that are not expressions are interpreted as themselves and may be strings symbols numbers etc.  There are several types of expression that correspond to various sorts of mathematical entities such as sums of class [Sum](../Type/op_Coredollar_Sum.mdx)  products of class [Product](../Type/op_Coredollar_Product.mdx)  fractions of class [Divide](../Type/op_Coredollar_Divide.mdx)  etc. Expressions are produced with the function [expression](../Method/op_Coredollar_expression.mdx) .  The various methods installed for it try to bring as much of the semantic structure of the mathematical object to light.  The following examples illustrate that using [peek](../Function/op_Coredollar_peek.mdx)  and [peek'](../Method/peekprime.mdx)  to display the internal structure. The function [factor](../Method/factor.mdx)  returns an expression. Expressions can be evaluated using [value](../Method/value.mdx) . The following operators can be applied to expressions: [SPACE](../Method/SPACE.mdx)  [*](../Method/op_Coredollar_star.mdx)  [**](../Method/op_Coredollar_star_star.mdx)  [+](../Method/op_Coredollar_plus.mdx)  [-](../Method/op_Coredollar_minus.mdx)  [/](../Method/op_Coredollar_slash.mdx)  [==](../Method/op_Coredollar_eq_eq.mdx)  [^](../Method/op_Coredollar_caret.mdx)  and [_](../Method/op_Coredollar_underscore.mdx) .  They are contagious in the sense that when applied to an expression and a non-expression the non-expression will be converted to an expression and the operator will be applied.  Only the most trivial algebraic simplifications are applied.
