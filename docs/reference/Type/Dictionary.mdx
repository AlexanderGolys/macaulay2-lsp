# Dictionary

**Dictionary  -- the class of all dictionaries**

## Description

 A dictionary is a special sort of hash table whose keys are the strings and whose values are the corresponding symbols.

## Examples

```macaulay2
Core.Dictionary # "sin"

```

```text
sin

Symbol
```

```macaulay2
Core.Dictionary #? "sin"

```

```text
true
```
