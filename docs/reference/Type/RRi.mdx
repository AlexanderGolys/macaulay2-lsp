# RRi

**RRi  -- the class of all real intervals**

## Description

 A real interval is entered as a pair of real numbers to the interval function.  It is stored internally as an arbitrary precision interval using the [MPFI](../Instance/MPFI.mdx)  library. The precision is measured in bits is visible in the ring displayed on the second of each pair of output lines and can be recovered using [precision](../Method/op_Coredollar_precision.mdx) . For real intervals the functions [class](../Function/op_Coredollar_class.mdx)  and [ring](../Method/op_Coredollar_ring.mdx)  yield different results.  That allows numbers of various precisions to be used without creating a new ring for each precision. The precision can be specified on input by specifying the precision of both input [RR](../Type/op_x226_x132_x157.mdx)  numbers. Alternatively the precision can be specified by including the option `Precision` . Intervals can also be created using [span(Sequence)](../Instance/span(Sequence).mdx)  to create the smallest interval containing the inputs. Operations using intervals are computed as sets so that the resulting intervals contain all possible outputs from pairs of points in input intervals. The notion of equality tested by [==](../Method/op_Coredollar_eq_eq.mdx)  amounts to checking the equality of the endpoints of intervals. The notion of equality tested by [===](../Method/op_Coredollar_eq_eq_eq.mdx)  takes into account the precision of the inputs as well. The notion of inequalities for intervals amounts to testing the inequality for all points in the intervals.  In particular [<=](../Method/op_Coredollar_lt_eq.mdx)  is not the same as [<](../Method/op_Coredollar_lt.mdx)  or [==](../Method/op_Coredollar_eq_eq.mdx) . Transcendental functions on intervals produce intervals containing the image of the function on the interval. Transcendental functions are available to high precision with [numericInterval](../Method/numericInterval.mdx) .
