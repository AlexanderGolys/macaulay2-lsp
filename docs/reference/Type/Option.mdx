# Option

**Option**

## Description

Such pairs are used as optional arguments for functions.There is also a way to make new [ hash tables](../Type/op_Coredollar_HashTable.mdx) from lists of key-value pairs.These pairs are implemented as lists so that if `z`  is ``  then `x`  is `z#0`  and `y`  is `z#1` .
