# showUserStructure

**showUserStructure  -- show parent structure for those types defined by user**

**Type:** [Command](../Type/Command.mdx)

## Description

Each type is displayed to the right of its parent.A type is an instance of the class [Type](../Type/op_Coredollar_Type.mdx) .

## Examples

```macaulay2
showUserStructure
```

```macaulay2
showUserStructure

```

```text
Thing : BasicList : RingElement : R
                         VisibleList : List : X : Y
                                                  Z

Descent
```

## Additional Information

- Outputs:
- a display of the parent structure of the types defined by the user and assigned to global variables
