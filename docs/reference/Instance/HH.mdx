# HH

**HH  -- general homology and cohomology functor**

**Type:** [ScriptedFunctor](../Type/ScriptedFunctor.mdx)

## Description

`HH`  is a [ScriptedFunctor](../Type/ScriptedFunctor.mdx)  which serves as an interface to the methods for [homology](../Method/homology.mdx)  and [cohomology](../Method/cohomology.mdx)  in the sense that `HH_i(M)`  is an abbreviation for `homology(iM)`  `HH^i(M)`  is an abbreviation for `cohomology(iM)`  and `HH(M)`  is an abbreviation for `homology(M)` . A second argument and optional arguments may be added.
