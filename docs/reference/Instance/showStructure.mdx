# showStructure

**showStructure  -- display parent structure**

**Type:** [Command](../Type/Command.mdx)

## Description


### Synopsis


- Outputs:
- a display of the parent structure of all types assigned to global variables


### Synopsis


- Inputs:
- `X` a [ type](../Type/op_Coredollar_Type.mdx)
- `Y` a [ type](../Type/op_Coredollar_Type.mdx)
- Outputs:
- a display of the class structure of the types specified

Each such type is displayed to the right of its [parent](../Function/op_Coredollar_parent.mdx) .A type is an instance of [Type](../Type/op_Coredollar_Type.mdx)  by definition.
