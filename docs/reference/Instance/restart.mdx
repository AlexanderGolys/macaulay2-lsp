# restart

**restart  -- restart Macaulay2**

**Type:** [Command](../Type/Command.mdx)

## Description

Functions previously registered with [addEndFunction](../Function/op_Coredollar_addEndFunction.mdx)  will be called before the current instance of the program terminates.  Then the program will be invoked afresh as described in [invoking the Macaulay2 program](../Instance/invoking the Macaulay2 program.mdx) .

## Examples

```macaulay2
restart
```

## Additional Information

- Consequences:
- the program will be restarted from the beginning
