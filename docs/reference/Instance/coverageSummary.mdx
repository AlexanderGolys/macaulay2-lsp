# coverageSummary

**coverageSummary  -- profile a computation**

**Type:** [Command](../Type/Command.mdx)

## Description

Running a computation with the `profile` keyword enables the Macaulay2 profiler which measures and stores the frequency of particular instructions for aid in analyzing and optimizing the computation.Afterwards running `profileSummary` and `coverageSummary` produces easy to read tables summarizing the accumulated data so far in different ways.

## Examples

```macaulay2
profile f()
profileSummary f
coverageSummary f
```

```macaulay2
coverageSummary

```
