# stdio

**stdio  -- the standard input output file**

**Type:** [File](../Type/File.mdx)

## Description

Use this file to get input from the terminal or to display information on the user's screen.  This is the file always used by [print](../Function/print.mdx)  and [<<](../Method/op_Coredollar_lt_lt.mdx)  if it is not explicitly given a file.

## Examples

```macaulay2
stdio
```

```macaulay2
stdio << "hi" << endl
hi

```

```text
stdio

File
```
