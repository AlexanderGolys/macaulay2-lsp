# exit

**exit  -- exit the program**

**Type:** [Command](../Type/Command.mdx)

## Description

`exit n`  -- terminates the program and returns `n`  as return code.`exit`  -- terminates the program and returns 0 as return code. Files are flushed and closed.  Functions registered with [addEndFunction](../Function/op_Coredollar_addEndFunction.mdx)  are called unless a nonzero return value has been provided.  Another way to exit is to type the end of file character which is typically set to Control-D in unix systems and is Control-Z under Windows.
