# quit

**quit  -- quit the program**

**Type:** [Command](../Type/Command.mdx)

## Description

`quit`  -- terminates the program and returns 0 as return code. Files are flushed and closed.  Another way to exit is to type the end of file character which is typically set to Control-D in unix systems and is Control-Z under MS-DOS.
