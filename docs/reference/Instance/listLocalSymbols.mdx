# listLocalSymbols

**listLocalSymbols  -- display of local symbols and their values**

**Type:** [Command](../Type/Command.mdx)

## Description


### Synopsis


- Inputs:
- `f` an instance of the type [PseudocodeClosure](../Type/PseudocodeClosure.mdx) a [ symbol](../Type/op_Coredollar_Symbol.mdx) a [ dictionary](../Type/op_Coredollar_Dictionary.mdx) or a [ function](../Type/Function.mdx)
- Outputs:
- a [ net](../Type/op_Coredollar_Net.mdx) a compact display of the symbols in the local dictionaries attached to the closure `f` and their values


### Synopsis


- Outputs:
- a [ net](../Type/op_Coredollar_Net.mdx) a compact display of the symbols in the local dictionaries attached to [current](../Instance/current.mdx)

This usage works only in the debugger where [current](../Instance/current.mdx)  has a non-null value.
### Synopsis


- Inputs:
- `X` a [ type](../Type/op_Coredollar_Type.mdx)
- `f` an instance of the type [PseudocodeClosure](../Type/PseudocodeClosure.mdx) a [ symbol](../Type/op_Coredollar_Symbol.mdx) a [ dictionary](../Type/op_Coredollar_Dictionary.mdx) or a [ function](../Type/Function.mdx)
- Outputs:
- a [ net](../Type/op_Coredollar_Net.mdx) a compact display of the symbols in the local dictionaries attached to the closure `f` and their values provided their values are instances of the type `X`


### Synopsis


- Outputs:
- a [ net](../Type/op_Coredollar_Net.mdx) a compact display of the symbols in the local dictionaries attached to [current](../Instance/current.mdx) whose values have type `X`.

This usage works only in the debugger where [current](../Instance/current.mdx)  has a non-null value.
