# closeOut

**closeOut  -- close an output file**

**Type:** [Manipulator](../Type/Manipulator.mdx)

## Description

`f << closeOut`  -- closes the output file `f` .`closeOut f`  -- closes the output file `f` . Any buffered output is first written to the file and the return value is an integer normally 0 or -1 on error or the return status of the child process in case the file was a pipe. If the file was open only for output then [close](../Instance/close.mdx)  is easier to use and has the same effect. If the file was open for both input and output it remains open for input.
