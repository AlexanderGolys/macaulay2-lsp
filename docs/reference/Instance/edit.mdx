### Synopsis


- Inputs:
- `f` a [ function](../Type/Function.mdx) or a [ keyword](../Type/op_Coredollar_Keyword.mdx)
- `X` a [ type](../Type/op_Coredollar_Type.mdx)
- `Y` a [ type](../Type/op_Coredollar_Type.mdx)

- `T` a [ type](../Type/op_Coredollar_Type.mdx)

The name of the user's preferred editor is take from the environment variable `EDITOR` .  If X is running and the editor is not Emacs then the editor is started in a new `xterm`  window.For an interactive example try `edit(dimModule)` .The value returned is the exit code returned by the editor as with [run](../Function/run.mdx)  usually zero.
