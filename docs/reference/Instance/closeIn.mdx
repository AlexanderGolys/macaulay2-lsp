# closeIn

**closeIn  -- close an input file**

**Type:** [Manipulator](../Type/Manipulator.mdx)

## Description

`f << closeIn`  -- closes the input file `f` .`closeIn f`  -- closes the input file `f` . If the file was open only for input then [close](../Instance/close.mdx)  is easier to use and has the same effect. If the file was open for both input and output it remains open for output.
