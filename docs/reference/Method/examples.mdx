# examples

**examples  -- list the examples in documentation**

**Type:** [MethodFunctionSingle](../Type/MethodFunctionSingle.mdx)

## Description

The output is returned as a [Net](../Type/op_Coredollar_Net.mdx) of height 0 so the examples will be displayed indented by just white space allowing immediate entry.Alternatively one could use [print](../Function/print.mdx) to display them with no indentation.If the input is an integer then the examples will correspond to the documentation node with that index in the last call to [about](../Method/op_Coredollar_about.mdx).If the input is a list then the examples for all of its elements will be gathered into a single net.

```macaulay2
examples s
```

## Additional Information

- Inputs:
- `s` a [ thing](../Type/Thing.mdx) a descriptor for a documentation node acceptable by [makeDocumentTag](../Method/makeDocumentTag.mdx)
- Outputs:
- a [ net](../Type/op_Coredollar_Net.mdx) containing examples of code provided in the documentation of `s`
