# toField

**toField  -- declare that a ring is a field**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

If the engine eventually discovers that some nonzero element of `L`  is not a unit an error will be signalled.  The user may then use [getNonUnit](../Function/op_Coredollar_getNonUnit.mdx)  to obtain a non-invertible element of `L` . If a ring probably is a field it can be used as a field until a contradiction is found and this may be a good way of discovering whether a ring is a field.

## Additional Information

- Inputs:
- `R` a [ ring](../Type/Ring.mdx)
- Outputs:
- `L` a new ring isomorphic to `R` declared to be a field. Polynomial rings over it will support Gröbner basis operations.
