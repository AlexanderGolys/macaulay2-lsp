# scanValues

**scanValues  -- apply a function to each value in a hash table or database**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

`scanValues(t f)`  applies the function `f`  to each value in the hash table `t` .

## Installed For

### scanValues([HashTable](../Type/HashTable.mdx), [Function](../Type/Function.mdx))

## Examples

```macaulay2
scanValues(t f)
```

```macaulay2
scanValues(t print)
8
20
4
20
```

```macaulay2
scanValues(t v -> if v>10 then print v)
20
20
```

## Additional Information

- Inputs:
- `t` a [ hash table](../Type/op_Coredollar_HashTable.mdx)
- `f` a [ function](../Type/Function.mdx)


### Caveat

This function requires an immutable hash table.  To scan the values in a mutable hash table use `scan(values t f)` .
