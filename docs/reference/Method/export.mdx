# export

**export  -- export symbols from a package**

**Type:** [MethodFunctionSingle](../Type/MethodFunctionSingle.mdx)

## Description

A package can contain the code for many functions only some of which should be made visible to the user. The function `export` allows one to specify which symbols are to be made visible. For an example see [an example of a package](../Instance/an example of a package.mdx).No single-letter symbol should be exported since such symbols are reserved as variables for the user.Use [exportMutable](../Method/op_Coredollar_exportMutable.mdx) to export symbols whose values the user is permitted to modify.Use [importFrom](../Method/op_Coredollar_importFrom.mdx) to import private symbols of a package.

## Additional Information

- Inputs:
- a [ list](../Type/op_Coredollar_List.mdx) containing strings or options with string keys and values belonging to the package
- Outputs:
- a [ list](../Type/op_Coredollar_List.mdx) the list of exported symbols
- Consequences:
- the symbols whose names are in the list as strings which should refer to functions or other symbols defined in the package are made available to the user of the package and are marked non-mutable. The strings are converted to symbols with those names in the dictionary of the package. An option of the form `` creates a symbol with the name `name` that is a synonym of the symbol `symbol`.
