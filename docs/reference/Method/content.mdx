# content

**content  -- the content of a polynomial**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

The content is the ideal in the base ring generated by the coefficients.

## Installed For

### content([RingElement](../Type/RingElement.mdx))

### content([RingElement](../Type/RingElement.mdx), [RingElement](../Type/RingElement.mdx)) -> [Ideal](../Type/Ideal.mdx)

## Examples

```macaulay2
content f
content(f x)
```

```macaulay2
content(4*x + 6*x^5)

```

```text
ideal (6 4)

Ideal of ZZ
```

```macaulay2
content(4*x + 6*x^5 x)

```

```text
ideal (6 4)

Ideal of R
```

```macaulay2
content(4*x + 6*x^5 y)

             5
```

```text
ideal(6x  + 4x)

Ideal of R
```

## Additional Information

- Inputs:
- `f` a [ ring element](../Type/RingElement.mdx)
- `x` a [ ring element](../Type/RingElement.mdx) a variable in the ring of `f`
- Outputs:
- an [ ideal](../Type/op_Coredollar_Ideal.mdx) the content of a matrix or polynomial
