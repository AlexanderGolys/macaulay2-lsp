# genericMatrix

**genericMatrix  -- make a generic matrix of variables**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

 Omitting the input `r`  is the same as having `r`  be the first variable in `R` .

## Installed For

### genericMatrix([Ring](../Type/Ring.mdx), [RingElement](../Type/RingElement.mdx), [ZZ](../Type/ZZ.mdx), [ZZ](../Type/ZZ.mdx)) -> [Matrix](../Type/Matrix.mdx)

## Additional Information

- Inputs:
- `R` a [ ring](../Type/Ring.mdx)
- `r` a [ ring element](../Type/RingElement.mdx) which is a variable in the ring `R` (this input is optional)
- `m` an [ integer](../Type/ZZ.mdx)
- `n` an [ integer](../Type/ZZ.mdx)
- Outputs:
- a [ matrix](../Type/op_Coredollar_Matrix.mdx) with `m` rows and `n` columns whose entries are variables in the ring `R` starting with `r`
