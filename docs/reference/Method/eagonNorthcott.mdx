# eagonNorthcott

**eagonNorthcott  -- Eagon-Northcott complex of a matrix of linear forms**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

 The Eagon-Northcott complex is an explicit chain complex that gives a minimal projective resolution of the cokernel of the matrix maximal minors of a generic matrix of linear forms. This function was written by Greg Smith.

### eagonNorthcott([Matrix](../Type/Matrix.mdx))
