# texMath

**texMath  -- convert to TeX math format**

**Type:** [MethodFunctionSingle](../Type/MethodFunctionSingle.mdx)

## Description

 The main difference between this and [tex](../Method/op_Coredollar_tex.mdx)  is that the surrounding dollar signs aren't there.

## Examples

```macaulay2
texMath x
```

```macaulay2
texMath (x-1)^6

```

```text
x^{6}-6\x^{5}+15\x^{4}-20\x^{3}+15\x^{2}-6\x+1
```

## Additional Information

- Inputs:
- `x` any Macaulay2 object
- Outputs:
- a [ string](../Type/op_Coredollar_String.mdx) `x` converted to TeX math format


### Caveat

 No attempt is made to wrap large matrices or equations.
