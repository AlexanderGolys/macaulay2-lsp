# isSubmodule

**isSubmodule  -- whether a module is evidently a submodule of a free module**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

 No computation is done -- `M`  may be a isomorphic to a submodule of a free  module although this function will not detect it.

## Installed For

### isSubmodule([Module](../Type/Module.mdx))

### isSubmodule([Thing](../Type/Thing.mdx))

## Examples

```macaulay2
isSubmodule M
```

```macaulay2
isSubmodule M

```

```text
true
```

```macaulay2
isSubmodule N

```

```text
true
```

```macaulay2
isSubmodule N'

```

```text
false
```

## Additional Information

- Inputs:
- `M` a [ thing](../Type/Thing.mdx)
- Outputs:
- [true](../Instance/op_Coredollar_true.mdx) if `M` is evidently a submodule of a free module and [false](../Instance/op_Coredollar_blockMatrixForm.mdx) otherwise
