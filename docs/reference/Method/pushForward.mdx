# pushForward

**pushForward  -- compute the pushforward of a module along a ring map**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

 Currently `R`  and `S`  must both be polynomial rings over the same base field. This function first checks to see whether M will be a finitely generated R-module via F.  If not an error message describing the codimension of M/(vars of S)M is given (this is equal to the dimension of R if and only if M is a finitely generated R-module. Assuming that it is the push forward `F_*(M)`  is computed.  This is done by first finding a presentation for `M`  in terms of a set of elements that generates `M`  as an `S` -module and then applying the routine [coimage](../Method/op_Coredollar_coimage.mdx)  to a map whose target is `M`  and whose source is a free module over `R` .
### Example: The Auslander-Buchsbaum formula

 Let's illustrate the Auslander-Buchsbaum formula. First construct some rings and make a module of projective dimension 2. Create ring maps. The module M when thought of as an R5 or R4 module has the same depth but since depth M + pdim M = dim ring the projective dimension will drop to 1 respectively 0 for these two rings.
### Example: generic projection of a homogeneous coordinate ring

 We compute the pushforward N of the homogeneous coordinate ring M of the twisted cubic curve in P^3. The result is a module with the same codimension degree and genus as the twisted cubic but the support is a cubic in the plane necessarily having one node. Note: these examples are from the original Macaulay script by David Eisenbud.

## Additional Information

- Inputs:
- `F` a [ ring map](../Type/op_Coredollar_RingMap.mdx) a ring map F: R --> S graded
- `M` a [ module](../Type/op_Coredollar_Module.mdx) over S graded
- [ Optional inputs](../Instance/using functions with optional inputs.mdx):
- `MonomialOrder````...` default value Eliminate the type of monomial ordering to use in the computation as keyword either [Eliminate](../Type/op_Coredollar_Eliminate.mdx) [ProductOrder](../Type/ProductOrder.mdx) or [Lex](../Method/op_Coredollar_Lex.mdx)
- `UseHilbertFunction```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value true whether to use the Hilbert function as a hint for the Gröbner basis computation if `M` and `F` are homogeneous
- `StopBeforeComputation```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value false see [gb(...](../Instance/gb(....mdx)
- `DegreeLimit```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value {} see [gb(...](../Instance/gb(....mdx)
- `PairLimit```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value infinity see [gb(...](../Instance/gb(....mdx)
- `Strategy````...` default value null
- Outputs:
- a [ module](../Type/op_Coredollar_Module.mdx) M considered as an R-module


### Caveat

 The module M must be homogeneous as must R S and f.  If you need this function in more general situations please write it and send it to the Macaulay2 authors or ask them to write it!
