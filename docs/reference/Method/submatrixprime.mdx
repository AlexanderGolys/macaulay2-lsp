# submatrix'

**submatrix'  -- exclude rows and/or columns of a matrix**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

 Each list of integers may contain ranges and repetitions as in `{3, 5..7, 3:0}` .  Excluding a row or column more than once is allowed but has no extra effect.

## Examples

```macaulay2
submatrix'(f rows cols)
submatrix'(fcols)
submatrix'(fcols)
submatrix'(frows)
```

## Additional Information

- Inputs:
- `f` a map between free modules
- `rows` a [ visible list](../Type/VisibleList.mdx) a list of integers denoting the choice of rows to exclude. If omitted exclude no rows
- `cols` a [ visible list](../Type/VisibleList.mdx) a list of integers denoting the choice of columns to exclude. If omitted exclude no columns
- Outputs:
- a [ matrix](../Type/op_Coredollar_Matrix.mdx) the submatrix of `f` with `rows` and `cols` left out
