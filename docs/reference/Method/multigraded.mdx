# multigraded

**multigraded  -- convert a Betti tally into a multigraded Betti tally**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

A multigraded Betti tally is a special type of [BettiTally](../Type/op_Coredollar_BettiTally.mdx) that both prints nicely and from which multigraded Betti numbers could be easily extracted.By changing the weights we can reorder the columns of the diagram. The following three displays show the first degree the second degree and the total degree respectively.

## Installed For

### multigraded([BettiTally](../Type/BettiTally.mdx)) -> [MultigradedBettiTally](../Type/MultigradedBettiTally.mdx)

## Examples

```macaulay2
multigraded t
```

```macaulay2
B = multigraded t

         0         1                   2                   3                   4
```

- Outputs:
