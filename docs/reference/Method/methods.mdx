# methods

**methods  -- list methods**

**Type:** [MethodFunctionSingle](../Type/MethodFunctionSingle.mdx)

## Description


### Synopsis


- Inputs:
- `x` a [ function](../Type/Function.mdx) a [ type](../Type/op_Coredollar_Type.mdx) a [ keyword](../Type/op_Coredollar_Keyword.mdx) or a [ package](../Type/op_Coredollar_Package.mdx)
- Outputs:
- a [ vertical list](../Type/VerticalList.mdx) of those methods associated with `x`


### Synopsis


- Inputs:
- `s` a [ symbol](../Type/op_Coredollar_Symbol.mdx)
- `X` a [ type](../Type/op_Coredollar_Type.mdx)
- Outputs:
- a [ vertical list](../Type/VerticalList.mdx) of those methods associated with the operator `s` and the type `X`


### Synopsis


- Inputs:
- `X` a [ type](../Type/op_Coredollar_Type.mdx)
- `Y` a [ type](../Type/op_Coredollar_Type.mdx)
- Outputs:
- a [ vertical list](../Type/VerticalList.mdx) of those methods associated with

 This function operates by examining those types that are values of global symbols for keys that appear to be storing references to methods.  Types that don't appear as values of global variables will not be examined so perhaps not all methods will be found.
