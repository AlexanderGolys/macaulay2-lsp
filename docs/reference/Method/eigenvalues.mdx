# eigenvalues

**eigenvalues  -- find eigenvalues of a matrix**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

 In this example we compute the eigenvalues of a matrix and display their classes. If the matrix is symmetric (over [RR](../Type/op_x226_x132_x157.mdx) ) or Hermitian (over [CC](../Type/op_x226_x132_x130.mdx) ) this information may be provided as an optional argument ``  so the resulting eigenvalues will be in [RR](../Type/op_x226_x132_x157.mdx)  not [CC](../Type/op_x226_x132_x130.mdx) . The LAPACK and Eigen libraries are used to compute eigenvectors of real and complex matrices.

## Additional Information

- Inputs:
- `M` a [ matrix](../Type/op_Coredollar_Matrix.mdx) or a [MutableMatrix](../Type/op_Coredollar_MutableMatrix.mdx) over [RR](../Type/op_x226_x132_x157.mdx) or [CC](../Type/op_x226_x132_x130.mdx) which is a square n by n matrix
- [ Optional inputs](../Instance/using functions with optional inputs.mdx):
- [](../Instance/eigenvalues(....mdx)```...` default value false whether to assume the matrix is symmetric or Hermitian
- Outputs:
- a [ vertical list](../Type/VerticalList.mdx) a list of the eigenvalues of `M`


### Caveat

 The eigenvalues are approximate.
