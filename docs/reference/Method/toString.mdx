# toString

**toString  -- convert to a string**

**Type:** [MethodFunctionSingle](../Type/MethodFunctionSingle.mdx)

## Description

 Sometimes the string representation is just the name. See also [toExternalString](../Method/op_Coredollar_toExternalString.mdx)  which will try to convert `x`  to a string that can be read back into the program later. If a ring has a global name then toString returns this name. Matrices and ring elements are linearized

## Examples

```macaulay2
toString x
```

```macaulay2
toString {1,4,a,f,212312,2.123243242}

```

```text
{1, 4, a, f, 212312, 2.12324}
```

```macaulay2
toString R

```

```text
R
```

```macaulay2
toString(QQ[a])

```

```text
QQ[a]
```

```macaulay2
toString (x_1^3-3/4*x_5*x_3)

```

```text
x_1^3-(3/4)*x_3*x_5
```

```macaulay2
toString vars R

```

```text
matrix {{x_1, x_2, x_3, x_4, x_5}}
```
