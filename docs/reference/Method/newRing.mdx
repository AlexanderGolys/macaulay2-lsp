# newRing

**newRing  -- make a copy of a ring with some features changed**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

If a different number of variables is given with [Variables](../Instance/Variables.mdx) then the list of degrees in `R` will be ignored.  If a new degree rank is specified with [DegreeRank](../Method/op_Coredollar_DegreeRank.mdx) then the list of degrees and the heft vector of `R` will be ignored.  If a new nonempty list of degrees is specified with [Degrees](../Method/op_Coredollar_Degrees.mdx) then the degree rank and the heft vector of `R` will be ignored.The default values for the options of `newRing` are all set to a non-accessible private symbol whose name is `nothing`.
