## Examples

```macaulay2
hooks key
hooks store
hooks(store key)
```

## Additional Information

- Inputs:
- `key` a [ sequence](../Type/Sequence.mdx) or a [ symbol](../Type/op_Coredollar_Symbol.mdx)
- `store` a [ hash table](../Type/op_Coredollar_HashTable.mdx) the hash table where the hooks are stored
- [ Optional inputs](../Instance/using functions with optional inputs.mdx):
- `Strategy```a [ thing](../Type/Thing.mdx) default value null only list hooks with the given strategy
- Outputs:
- a [ numbered vertical list](../Type/NumberedVerticalList.mdx) of those hooks associated with `key` or stored in `store`
