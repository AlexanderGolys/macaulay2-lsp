# generateAssertions

**generateAssertions  -- generate assert statements from experimental input**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

generateAssertions  -- generate assert statements from experimental input

## Installed For

### generateAssertions([List](../Type/List.mdx))

### generateAssertions([String](../Type/String.mdx))

## Examples

```macaulay2
generateAssertions x
```

```macaulay2
generateAssertions ///
     	2+2
     	2^20
     	///

```

```text

     assert( (       2+2) === 4 );
     assert( (       2^20) === 1048576 );
```

## Additional Information

- Inputs:
- `x` a string whose non-comment non-blank lines are Macaulay2 expressions to be evaluated
- Outputs:
- a net whose lines are assert statements that assert that the expressions evaluate to the expected value just computed
