# support

**support  -- list of variables occurring in a polynomial or matrix**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

 If the ring is a polynomial ring over another polynomial ring then the support contains all of the variables even the ones in the coefficient ring. The  ring of each of these is the ring of f. Here is one way to select only the top level variables. To obtain a list of the integer indices of the variables one can use either [indices(RingElement)](../Instance/indices(RingElement).mdx)  or apply [index](../Method/op_Coredollar_index.mdx)  to each variable.

## Additional Information

- Inputs:
- `f` a [ ring element](../Type/RingElement.mdx) or a [ matrix](../Type/op_Coredollar_Matrix.mdx) over a polynomial ring
- Outputs:
- a [ list](../Type/op_Coredollar_List.mdx) of [ ring elements](../Type/RingElement.mdx) the variables occurring in `f`
