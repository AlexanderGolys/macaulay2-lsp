# sqrt

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

sqrt  -- square root function

## Examples

```macaulay2
sqrt x
sqrt I
```

```macaulay2
sqrt 2p200

```

```text
1.41421356237309504880168872420969807856967187537694807317668

RR (of precision 200)
```

```macaulay2
sqrt (+ii)

```

```text
.7071067811865476+.7071067811865475*ii

CC (of precision 53)
```

## Additional Information

- Inputs:
- `x` a [ real number](../Type/op_x226_x132_x157.mdx)
- `I` a [ real interval](../Type/RRi.mdx)
- Outputs:
- the square root of `x`
- a [ real interval](../Type/RRi.mdx) an interval containing the square roots of the points of `I`
