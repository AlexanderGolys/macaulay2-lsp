# integrate

**integrate  -- numerical integration**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

Integrate `f` from `a` to `b` numerically using https://en.wikipedia.org/wiki/Gaussian_quadrature Gaussian quadrature.For half-infinite intervals 20-point https://en.wikipedia.org/wiki/Gauss-Laguerre_quadrature Gauss-Laguerre quadrature is used.For infinite intervals 20-point https://en.wikipedia.org/wiki/Gauss-Hermite_quadrature Gauss-Hermite quadrature is used.
