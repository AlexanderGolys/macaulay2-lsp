# Print

**Print  -- top level method for printing results**

**Type:** [Symbol](../Type/Symbol.mdx)

## Description

 The function `f`  is responsible for printing the output prompt and for applying the [BeforePrint](../Instance/BeforePrint.mdx)  and [AfterPrint](../Method/op_Coredollar_AfterPrint.mdx)  methods if desired.

## Examples

```macaulay2
X#{topLevelMode,Print} = f
```

## Additional Information

- Inputs:
- `X` a [ type](../Type/op_Coredollar_Type.mdx)
- `f` a [ function](../Type/Function.mdx) that can print something of type `X`
- Consequences:
- at top level whenever it is time to print an output value of type `X` the function `f` will be called
