# findFiles

**findFiles  -- find files recursively**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

findFiles  -- find files recursively

## Installed For

### findFiles([List](../Type/List.mdx))

### findFiles([String](../Type/String.mdx))

## Options

- [FollowLinks](../Option/FollowLinks.mdx) => false
- [Exclude](../Method/Exclude.mdx) => {}

## Examples

```macaulay2
findFiles p
```

## Additional Information

- Inputs:
- `p` a [ string](../Type/op_Coredollar_String.mdx) or a [ list](../Type/op_Coredollar_List.mdx) a directory or list of directories
- [ Optional inputs](../Instance/using functions with optional inputs.mdx):
- `Exclude````...` default value {} a list of strings regarded as regular expressions; files found whose paths have base filenames matching one of these regular expressions will be excluded from the results
- `FollowLinks```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value false whether to follow symbolic links to directories and to report on files found there
- Outputs:
- a list of paths to files found in the directory tree(s) rooted at the locations(s) specified by `p`
