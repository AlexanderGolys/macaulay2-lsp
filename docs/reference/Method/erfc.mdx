# erfc

**erfc  -- complementary error function**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

The complementary https://en.wikipedia.org/wiki/error_function error function \(\operatorname{erfc} x = \frac{2}{\sqrt\pi}\int_x^\infty e^{-t^2}\dt\).
