# numerator

**numerator  -- numerator of a fraction**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

`numerator`  also works with Hilbert series.For a Laurent polynomial in a ring with inverses of variables it gives the result after clearing all the denominators in each of the terms by multiplying by a suitable monomial.

## Installed For

### numerator([Divide](../Type/Divide.mdx))

### numerator([QQ](../Type/QQ.mdx))

## Examples

```macaulay2
numerator x
```

```macaulay2
numerator (4/6)

```

```text
2
```

```macaulay2
numerator((x+2*y-3)/(x-y))

```

```text
ZZ[x..y]
```

```text

ZZ[T]
```


```text
x*z  + y  + y*z  + z

R
```
