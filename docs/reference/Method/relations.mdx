# relations

**relations  -- the defining relations**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

`relations M`  -- produce the relations defining a module M. The relations are represented as a matrix and if not stored in the module under M.relations the matrix is understood to be empty.
