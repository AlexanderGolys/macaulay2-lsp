# span

**span  -- construct smallest interval**

**Type:** [MethodFunctionSingle](../Type/MethodFunctionSingle.mdx)

## Description

Returns the smallest interval containing the inputs (which can include intervals).  Typically the returned interval is not empty.  See [span(Sequence)](../Instance/span(Sequence).mdx) and [span(List)](../Instance/span(List).mdx)
