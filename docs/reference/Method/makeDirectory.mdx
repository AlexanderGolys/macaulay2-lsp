# makeDirectory

**makeDirectory  -- make a directory**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

A filename starting with `~/`  will have the tilde replaced by the home directory.

## Installed For

### makeDirectory([String](../Type/String.mdx)) -> [String](../Type/String.mdx)

## Examples

```macaulay2
makeDirectory dir
```

```macaulay2
makeDirectory (dir|"/a/b/c")

```

```text
/tmp/M2-706106-0/0/a/b/c
```

## Additional Information

- Inputs:
- `dir` a [ string](../Type/op_Coredollar_String.mdx) a path to the desired directory
- Outputs:
- a [ string](../Type/op_Coredollar_String.mdx) the name of the newly made directory
- Consequences:
- the directory is made with as many new path components as needed
