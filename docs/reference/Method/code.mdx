# code

**code  -- display source code**

**Type:** [MethodFunctionSingle](../Type/MethodFunctionSingle.mdx)

## Description

- Inputs:

- Outputs:
- a [ net](../Type/op_Coredollar_Net.mdx) the source code of the function or command`f`


### Synopsis


- Inputs:
- `f` a [ function](../Type/Function.mdx) or a [ keyword](../Type/op_Coredollar_Keyword.mdx)
- `X` a [ type](../Type/op_Coredollar_Type.mdx)
- Outputs:
- a [ net](../Type/op_Coredollar_Net.mdx) the source code of method for applying `f` to an argument of type `X`


### Synopsis

### Synopsis

### Synopsis


- Inputs:
