# toList

**toList  -- create a list**

**Type:** [MethodFunctionSingle](../Type/MethodFunctionSingle.mdx)

## Description

The command `toList 1..9`  will throw an error because `toList`  comes before [..](../Method/op_Coredollar_dot_dot.mdx) in Macaulay2's order of operations. To create a list from a range use `toList (1..9)`  instead.Converting between list types may change the order of the elements in unexpected ways.

## Additional Information

- Inputs:
- `A` a [ set](../Type/op_Coredollar_Set.mdx) a [ string](../Type/op_Coredollar_String.mdx) a [ basic list](../Type/op_Coredollar_BasicList.mdx) or a [ tally](../Type/Tally.mdx) or an instance of a class with the [iterator](../Method/iterator.mdx) method installed
- Outputs:
- `L` a [ list](../Type/op_Coredollar_List.mdx) a list whose elements are the elements of `A`
