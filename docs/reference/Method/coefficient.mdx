# coefficient

**coefficient  -- coefficient of a monomial**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

 The returned value is an element of the coefficient ring even in the case when that ring is another polynomial ring.

## Installed For

### coefficient([MonoidElement](../Type/MonoidElement.mdx), [RingElement](../Type/RingElement.mdx))

### coefficient([RingElement](../Type/RingElement.mdx), [RingElement](../Type/RingElement.mdx)) -> [RingElement](../Type/RingElement.mdx)

## Examples

```macaulay2
coefficient(mf)
```

```macaulay2
coefficient(y^2f)

```

```text
a - 2

GF 25
```

```macaulay2
coefficient(ra*x*(r+a*s))

```

```text
a*x

R
```

## Additional Information

- Inputs:
- `m` a [ ring element](../Type/RingElement.mdx) a monomial
- `f` a [ ring element](../Type/RingElement.mdx) in the same ring `R` as `m`
- Outputs:
- a [ ring element](../Type/RingElement.mdx) the coefficient of the monomial `m` in `f` as an element of the coefficient ring of `R`
