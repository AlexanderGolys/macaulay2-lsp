# show

**show  -- display various objects in an external viewer**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

The functions `showTex`  and `showHtml`  are specializations of the `show`  method which first convert `x`  to a [TEX](../Instance/TEX.mdx) or [Hypertext](../Instance/Hypertext.mdx) object respectively and display that result.For example the following lines would display a matrix in a browser or PDF viewer:By default the viewer is determined by either `open` on macOS or `xdg-open` on Linux distributions. As backup for when neither `open` nor `xdg-open` is available the environmental variable `WWWBROWSER` or `firefox` is used.

## Installed For

### show([URL](../Type/URL.mdx))

## Examples

```macaulay2
show x
```

## Additional Information

- Inputs:
- `x` a [ markup list](../Instance/Hypertext.mdx) an instance of the type [TEX](../Instance/TEX.mdx) or an instance of the type [URL](../Type/op_Coredollar_URL.mdx)
- Consequences:
- An external viewer such as a web browser or PDF viewer is started to view the object `x`


### Caveat

No attempt is made to wrap large matrices or equations. The code for this function is Unix dependent at the moment requiring that certain commands like `pdflatex`  are present.
