# copyDirectory

**copyDirectory**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

 Now we remove the files and directories we created.

## Installed For

### copyDirectory([String](../Type/String.mdx), [String](../Type/String.mdx))

## Options

- [UpdateOnly](../Method/UpdateOnly.mdx) => false
- [FollowLinks](../Option/FollowLinks.mdx) => false
- [Exclude](../Method/Exclude.mdx) => \.~[0-9.]+~$
- [Verbose](../Method/Verbose.mdx) => false

## Examples

```macaulay2
copyDirectory(srcdst)
```

```macaulay2
copyDirectory(srcdst
```

```macaulay2
copyDirectory(srcdst
```

## Additional Information

- Inputs:
- `src` a [ string](../Type/op_Coredollar_String.mdx)
- `dst` a [ string](../Type/op_Coredollar_String.mdx)
- [ Optional inputs](../Instance/using functions with optional inputs.mdx):
- `Exclude````...` default value "\\.~[0-9.]+~$" a string containing a regular expression or a list of such strings. If the base part of the name of a file in the source tree matches one of the regular expressions then no link to it is created
- `UpdateOnly```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value false whether to copy files only if the target file does not exist or is older than the source file
- `FollowLinks```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value false whether to follow symbolic links in the source tree to directories
- `Verbose```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value false whether to report individual file operations
- Consequences:
- a copy of the directory tree rooted at `src` is created rooted at `dst`
