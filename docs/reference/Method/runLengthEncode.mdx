# runLengthEncode

**runLengthEncode  -- run length encoding**

**Type:** [MethodFunctionSingle](../Type/MethodFunctionSingle.mdx)

## Description

The result is useful in printed displays as a way of making them more compact.  The original list can be recovered by applying [value](../Method/value.mdx)  to the elements of the result and then using [deepSplice](../Function/op_Coredollar_deepSplice.mdx)  provided that `x`  contains no entries that are sequences.
