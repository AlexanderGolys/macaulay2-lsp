# httpHeaders

**httpHeaders  -- prepend http headers to a string**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

This function is experimental and is intended to support the development of web servers.

## Installed For

### httpHeaders([String](../Type/String.mdx)) -> [String](../Type/String.mdx)

## Examples

```macaulay2
httpHeaders s
```

```macaulay2
httpHeaders "hi there"

```

```text
HTTP/1.1 200 OK
     Server: Macaulay2/1.25.11
     Connection: close
     Content-Length: 8
     Content-type: text/html; charset=utf-8

     hi there
```

## Additional Information

- Inputs:
- `s` a [ string](../Type/op_Coredollar_String.mdx)
- Outputs:
- a [ string](../Type/op_Coredollar_String.mdx) the string obtained from `s` by prepending appropriate headers to it
