# index

**index  -- numeric index of a ring variable**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

 Variables are indexed in the following way: the first variable has index 0 the second index 1 and so on until n-1 where n is the number of generators of R the ring of v.  Then if the coefficient ring is a polynomial ring those variables are numbered starting at n and so on. Notice that r is an element of B and so indices are taken from that ring. If we consider r as an element of C we get a different answer.  Variables of coefficient rings of coefficient rings have an index too. The symbol `index`  is also as a key used in [Monoid](../Type/op_Coredollar_Monoid.mdx)  to store a table that is used to map generator names to the position of the generator in the list of generators.

## Additional Information

- Inputs:
- `v` a [ ring element](../Type/RingElement.mdx)
- Outputs:
- an [ integer](../Type/ZZ.mdx) the integer index starting at 0 of v if it is a variable. If v is not a variable then [null](../Instance/null.mdx) is returned
