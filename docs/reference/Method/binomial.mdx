# binomial

**binomial  -- binomial coefficient**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

When either `n` or `k` are not [ZZ](../Type/ZZ.mdx) objects the [Gamma](../Method/op_Coredollar_Gamma.mdx) function is used i.e.$\binom{n}{k} = \frac{\Gamma(n + 1)}{\Gamma(k + 1)\Gamma(n - k + 1)}$.A polynomial may also be used for `n`.

### binomial([Number](../Type/Number.mdx), [Number](../Type/Number.mdx))

## Additional Information

- Inputs:
- `n` an [ integer](../Type/ZZ.mdx) or a [ ring element](../Type/RingElement.mdx)
- `k` an [ integer](../Type/ZZ.mdx) must be non-negative;
- Outputs:
- a [ number](../Type/op_Coredollar_Number.mdx) the binomial coefficient the coefficient of $x^k$ in $(1+x)^n$ or $n(n-1)...(n-k+1)/k!$.
