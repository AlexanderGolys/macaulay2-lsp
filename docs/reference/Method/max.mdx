# max

**max  -- get the maximum element in a list or sequence**

**Type:** [MethodFunctionSingle](../Type/MethodFunctionSingle.mdx)

## Description

If `L`  contains elements in a polynomial ring the [MonomialOrder](../Instance/MonomialOrder.mdx) of the ring is used for comparisons.More generally the order of the elements is determined using the [?](../Method/op_Coredollar_question.mdx) operator.If `X`  is a list of lists `max`  acts on the outermost level.

## Installed For

### max([VisibleList](../Type/VisibleList.mdx)) -> [Thing](../Type/Thing.mdx)

## Examples

```macaulay2
max X
```

```

```

```macaulay2
max {x*y^2, x*y^2 + z^2, y^4, y*z^5}

```

```text
x*y  + z

R1
```

```macaulay2
max (x*y^2 x*y^2 + z^2 y^4 y*z^5)

```

```text
y*z

R2
```

```macaulay2
max {{3, 1, 2}, {2, 9, 6}, {3, 7, 5}}

```

```text
{3, 7, 5}

List
```

```macaulay2
max flatten {{3, 1, 2}, {2, 9, 6}, {3, 7, 5}}

```

```text
9
```
