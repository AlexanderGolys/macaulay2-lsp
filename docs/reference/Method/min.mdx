# min

**min  -- get the minimum element in a list or sequence**

**Type:** [MethodFunctionSingle](../Type/MethodFunctionSingle.mdx)

## Description

If `L`  contains elements in a polynomial ring the [MonomialOrder](../Instance/MonomialOrder.mdx) of the ring is used for comparisons.More generally the order of the elements is determined using the [?](../Method/op_Coredollar_question.mdx) operator.If `X`  is a list of lists `min`  acts on the outermost level.

## Installed For

### min([VisibleList](../Type/VisibleList.mdx)) -> [Thing](../Type/Thing.mdx)
