# GlobalAssignHook

**GlobalAssignHook  -- hook for assignment to global variables**

**Type:** [Symbol](../Type/Symbol.mdx)

## Description

This technique is used for example for instances of [Type](../Type/op_Coredollar_Type.mdx)  and [Ring](../Type/Ring.mdx)  to arrange for the name of the type or ring to be set to the name of the global variable to which it is first assigned.  The functions [globalAssignFunction](../Function/globalAssignFunction.mdx)  and [globalReleaseFunction](../Function/op_Coredollar_globalReleaseFunction.mdx)  may installed as methods for this purpose.

## Examples

```macaulay2
X.GlobalAssignHook = f
```

```macaulay2
RR.GlobalAssignHook = (symval) -> << "--about to assign " << val << " to " << sym << endl;
```

## Additional Information

- Inputs:
- `X` a [ type](../Type/op_Coredollar_Type.mdx)
- `f` a [ function](../Type/Function.mdx) of two variables: the symbol to which a value is about to be assigned and the value being assigned
- Consequences:
- `f` will be called just before an assignment to a global variable of an instance of class `X` occurs
