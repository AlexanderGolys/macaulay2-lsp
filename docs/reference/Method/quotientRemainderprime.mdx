# quotientRemainder'

**quotientRemainder'  -- matrix quotient and remainder (opposite)**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

 The equation `q*g+r == f`  will hold.  The sources and targets of the maps should be free modules. This function is obtained from `quotientRemainder`  by transposing the inputs and outputs.

## Installed For

### quotientRemainder'([Matrix](../Type/Matrix.mdx), [Matrix](../Type/Matrix.mdx))

## Examples

```macaulay2
(qr) = quotientRemainder'(fg)
```

## Additional Information

- Inputs:
- `f` a [ matrix](../Type/op_Coredollar_Matrix.mdx)
- `g` a [ Gröbner basis](../Type/op_Coredollar_GroebnerBasis.mdx) or a [ matrix](../Type/op_Coredollar_Matrix.mdx) with the same source as `f`
- Outputs:
- `q` the quotient of `f` upon (opposite) division by `g`
- `r` the remainder of `f` upon (opposite) division by `g`
