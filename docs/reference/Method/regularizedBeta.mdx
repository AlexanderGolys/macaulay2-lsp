# regularizedBeta

**regularizedBeta  -- regularized beta function**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

This is the regularized (incomplete) https://en.wikipedia.org/wiki/beta_function beta function \(I_x(a b) = \frac{1}{B(a, b)}\int_0^x t^{a - 1} (1 - t)^{b - 1}\dt\).
