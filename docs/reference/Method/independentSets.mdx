# independentSets

**independentSets  -- some size-maximal independent subsets of variables modulo an ideal**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

 An independent set of variables of an ideal `J`  in a polynomial ring `R`  is a set of variables that are algebraically independent modulo `J`  (i.e. there is no polynomial in `J`  involving only these sets of variables. If the Krull dimension of `R/J`  is `d`  then a maximal independent set is an independent set having size `d` . The independent sets returned correspond one for one with the minimal primes of smallest codimension of the ideal of lead terms of J. The optional Limit argument is useful if you need only one or several such independent sets. Often you want the list of the variables in a maximal independent set or the list of those not in the set. This function is useful as a subroutine to primary decomposition algorithms.

## Additional Information

- Inputs:
- `J` an [ ideal](../Type/op_Coredollar_Ideal.mdx) or a [ monomial ideal](../Type/op_Coredollar_MonomialIdeal.mdx)
- [ Optional inputs](../Instance/using functions with optional inputs.mdx):
- `Limit```an [ integer](../Type/ZZ.mdx) default value infinity the maximum number of independent sets to be found
- Outputs:
- a [ list](../Type/op_Coredollar_List.mdx) of products of variables. The support of any one of these products is a maximal independent subset of variables modulo `J`
