# html

**html  -- convert to HTML format**

**Type:** [MethodFunctionSingle](../Type/MethodFunctionSingle.mdx)

## Description

`html x` converts `x` to HTML format.The return value is a string that is suitable for use in a .html file readable by a browser. [hypertext](../Method/op_Coredollar_hypertext.mdx) elements are translated into the corresponding HTML elements. When no HTML conversion is available[tex](../Method/op_Coredollar_tex.mdx) is called. $\LaTeX$ can be rendered in the browser using MathJax or $\KaTeX$.
