# sign

**sign  -- sign (signum) function**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

When x is real then this returns 1 if it is positive -1 if it is negative and 0 if it is zero.If x is complex and nonzero then this returns $x/|x|$.
