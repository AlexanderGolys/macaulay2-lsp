# quotient'

**quotient'  -- factor a map through another with the same source**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

This function produces a matrix `h` such that `f - h*g` is the reduction of `f` modulo a Gröbner basis for the image of `dual g`. See [quotient](../Method/quotient.mdx) for the dual notion.If the remainder `f - h*g` is zero then the quotient `g\\f` satisfies the equation `f === (g\\f) * g`. Otherwise the equation `h * g + r === f` will hold where `r` is the map provided by [remainder'](../Method/op_Coredollar_remainderprime.mdx).Note however that currently the function [remainder'](../Method/op_Coredollar_remainderprime.mdx) only works if the source and target modules are free.

## Examples

```macaulay2
h = quotient'(f g)
h = g \\ f
```
