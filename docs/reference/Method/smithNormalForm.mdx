# smithNormalForm

**smithNormalForm  -- smith normal form for a matrix over a PID**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

 This function produces a diagonal matrix `D`  and invertible matrices `P`  and `Q`  such that `D = PMQ` with diagonal entries `d1 d2 ... dn`  of `D`  satisfying `d1|d2|...|dn.`This function is the underlying routine used by [minimalPresentation](../Method/minimalPresentation.mdx)  in the case when the ring is [ZZ](../Type/ZZ.mdx)  or a polynomial ring in one variable over a field. In the following example we test the result be checking that the entries of `D1 P1 M Q1`  are the same. The degrees associated to these matrices do not match up so a simple test of equality would return false. The key idea of the current implementation is as follows: compute a Gröbner basis transpose the generators and repeat until we encounter a matrix whose transpose is already a Gröbner basis.

## Additional Information

- Inputs:
- `M` a [ matrix](../Type/op_Coredollar_Matrix.mdx)
- [ Optional inputs](../Instance/using functions with optional inputs.mdx):
- `ChangeMatrix```a [ list](../Type/op_Coredollar_List.mdx) default value {true, true} of two Boolean elements. This determines whether the change of basis matrices `P` and/or `Q` are computed
- `KeepZeroes```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value true whether to keep rows and columns that are completely zero
- Outputs:
- `D` a [ matrix](../Type/op_Coredollar_Matrix.mdx) The Smith normal form of `M`
- `P` a [ matrix](../Type/op_Coredollar_Matrix.mdx) invertible (left) change of basis matrix
- `Q` a [ matrix](../Type/op_Coredollar_Matrix.mdx) invertible (right) change of basis matrix


### Caveat

 The behavior of this function is not defined when the ring is not a PID.
