# betti

**betti  -- display or modify a Betti diagram**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

The function `betti` creates and displays the Betti diagram of mathematical objects that can be presented using graded free modules and graded maps between them such as ideals modules and chain complexes. The returned [BettiTally](../Type/op_Coredollar_BettiTally.mdx) encapsulates the data from the entries of the displayed Betti diagram in case they are needed in a program.The keys are triples `(idh)` encoding:`i` the column labels representing the homological degree;`d` a list of integers giving a multidegree; and`h` the row labels representing the dot product of a weight covector and `d`.Only `i` and `h` are used in printing and the weight covector can be modified by specifying the [betti(...](../Instance/betti(....mdx) option. The [ heft vector](../Instance/heft vectors.mdx) of the ring of the input object is the default choice for the weight covector.If the ring has no heft vector then the weights vector is taken to be all zero. If the option [betti(...](../Instance/betti(....mdx) is provided the length of the given weight vector should be the same as the [ degree length](../Method/degreeLength.mdx) of the ring of the input object.If the ring is multigraded the function [multigraded(BettiTally)](../Instance/multigraded(BettiTally).mdx) may be used to extract information from all degree components of the Betti diagram at once.
### Betti table of a Gröbner basis


- Inputs:
- `G` a [ Gröbner basis](../Type/op_Coredollar_GroebnerBasis.mdx)
- `Weights`
- Outputs:
- a [ Betti tally](../Type/op_Coredollar_BettiTally.mdx) a diagram showing the degrees of the generators of the source and target modules of the matrix of generators of `G`


### Betti diagram showing the degrees of the target and source of a map


- Inputs:
- `f` a [ matrix](../Type/op_Coredollar_Matrix.mdx)
- `Weights`
- Outputs:
- a [ Betti tally](../Type/op_Coredollar_BettiTally.mdx) a diagram showing the degrees of the generators of the source and target modules of `f`

The diagram ignores the degree of the map itself.
### Betti diagram showing the degrees of generators and relations of a homogeneous module


- Inputs:
- `M` a [ module](../Type/op_Coredollar_Module.mdx)
- `Weights`
- Outputs:
- a [ Betti tally](../Type/op_Coredollar_BettiTally.mdx) showing the zero-th first graded and total Betti numbers of $M$.

Note that the Betti numbers are not minimized.Also see [betti(CoherentSheaf)](../Instance/betti(CoherentSheaf).mdx).
### Betti diagram showing the degrees of generators of a homogeneous ideal


- Inputs:
- `I` an [ ideal](../Type/op_Coredollar_Ideal.mdx)
- `Weights`
- Outputs:
- a [ Betti tally](../Type/op_Coredollar_BettiTally.mdx) showing the degrees of the generators and relations of the quotient of the ambient ring by $I$

Note that the Betti numbers are not minimized.
