# forceGB

**forceGB  -- declare that the columns of a matrix are a Gröbner basis**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

 Declares that the columns of the matrix `f`  constitute a Gröbner basis autoreduces it minimizes it sorts it and returns a Gröbner basis object declaring itself complete without computing any S-pairs. Sometimes one knows that a set of polynomials (or columns of such) form a Gröbner basis but *Macaulay2*  doesn't.  This is the way to inform the system of this fact. This Gröbner basis object is stored with the matrix and can be obtained as usual: Requesting a Gröbner basis for `f`  requires no computation.If an autoreduced Gröbner basis is desired replace `f`  by `gens forceGB f`  first.
