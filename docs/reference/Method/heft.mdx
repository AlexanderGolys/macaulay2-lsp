# heft

**heft  -- heft vector of ring or monoid**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

`heft` returns the [ heft vector](../Instance/heft vectors.mdx) in use for `R`

## Installed For

### heft([Monoid](../Type/Monoid.mdx))

### heft([PolynomialRing](../Type/PolynomialRing.mdx))

### heft([QuotientRing](../Type/QuotientRing.mdx))

### heft([Ring](../Type/Ring.mdx)) -> [List](../Type/List.mdx)

## Examples

```macaulay2
heft R
```

```macaulay2
heft S

```

```text
{1, 1, 1, 1}

List
```

## Additional Information

- Inputs:
- `R` a [ ring](../Type/Ring.mdx) or a [ monoid](../Type/op_Coredollar_Monoid.mdx)
- Outputs:
- a [ list](../Type/op_Coredollar_List.mdx) a weight co-vector of integers with length the same as [ degree length](../Method/degreeLength.mdx) of `R` or
- [null](../Instance/null.mdx) if there is no heft vector.
