# intersect

**intersect  -- compute an intersection**

**Type:** [MethodFunctionBinary](../Type/MethodFunctionBinary.mdx)

## Description

This function calculates the intersection of a list or sequence of compatible objects.When a more efficient algorithm is available for computing the intersection of all inputs simultaneously rather than iteratively for instance for intersecting [Module](../Type/op_Coredollar_Module.mdx) s a specialized function that takes a list or sequence may be installed on `(symbol intersect Type)` .This function may also be called using the synonym `intersection` .
