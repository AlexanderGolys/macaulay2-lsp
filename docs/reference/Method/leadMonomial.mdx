# leadMonomial

**leadMonomial  -- the leading monomial of a ring element**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

The leading term is with respect to the monomial ordering in the ring. See [monomial orderings](../Instance/monomial orderings.mdx) for details.

## Installed For

### leadMonomial([RingElement](../Type/RingElement.mdx)) -> [RingElement](../Type/RingElement.mdx)

## Examples

```macaulay2
leadMonomial f
```

```macaulay2
leadMonomial f

        3
```

```text
b*c

R
```

```macaulay2
leadMonomial g

        2
```

```text
a*b

S
```

## Additional Information

- Inputs:
- `f` a [ ring element](../Type/RingElement.mdx) a polynomial
- Outputs:
- a [ ring element](../Type/RingElement.mdx) the monomial with no coefficient of the leading term of `f`
