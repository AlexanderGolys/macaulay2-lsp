# pfaffian

**pfaffian  -- Pfaffian of a skew-symmetric matrix**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

The https://en.wikipedia.org/wiki/Pfaffian Pfaffian of a $2n\times 2n$ skew-symmetric matrix $M=(m_{ij})$ is $$\frac{1}{2^nn!}\sum_{\sigma\in S_{2n}}\operatorname{sgn}(\sigma)\prod_{i=1}^nm_{\sigma(2i-1),\sigma(2i)}$$ where $S_n$ is the symmetric group on $2n$ elements.The square of the Pfaffian is the determinant.Skew-symmetric matrices with an odd number of rows and columns have Pfaffian zero.
