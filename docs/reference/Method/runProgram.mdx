# runProgram

**runProgram  -- run an external program**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

This method runs an external program which has already been loaded using [findProgram](../Method/findProgram.mdx).  The results of this run are available in a [ProgramRun](../Type/op_Coredollar_ProgramRun.mdx) object.The value corresponding to the `"output"` key may also be obtained using [toString](../Method/toString.mdx).It is also possible to skip [findProgram](../Method/findProgram.mdx) and just provide two strings: the name of the program and the command line arguments.Internally this routine uses [run](../Function/run.mdx). Another way to interact with programs is to pass a string beginning with "!" to [get](../Function/op_Coredollar_get.mdx)[openIn](../Function/op_Coredollar_openIn.mdx)[openOut](../Function/op_Coredollar_openOut.mdx) or [openInOut](../Function/op_Coredollar_openInOut.mdx).

## Additional Information

- Inputs:
- `program` an instance of the type [Program](../Type/op_Coredollar_Program.mdx) the program to run generated by [findProgram](../Method/findProgram.mdx).
- `exe` a [ string](../Type/op_Coredollar_String.mdx) the specific executable file to run. This is only necessary if the program consists of multiple such files. If not given then `program#"name"` is used.
- `args` a [ string](../Type/op_Coredollar_String.mdx) the command line arguments passed to the program.
- [ Optional inputs](../Instance/using functions with optional inputs.mdx):
- `KeepFiles```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value false whether to keep the temporary files containing the program's output.
- `RaiseError```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value true whether to raise an error if the program returns a nonzero value.
- `RunDirectory```a [ string](../Type/op_Coredollar_String.mdx) default value null the directory from which to run the program. If it does not exist then it will be created. If [null](../Instance/null.mdx) then the program will be run from the current working directory (see [currentDirectory](../Function/currentDirectory.mdx)).
- `Verbose```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value false whether to print the command line input and the program's output.
