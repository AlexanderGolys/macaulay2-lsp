# unique

**unique  -- eliminate duplicates from a list**

**Type:** [MethodFunctionSingle](../Type/MethodFunctionSingle.mdx)

## Description

The output list maintains the order of elements in `L` .Another way to list the unique elements of `L`  is by creating a set from `L`  and then listing its elements. This may be slightly faster than `unique`  but forgets the ordering of `L` .To count occurrences of each element use [tally](../Function/op_Coredollar_tally.mdx). To create a sorted list see [sort](../Method/op_Coredollar_sort.mdx). For an overview of lists and sequences see [lists and sequences](../Instance/lists and sequences.mdx).
