# partitions

**partitions  -- list the partitions of an integer**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

Each partition is a basic list of type [Partition](../Type/op_Coredollar_Partition.mdx).For ordered lists of exactly `k`  nonnegative integers that sum to `n`  use [compositions](../Method/compositions.mdx) instead. In the following example we create Partition objects from the output of `compositions`  to find all the partitions of 10 of length exactly 4 with no part greater than 5.If `partitions n`  is called on a negative integer `n`  an empty list is returned. If a negative integer is given for `k`  it will cause an error.

## Additional Information

- Inputs:
- `n` an [ integer](../Type/ZZ.mdx) a nonnegative integer
- `k` an [ integer](../Type/ZZ.mdx) a nonnegative integer the maximum size of each part
- Outputs:
- a [ list](../Type/op_Coredollar_List.mdx) of all partitions of `n`
