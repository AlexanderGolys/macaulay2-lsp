# preimage

**preimage  -- preimage of a map**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description


### preimage of an ideal under a ring map


- Inputs:
- `f` a [ ring map](../Type/op_Coredollar_RingMap.mdx)
- `M` an [ ideal](../Type/op_Coredollar_Ideal.mdx) in the target of $f$;
- Outputs:
- an [ ideal](../Type/op_Coredollar_Ideal.mdx) the preimage of $I$ under the map $f$;


### preimage of a submodule under a module map


- Inputs:
- `f` a [ matrix](../Type/op_Coredollar_Matrix.mdx)
- `M` a [ module](../Type/op_Coredollar_Module.mdx) a submodule in the target of $f$;
- Outputs:
- a [ module](../Type/op_Coredollar_Module.mdx) the preimage of $M$ under the map $f$;

$M$ and [target](../Method/op_Coredollar_target.mdx) of $f$ should have the same [ambient](../Method/op_Coredollar_ambient.mdx) module.
