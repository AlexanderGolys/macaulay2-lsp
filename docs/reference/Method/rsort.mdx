# rsort

**rsort  -- sort a list or matrix in reverse order**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

 Same as [sort](../Method/op_Coredollar_sort.mdx)  except that the elements or columns are placed in reverse order. The optional parameters are the same as for [sort](../Method/op_Coredollar_sort.mdx) .

## Options

- [MonomialOrder](../Option/MonomialOrder.mdx) => Ascending
- [DegreeOrder](../Option/DegreeOrder.mdx) => null
