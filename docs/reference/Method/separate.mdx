# separate

**separate  -- split a string into substrings using a regular expression**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

For an introduction to regular expressions see [regular expressions](../Instance/regular expressions.mdx).Example 1: The command `separate(s)` breaks the string at every occurrence of `\r\n` or `\n`.This is equivalent to using the [lines](../Function/op_Coredollar_lines.mdx) function.Example 2: use commas periods and semicolons as separators.Example 3: match any number of consecutive spaces.We can now correct the original string using the [demark](../Function/op_Coredollar_demark.mdx) and [replace](../Method/op_Coredollar_replace.mdx) functions.Example 4: delete every word starting with "x" from a string by using [concatenate](../Function/concatenate.mdx) together with [separate](../Method/op_Coredollar_separateRegexp.mdx).Example 5: The optional argument `n` allows us to specify a separator that differs from the match criteria. In the previous example words beginning with "x" were both the match and the separator. In this example we match words beginning with "x" but separate the string using the leading "x". With [concatenate](../Function/concatenate.mdx) this results in deleting just the "x" from words starting with "x" (not the same as removing every "x").`separateRegexp` is a deprecated synonym for `separate`.

## Additional Information

- Inputs:
- `re` a [ string](../Type/op_Coredollar_String.mdx) a [ regular expression](../Instance/regular expressions.mdx) describing a pattern
- `str` a [ string](../Type/op_Coredollar_String.mdx) the string to split
- `n` an [ integer](../Type/ZZ.mdx) the index of the parenthesized expression to split on
- [ Optional inputs](../Instance/using functions with optional inputs.mdx):
- `POSIX```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value false if true interpret the `re` using the POSIX Extended flavor otherwise the Perl flavor
- Outputs:
- a [ list](../Type/op_Coredollar_List.mdx) a list of strings obtained by breaking `str` at every match to the pattern `re` or if a natural number `n` is specified using the $n$-th parenthesized expression in `re` as the separator. If no `re` is specified`str` is split at every new line.


### Caveat

For backwards compatibility if the pattern is a single character and it is an unescaped special character such as `+``*` or `.` then it is treated as a literal character. In future code the pattern must be escaped.
