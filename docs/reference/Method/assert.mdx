# assert

**assert  -- check whether something is true raise an error if not**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

`assert x` raises an error if `x` isn't true.If `x` is an [Expression](../Type/op_Coredollar_Expression.mdx) that evaluates to false then a partially evaluated form is printed with the error message to assist in debugging.

## Installed For

### assert([Expression](../Type/Expression.mdx))

### assert([Thing](../Type/Thing.mdx))

## Examples

```macaulay2
assert x
```

```macaulay2
assert( (2+2) === 4)
```

```macaulay2
assert(rank matrix {{1, 2}, {2, 4}} == 2)
stdio:3:6:(3): error: assertion failed
```

```macaulay2
assert Equation(rank matrix {{1, 2}, {2, 4}} 2)
stdio:4:6:(3): error: assertion failed:
1 == 2 is false
```
