# isMember

**isMember  -- test membership in a list or set**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

This function may also be called using the synonym `member`.

## Examples

```macaulay2
isMember(ex)
```

```macaulay2
isMember(c{a,b,c,d,e})

```

```text

```




```text

```

## Additional Information

- Inputs:
- `e` a [ thing](../Type/Thing.mdx)
- `x` a [ list](../Type/op_Coredollar_List.mdx) a [ sequence](../Type/Sequence.mdx) or a [ set](../Type/op_Coredollar_Set.mdx)
- Outputs:
- a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) whether e is in the list sequence or set x;
