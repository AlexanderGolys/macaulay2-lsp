# importFrom

**importFrom  -- import symbols to the current private dictionary**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

This function can be used to import specific symbols from the private dictionary of another package into the private dictionary of the [ current package](../Instance/currentPackage.mdx).To import all private symbols of a package use [debug(Package)](../Instance/debug(Package).mdx) instead. The symbols imported with this function can then be exported using [export](../Method/export.mdx) or [exportMutable](../Method/op_Coredollar_exportMutable.mdx).

## Examples

```macaulay2
importFrom(pkg {"symbol1", "symbol2"})
```

## Additional Information

- Inputs:
- `pkg` a [ package](../Type/op_Coredollar_Package.mdx) or a [ string](../Type/op_Coredollar_String.mdx) the package containing the private symbols
- a [ string](../Type/op_Coredollar_String.mdx) or a [ list](../Type/op_Coredollar_List.mdx) of strings corresponding to the private [ symbols](../Type/op_Coredollar_Symbol.mdx) to export from the package
- Outputs:
- a [ list](../Type/op_Coredollar_List.mdx) of [ symbols](../Type/op_Coredollar_Symbol.mdx)
- Consequences:
- package symbols provided in the list will be added to the private [ dictionary](../Type/op_Coredollar_Dictionary.mdx) of the [ current package](../Instance/currentPackage.mdx) but will not be exported
