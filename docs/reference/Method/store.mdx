# store

**store  -- store the value of an atomic integer**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

The value of y is stored in x and [null](../Instance/null.mdx) is returned.  This operation occurs atomically and is thread safe.

## Installed For

### store([AtomicInt](../Type/AtomicInt.mdx), [ZZ](../Type/ZZ.mdx))

## Examples

```macaulay2
store(x y)
```

```macaulay2
store(x 5)
```

## Additional Information

- Inputs:
- `x` an [ atomic integer](../Type/op_Coredollar_AtomicInt.mdx)
- `y` an [ integer](../Type/ZZ.mdx)
