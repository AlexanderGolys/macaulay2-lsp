# super

**super  -- get the ambient module**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

`super M`  -- yields the module that the module `M`  is a submodule of.`super f`  -- if `f`  is a map whose target is a submodule of `M`  yields the composite of `f`  with the inclusion into `M` .
