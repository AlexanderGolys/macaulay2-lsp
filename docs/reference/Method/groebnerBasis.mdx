# groebnerBasis

**groebnerBasis  -- Gröbner basis as a matrix**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

With no `Strategy`  option this just calls [gb](../Method/gb.mdx).With a `Strategy`  option the code is experimental subject to interface changes and might have bugs.  So use at your own risk!  However it appears to work correctly and is often very fast in cases where it applies.  If you encounter any bugs please let us know!If either `"MGB"`  (MGB stands for mathicGB the name of the package used) or `"F4"`  is given for the Strategy then experimental code (written by Bjarke Roune and M. Stillman) is used. The plan is for this to become the default version for Gröbner bases in later versions of Macaulay2.  But for now it is experimental.These strategies only work for ideals in polynomial rings over a finite field ZZ/p. In other cases either an error will be given or the current default Gröbner basis algorithm will be used.Also implemented is a Faugere-like algorithm that is sometimes much faster (but also sometimes takes a large amount of memory).

## Additional Information

- Inputs:
- `I` an [ ideal](../Type/op_Coredollar_Ideal.mdx) or a module or a matrix (in which case the result is the Gröbner basis of the submodule generated by the columns)
- `MGBOptions` a [ list](../Type/op_Coredollar_List.mdx) For internal use only. Warning: the interface is likely to change.
- [ Optional inputs](../Instance/using functions with optional inputs.mdx):
- `Strategy```a [ string](../Type/op_Coredollar_String.mdx) default value null If not given use the default algorithm. If given value must be "MGB" or "F4" and the result is experimental
- `MGBOptions`
- Outputs:
- `M` a [ matrix](../Type/op_Coredollar_Matrix.mdx) The matrix whose columns are the generators of the Gröbner basis of `I`. In the non-local monomial order case the result is auto-reduced and sorted.


### Caveat

(1) The MGB and F4 options are experimental work only over a finite field of char $< 2^{32}$ not over quotient rings and not over exterior or Weyl algebras.  However these versions can be much faster when they apply. (2) The experimental versions do not stash their results into the ideal or module. (3) The experimental version only works for ideals currently.
