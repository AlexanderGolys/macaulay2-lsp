## Additional Information

- Inputs:
- `x` a [ real number](../Type/op_x226_x132_x157.mdx)
- `b` a [ real number](../Type/op_x226_x132_x157.mdx) the base for the logarithm
- `I` a [ real interval](../Type/RRi.mdx)
- `J` a [ real interval](../Type/RRi.mdx) an interval of bases for the logarithm
- Outputs:
- the logarithm of `x`
- a [ real interval](../Type/RRi.mdx) an interval containing the logarithms of points of `I`
- a [ real interval](../Type/RRi.mdx) an interval containing the logarithms for bases in `J`
