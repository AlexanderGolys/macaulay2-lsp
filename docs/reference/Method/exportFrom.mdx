# exportFrom

**exportFrom  -- export symbols from a package's private dictionary**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

This function can be used to export specific symbols from the private dictionary of another package.

## Installed For

### exportFrom([Package](../Type/Package.mdx), [List](../Type/List.mdx))

### exportFrom([Package](../Type/Package.mdx), [String](../Type/String.mdx))

### exportFrom([String](../Type/String.mdx), [List](../Type/List.mdx))

### exportFrom([String](../Type/String.mdx), [String](../Type/String.mdx))

## Examples

```macaulay2
exportFrom(pkg {"symbol1", "symbol2"})
```

## Additional Information

- Inputs:
- `pkg` a [ package](../Type/op_Coredollar_Package.mdx) or a [ string](../Type/op_Coredollar_String.mdx) the package containing the symbols
- a [ string](../Type/op_Coredollar_String.mdx) or a [ list](../Type/op_Coredollar_List.mdx) of strings corresponding to the symbols to export
- Consequences:
- package symbols provided in the list will be added to the [ dictionary](../Type/op_Coredollar_Dictionary.mdx) of the [ current package](../Instance/currentPackage.mdx) and will be exported
