# inverseRegularizedBeta

**inverseRegularizedBeta  -- inverse of the regularized beta function**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

This is the inverse of [regularizedBeta](../Method/regularizedBeta.mdx) with respect to the first argument.
