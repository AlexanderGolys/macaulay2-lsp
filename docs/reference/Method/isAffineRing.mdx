# isAffineRing

**isAffineRing  -- whether something is an affine ring**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

 For our purposes an affine ring is a quotient of a (not necessarily commutative) [ polynomial ring](../Type/PolynomialRing.mdx)  over a field.
