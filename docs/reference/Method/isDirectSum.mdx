# isDirectSum

**isDirectSum  -- whether something is a direct sum**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

 Works for modules chain complexes etc. The components of the sum can be recovered with [components](../Method/op_Coredollar_components.mdx) .

## Installed For

### isDirectSum([Module](../Type/Module.mdx))

## Examples

```macaulay2
isDirectSum ZZ^6

```

```text
false
```

```macaulay2
isDirectSum F

```

```text
true
```
