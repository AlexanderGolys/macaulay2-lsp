# selectInSubring

**selectInSubring  -- select columns in a subring**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

 For example consider the following block (or product) order. The lexicographic order is considered as one block as in the following example. If you wish to be able to pick out the elements not involving a or a and b etc then create a block monomial order.

## Installed For

### selectInSubring([ZZ](../Type/ZZ.mdx), [Matrix](../Type/Matrix.mdx)) -> [Matrix](../Type/Matrix.mdx)

## Additional Information

- Inputs:
- `i` an [ integer](../Type/ZZ.mdx)
- `m` a [ matrix](../Type/op_Coredollar_Matrix.mdx)
- Outputs:
- a [ matrix](../Type/op_Coredollar_Matrix.mdx) with the same target and ring as `m` consisting of those columns of `m` which lie in the subring where the first `i` blocks of the monomial order are zero


### Caveat

 This routine doesn't do what one would expect for graded orders such as `GLex` .  There the first part of the monomial order is the degree which is usually not zero.
