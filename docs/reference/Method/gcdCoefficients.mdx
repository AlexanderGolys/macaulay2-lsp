# gcdCoefficients

**gcdCoefficients  -- greatest common divisor with coefficients**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

This returns a sequence of the form `(d r s)` where $d=\gcd(a b)$ and $r$ and $s$ are the minimal Bézout coefficients satisfying the equation $d = ar + bs$.It works for integers or elements of polynomial rings in one variable.
