# getPrimeWithRootOfUnity

**getPrimeWithRootOfUnity  -- find a prime p with a primitive n-th root of unity r in ZZ/p**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

We compute the prime p as a larger prime factor of $r1^n-1$. If the largest p in the desired range does not work we pass to $r1+1$ and repeat.

## Installed For

### getPrimeWithRootOfUnity([ZZ](../Type/ZZ.mdx), [ZZ](../Type/ZZ.mdx)) -> [ZZ](../Type/ZZ.mdx)

## Options

- [Range](../Method/Range.mdx) => (10000,30000)

## Additional Information

- Inputs:
- `n` an [ integer](../Type/ZZ.mdx) the exponent of the root of unity
- `r1` an [ integer](../Type/ZZ.mdx) tentative root of unity
- [ Optional inputs](../Instance/using functions with optional inputs.mdx):
- `Range````...` default value (1000030000) (ab) specifying an integral interval in which we search for a prime number with desired properties. If $b < a + 2*\log a$ an error message will be returned.
- Outputs:
- `p` an [ integer](../Type/ZZ.mdx) a prime in the specified range. The default range is $(10^43*10^4)$
- `r` an [ integer](../Type/ZZ.mdx) a primitive n-th root of unity mod p
