# exponents

**exponents  -- the exponents of a polynomial**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

exponents  -- the exponents of a polynomial

## Installed For

### exponents([MonoidElement](../Type/MonoidElement.mdx))

### exponents([RingElement](../Type/RingElement.mdx)) -> [List](../Type/List.mdx)

## Examples

```macaulay2
exponents m
```

```macaulay2
exponents (f = x^2 - 7 + x*y*z^11 + y)

```

```text
{{1, 1, 11}, {2, 0, 0}, {0, 1, 0}, {0, 0, 0}}

List
```

```macaulay2
exponents leadMonomial f

```

```text
{{1, 1, 11}}

List
```

## Additional Information

- Inputs:
- `m` a [ ring element](../Type/RingElement.mdx) or a [ monoid element](../Type/op_Coredollar_MonoidElement.mdx) a monomial
- Outputs:
- a [ list](../Type/op_Coredollar_List.mdx) for a monomial provides the list of exponents; for a polynomial provides a list whose elements are the lists of exponents of the terms of `f`
