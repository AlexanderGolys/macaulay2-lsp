# match

**match  -- regular expression matching**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

For an introduction to regular expressions see [regular expressions](../Instance/regular expressions.mdx).The `` option can be used to specify the POSIX Extended flavor for the regular expression used to match. Note that only the Perl flavor allows the use of lookahead and lookbehinds.When the first input is a list by default the output is true if `str` is a match for at least one of the given regular expressions.Optionally`` indicates that the string should match every pattern in the list to be a match.The `Strategy` option is not used when the first input is not a list.

## Examples

```macaulay2
match(re str)
match(patterns str)
```

```macaulay2
match("cat" s)

```

```text
true
```

```macaulay2
match ("cats" s)

```

```text
false
```

```macaulay2
match("cat(?!fish)" s)

```

```text
true
```

```macaulay2
match("cat(?=fish)" s)

```

```text
true
```

```macaulay2
match("(?<!cat)fish" "cat catfish dog")

```

```text
false
```

```macaulay2
match("(?<!cat)fish" "cat swordfish dog")

```

```text
true
```

```macaulay2
match({"Cat", "Dog"} "CatDog")

```

```text
true
```

```macaulay2
match({"Cat", "Dog"} "Catfish")

```

```text
true
```

```macaulay2
match({"Cat", "Dog"} "CatDog"
```

```macaulay2
not match({"Cat", "Dog"} "Catfish"
```

## Additional Information

- Inputs:
- `re` a [ string](../Type/op_Coredollar_String.mdx) a [ regular expression](../Instance/regular expressions.mdx) describing a pattern
- `str` a [ string](../Type/op_Coredollar_String.mdx) a subject string to be searched
- `patterns` a [ list](../Type/op_Coredollar_List.mdx) a list of regular expressions
- [ Optional inputs](../Instance/using functions with optional inputs.mdx):
- `POSIX```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value false if true interpret the `re` using the POSIX Extended flavor otherwise the Perl flavor
- `Strategy```a [ function](../Type/Function.mdx) default value any logical quantifier for matching a list of patterns typically [all](../Method/all.mdx) or [any](../Function/any.mdx)
- Outputs:
- a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) whether the string `str` is a match for the regular expression `re` or at least one of `patterns` when `` (default)
- Consequences:
- the variable [lastMatch](../Instance/lastMatch.mdx) is set to the value returned by [regex](../Method/op_Coredollar_regex.mdx) which is called by [match](../Method/match.mdx).
