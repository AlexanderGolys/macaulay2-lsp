# makePackageIndex

**makePackageIndex  -- create an index of installed packages**

**Type:** [MethodFunctionSingle](../Type/MethodFunctionSingle.mdx)

## Description

This command may need to be run after installing a package via [installPackage](../Method/installPackage.mdx).This command is run each time the program is started updating the index file. Thus one can simply restart Macaulay2 to obtain the same consequence.

## Installed For

### makePackageIndex([List](../Type/List.mdx))

### makePackageIndex([Sequence](../Type/Sequence.mdx))

## Examples

```macaulay2
makePackageIndex()
```

## Additional Information

- Consequences:
- Creates a file `index.html` in the `~/.Macaulay2` directory containing links to the documentation for Macaulay2 and all installed packages.
