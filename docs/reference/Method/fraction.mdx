# fraction

**fraction**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

The output will be in the fraction field of the ring containing `f` and `g` without reducing it to lowest terms.

## Installed For

### fraction([RingElement](../Type/RingElement.mdx), [RingElement](../Type/RingElement.mdx))

## Examples

```macaulay2
fraction(f g)
```

## Additional Information

- Outputs:
- a [ ring element](../Type/RingElement.mdx) the fraction `f/g`
