# regexQuote

**regexQuote  -- escape special characters in regular expressions**

**Type:** [MethodFunctionSingle](../Type/MethodFunctionSingle.mdx)

## Description

regexQuote  -- escape special characters in regular expressions

## Installed For

### regexQuote([String](../Type/String.mdx)) -> [String](../Type/String.mdx)

## Examples

```macaulay2
regexQuote s
```

```macaulay2
regexQuote "2+2"

```

```text
2\+2
```

## Additional Information

- Inputs:
- `s` a [ string](../Type/op_Coredollar_String.mdx)
- Outputs:
- a [ string](../Type/op_Coredollar_String.mdx) obtained from `s` by escaping all of the characters that have special meanings in regular expressions (`\ ^ $. | ? * + ( ) [ ] {, }`) with a `\`.
