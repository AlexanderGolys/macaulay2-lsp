# homogenize

**homogenize  -- homogenize with respect to a variable**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

`homogenize(mv)`  -- homogenize the ring element vector matrix or module `m`  using the variable `v`  in the ring of `m` .`homogenize(mvw)`  -- homogenize `m`  using the variable `v`  so that the result is homogeneous with respect to the given list `w`  of integers provided as weights for the variables. The weights that may be used are limited (roughly) to the range -2^30 .. 2^30.

## Additional Information

### Caveat

 If the homogenization overflows the monomial this is not reported as an error.
