# listForm

**listForm  -- convert to list form**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

A monomial is represented by the list of its exponents. A polynomial is represented by lists of pairs `(m c)` one for each term where `m` is a list of exponents for monomial and `c` is the coefficient.

## Installed For

### listForm([MonoidElement](../Type/MonoidElement.mdx))

### listForm([RingElement](../Type/RingElement.mdx)) -> [List](../Type/List.mdx)

## Examples

```macaulay2
listForm f
```

```macaulay2
listForm (x^2 - 7 + x*y*z^11 + y)

```

```text
{({1, 1, 11}, 1), ({2, 0, 0}, 1), ({0, 1, 0}, 1), ({0, 0, 0}, -7)}

List
```

## Additional Information

- Inputs:
- `f` a [ ring element](../Type/RingElement.mdx) or a [ monoid element](../Type/op_Coredollar_MonoidElement.mdx)
- Outputs:
- a [ list](../Type/op_Coredollar_List.mdx) the polynomial or monomial in a form represented by nested lists.
