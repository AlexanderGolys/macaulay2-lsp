# newPackage

**newPackage  -- the preamble of a package**

**Type:** [MethodFunctionSingle](../Type/MethodFunctionSingle.mdx)

## Description

The dictionaries for the symbols in the packages loaded by the user are moved out of the way to avoid conflicts so just the standard pre-loaded packages are visible to the source code of the package.  In addition the package [SimpleDoc](../Instance/SimpleDoc.mdx) is made available. If functions from additional packages are needed by the code in the new package then [needsPackage](../Method/op_Coredollar_needsPackage.mdx) can be used (after the use of `newPackage`) to provide them. If functions from additional packages are needed by the user who will load the new package then [needsPackage](../Method/op_Coredollar_needsPackage.mdx) can be used (before the use of `newPackage`) to provide them.The options can be recovered with [options](../Method/op_Coredollar_options.mdx) as follows.Here is a template for a typical `newPackage` entry in a package.

## Additional Information

- Inputs:
- `PackageName` a [ string](../Type/op_Coredollar_String.mdx) the name of the new package
- [ Optional inputs](../Instance/using functions with optional inputs.mdx):
- `Version```a [ string](../Type/op_Coredollar_String.mdx) default value "0.0" the version number of the package. A version number less than 1.0 indicates that the package is under development and the user interface may change.
- `Date```a [ string](../Type/op_Coredollar_String.mdx) default value null the date of this version of the package
- `InfoDirSection```a [ string](../Type/op_Coredollar_String.mdx) default value "Macaulay2 and its packages" the title of the section in the info page directory where the menu entry for this package should be made
- `Headline```a [ string](../Type/op_Coredollar_String.mdx) default value null a brief (5-10 words) description of the package
- `Authors```a [ list](../Type/op_Coredollar_List.mdx) default value {} each entry is a list of options the form ```` or `` where `x` is a string.
- `Keywords```a [ list](../Type/op_Coredollar_List.mdx) default value {Uncategorized} the entries are keywords describing the package used to classify the package in the list of [packages provided with Macaulay2](../Instance/packages provided with Macaulay2.mdx)
- `HomePage```a [ string](../Type/op_Coredollar_String.mdx) default value null the URI pointing to the home page of the package if any
- `DebuggingMode```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value false whether [debuggingMode](../Instance/debuggingMode.mdx) should be true during package loading. However if [debuggingMode](../Instance/debuggingMode.mdx) is already `false` it will remain so.
- `AuxiliaryFiles```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value false whether the package source to be distributed includes a directory for auxiliary files with the same name as the package
- `PackageExports```a [ list](../Type/op_Coredollar_List.mdx) default value {} the entries are names of other packages to load both for the user and for the code of the new package
- `PackageImports```a [ list](../Type/op_Coredollar_List.mdx) default value {} the entries of names of other packages to load just for the code of the new package
- `CacheExampleOutput```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value null whether [installPackage](../Method/installPackage.mdx) should cache (newer) example output in a subdirectory of the auxiliary file directory named `examples` for use in a future installation. This value can be overridden by a value explicitly specified when [installPackage](../Method/installPackage.mdx) is called. After the directory is created it will necessary for the user also to specify ``.
- `OptionalComponentsPresent```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value null whether all optional external components of the package are present on the system. Unless the user sets this option or `CacheExampleOutput` to `true` this option will be initialized to `true`.
- `UseCachedExampleOutput```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value null whether [installPackage](../Method/installPackage.mdx) should copy previously cached example output if it is present and corresponds to the current example input for a node rather than rerunning the examples which might be important if optional external software is not present in the system. This is relevant only when `CacheExampleOutput` and `AuxiliaryFiles` are set to `true`. Unless set by the user it is set to the negation of the value of `OptionalComponentsPresent`.
- `Certification```a [ list](../Type/op_Coredollar_List.mdx) default value null the certification block inserted by the maintainers of *Macaulay2* after the package has been accepted for publication by a journal such as The Journal of Software for Algebra and Geometry: *Macaulay2*. Authors should not undertake to create such a certification block themselves.
- `Configuration```a [ list](../Type/op_Coredollar_List.mdx) default value {} the entries are configuration options for the package. The keys and values should be constant expressions such as strings and integers not incorporating symbols to be exported by the package (and not yet defined). The first time the package is loaded by the user unless the `-q` option is specified on the `M2` command line these options will be stored in a file in the user's application directory (see [applicationDirectory](../Function/applicationDirectory.mdx)). The user can change the configuration by editing the file. The user can override the configuration settings when loading the package; see [loadPackage(...](../Instance/loadPackage(....mdx) and [needsPackage(...](../Instance/needsPackage(....mdx). The file will be overwritten when a newer version of the package with different configuration options is loaded but a backup will be made and the user's settings for the surviving options will be retained.
- `Reload```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value false whether to reload the package if it has been loaded before
- Outputs:
- a [ package](../Type/op_Coredollar_Package.mdx) the new package
- Consequences:
- a package is created
