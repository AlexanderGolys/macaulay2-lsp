# isPrime

**isPrime  -- whether a integer or polynomial is prime**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

Since [factor](../Method/factor.mdx)  returns factors guaranteed only to be pseudoprimes it may be useful to check their primality as follows.Primality testing for integers is handled by [FLINT](../Instance/FLINT.mdx) .

## Installed For

### isPrime([Ideal](../Type/Ideal.mdx))

### isPrime([RingElement](../Type/RingElement.mdx))

### isPrime([ZZ](../Type/ZZ.mdx)) -> [Boolean](../Type/Boolean.mdx)

## Examples

```macaulay2
isPrime f
```

```macaulay2
isPrime(t^2+t+1)

```


```text
false
```

```text

```

```text

```

```text
List
```

## Additional Information

- Inputs:
- `f` an [ integer](../Type/ZZ.mdx) or an element in a [ polynomial ring](../Type/PolynomialRing.mdx)
- Outputs:
- a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) [true](../Instance/op_Coredollar_true.mdx) if `f` is either a prime integer or an irreducible polynomial and [false](../Instance/op_Coredollar_blockMatrixForm.mdx) otherwise
