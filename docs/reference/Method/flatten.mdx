# flatten

**flatten  -- flatten a nested list or a matrix**

**Type:** [MethodFunctionSingle](../Type/MethodFunctionSingle.mdx)

## Description

If `x`  is a list then `flatten x`  effectively removes the braces surrounding any elements of `x`  that happen to be lists.If `x`  is a matrix then `flatten x`  puts the elements of `x`  in a single row *ordered by column* . If `x`  is an $m\times n$ matrix then `flatten x`  is a $1\times mn$ matrix.

## Examples

```macaulay2
flatten x
```

```macaulay2
flatten {{2,3,4}, {{5}, 6}, 7}

```

```text
{2, 3, 4, {5}, 6, 7}

List
```

```macaulay2
flatten m

```

```text
| 2 b2 c a 23 c3 |

             1      6
Matrix R  <-- R
```

## Additional Information

- Inputs:
- `x` a [ list](../Type/op_Coredollar_List.mdx) or [Matrix](../Type/op_Coredollar_Matrix.mdx)
- Outputs:
- a [ list](../Type/op_Coredollar_List.mdx) or matrix obtained by removing braces one level in


### Caveat

The matrix produced by `flatten m`  is *not*  the same as the matrix given by unnesting the list used to define the matrix.
