# homology

**homology  -- general homology functor**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

 Most applications of this functor are dispatched through `HH` . If it is intended that `i`  be of class [ZZ](../Type/ZZ.mdx)  `M`  be of class `A`  and `N`  be of class `B`  then the method for computing `HH_i(MN)`  can be installed with code of the following form.
```
     homology(ZZ A B) := opts -> (iMN) -> ...
```
