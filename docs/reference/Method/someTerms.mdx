# someTerms

**someTerms  -- select some terms of a polynomial**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

 The index i is 0-based and a negative number refers to location from the end of the polynomial. Here is an example where the coefficient ring is also a polynomial ring.

## Installed For

### someTerms([RingElement](../Type/RingElement.mdx), [ZZ](../Type/ZZ.mdx), [ZZ](../Type/ZZ.mdx)) -> [RingElement](../Type/RingElement.mdx)

## Examples

```macaulay2
someTerms(fin)
```

```macaulay2
someTerms(f01) -- the lead term

      2
```

```text
a

R
```

```macaulay2
someTerms(f-11) -- the last term

```

```text
9

R
```

```macaulay2
someTerms(f-22) -- the last 2 terms

```

```text
- 12b + 9

R
```

```macaulay2
someTerms(f-11) -- the last term

      2
```

```text
a  - 2a + 1

S
```

```macaulay2
someTerms(f-22) -- the last 2 terms

        2                       2
```

```text
(2a  - 2a*b - 2a + 2b)x + a  - 2a + 1

S
```

## Additional Information

- Inputs:
- `f` a [ ring element](../Type/RingElement.mdx) in a polynomial ring
- `i` an [ integer](../Type/ZZ.mdx) the starting index
- `n` an [ integer](../Type/ZZ.mdx) the number of terms to select
- Outputs:
- a [ ring element](../Type/RingElement.mdx) the `n` terms of the polynomial `f` starting with the `i` -th one
