# adjoint'

**adjoint'  -- the tensor-Hom adjunction maps**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

Recall that [tensor(Module](../Instance/tensor(Module.mdx) and [Hom(Module](../Instance/Hom(Module.mdx) form an adjoint pair meaning that there is a natural isomorphism $$ \mathrm{Hom}(F\otimes GH) \cong \mathrm{Hom}(F\mathrm{Hom}(GH)). $$
### Synopsis


- Inputs:
- `f` a [ matrix](../Type/op_Coredollar_Matrix.mdx) a homomorphism $F \otimes G \to H$
- `F` a [ module](../Type/op_Coredollar_Module.mdx) a free module;
- `G` a [ module](../Type/op_Coredollar_Module.mdx) a free module;
- Outputs:
- a [ matrix](../Type/op_Coredollar_Matrix.mdx) the adjoint homomorphism $F \to \mathrm{Hom}(GH)$

If `f` is homogeneous and `source f === F ** G` (including the grading) then the resulting matrix will be homogeneous.
### Synopsis


- Inputs:
- `g` a [ matrix](../Type/op_Coredollar_Matrix.mdx) a homomorphism $F \to \mathrm{Hom}(GH)$ between modules
- `G` a [ module](../Type/op_Coredollar_Module.mdx) a free module;
- `H` a [ module](../Type/op_Coredollar_Module.mdx) a free module;
- Outputs:
- a [ matrix](../Type/op_Coredollar_Matrix.mdx) the adjoint homomorphism $F \otimes G \to H$

If `g` is homogeneous and `target g === Hom(GH)` (including the grading) then the resulting matrix will be homogeneous.
