# antipode

**antipode  -- antipode for skew commuting polynomial rings**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

If the ring does not have skew commuting variables antipode is the identify function.If the ring does have skew commuting variables then the antipode returns a new polynomial with the same monomials and the coefficients have been modified to provide an isomorphism with the ring and its opposite ring i.e. this switches left and right modules of the ring.This is implemented in the following simple manner: each monomial which has exactly $d$ skew commuting variables occurring (thus with exponent 1 each) is multiplied by $(-1)^{(d-1)(d-2)/2}$.If the ring has some skew commuting variables and some commutative ones then only the skew ones are considered.The transpose of a matrix applies this function to each entry.  This is basically because the transpose of a left module gives a right module and we need to make that a left module again.  The key reason for this is so that the transpose of a complex remains a complex.If we had not used the antipode then this would be false!

## Additional Information

- Inputs:
- `f` a [ ring element](../Type/RingElement.mdx) An element in any ring
- Outputs:
- a [ ring element](../Type/RingElement.mdx) An element in the same ring the antipode of f


### Caveat

If the ring is a Weyl algebra the antipode is the identity which is probably not what is wanted.  If the ring is a quotient of a skew commuting polynomial ring $R/I$ then the antipode of an element should really be in the quotient ring $R/(antipode(I))$ but this function returns an element in the same ring.
