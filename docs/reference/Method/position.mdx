# position

**position  -- the first element of a list satisfying a condition**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

`position(A f)`  returns the smallest index `i`  such that `f(A#i)`  is true. If no element satisfies the condition[null](../Instance/null.mdx) is returned.Use `position(A B f)`  to return the smallest index `i`  such that `f(A#i B#i)`  is true.The `Reverse`  option will return the largest index instead.Use `position(n f)`  to return the smallest index `i`  such that `f(i)`  is true.To find all indices of elements satisfying the condition see [positions](../Method/op_Coredollar_positions.mdx). To return the elements rather than their indices see [select](../Method/select.mdx). The function [number](../Function/number.mdx) counts the number of elements satisfying the condition.
