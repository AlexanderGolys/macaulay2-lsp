# loadPackage

**loadPackage  -- load a package**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

The file `PackageName.m2` should be on the load [path](../Instance/path.mdx) and should contain a package named `PackageName`.If the variable [notify](../Instance/notify.mdx) is set to true then an informational message is displayed after the file is loaded.If the input is a loaded package then this command will reload the package instead:In fact this version of the command is simply a convenient shortcut for `loadPackage` with the option `Reload` overridden to true.

## Installed For

### loadPackage([Package](../Type/Package.mdx))

### loadPackage([String](../Type/String.mdx)) -> [Package](../Type/Package.mdx)

## Options

- [LoadDocumentation](../Option/LoadDocumentation.mdx) => false
- [Configuration](../Method/Configuration.mdx) => {}
- [FileName](../Option/FileName.mdx) => null
- [Reload](../Method/Reload.mdx) => null
- [DebuggingMode](../Method/DebuggingMode.mdx) => null

## Examples

```macaulay2
loadPackage PackageName
```

```macaulay2
loadPackage "FirstPackage"
 -- loading FirstPackage.m2
 -- opening database /usr/lib/Macaulay2/FirstPackage/cache/rawdocumentation-dcba-8.db
 -- beginDocumentation: using documentation database skipping the rest of /usr/share/Macaulay2/FirstPackage.m2
 -- package "FirstPackage" loaded
 -- loaded /usr/share/Macaulay2/FirstPackage.m2

```

```text
FirstPackage

Package
```

```macaulay2
loadPackage FirstPackage
 -- warning: reloading FirstPackage; recreate instances of types from this package
 -- closing database /usr/lib/Macaulay2/FirstPackage/cache/rawdocumentation-dcba-8.db
 -- loading FirstPackage.m2
 -- opening database /usr/lib/Macaulay2/FirstPackage/cache/rawdocumentation-dcba-8.db
 -- beginDocumentation: using documentation database skipping the rest of /usr/share/Macaulay2/FirstPackage.m2
 -- package "FirstPackage" loaded
 -- loaded /usr/share/Macaulay2/FirstPackage.m2

```

```text
FirstPackage

Package
```

## Additional Information

- Inputs:
- `PackageName` a [ string](../Type/op_Coredollar_String.mdx) the name of the package or a [Package](../Type/op_Coredollar_Package.mdx) object
- [ Optional inputs](../Instance/using functions with optional inputs.mdx):
- `FileName```a [ string](../Type/op_Coredollar_String.mdx) default value null the name of the file containing the source code of the package from which it should be loaded
- `LoadDocumentation```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value false whether to load the documentation of the package too; see [beginDocumentation](../Function/beginDocumentation.mdx)
- `DebuggingMode```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value null the value of [debuggingMode](../Instance/debuggingMode.mdx) during loading the package; specifying it here overrides the value specified as an option to [newPackage](../Method/op_Coredollar_newPackage.mdx) by the package itself; however if [debuggingMode](../Instance/debuggingMode.mdx) is already `false` it will remain so.
- `Configuration```a [ list](../Type/op_Coredollar_List.mdx) default value {} the entries are options `` overriding the defaults specified in the source code of the package and the (possibly updated) values in the file in the user's application directory.
- `Reload```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value null whether to reload the package if it has been loaded before. If the input was an already loaded [Package](../Type/op_Coredollar_Package.mdx) this is automatically set to true.
- Outputs:
- a [ package](../Type/op_Coredollar_Package.mdx) the package just loaded; if the input was an already loaded [Package](../Type/op_Coredollar_Package.mdx) this is the reloaded package
- Consequences:
- Loads (or reloads) the package `PackageName` that is in the file `PackageName.m2`.
