# isFreeModule

**isFreeModule  -- whether something is a free module**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

 This function checks if the module `M`  is equal to its [ambient](../Method/op_Coredollar_ambient.mdx)  free module by examining its matrix of [ generators](../Instance/generators(Module).mdx)  and its matrix of [ relations](../Instance/relations(Module).mdx) . To determine whether `M`  is isomorphic to a free module use [prune](../Method/prune.mdx)  `M` .

## Installed For

### isFreeModule([Module](../Type/Module.mdx))

### isFreeModule([Thing](../Type/Thing.mdx)) -> [Boolean](../Type/Boolean.mdx)

## Examples

```macaulay2
isFreeModule M
```

```macaulay2
isFreeModule M

```

```macaulay2
isFreeModule prune M

```

```text
true
```

## Additional Information

- Inputs:
- `M` a [ thing](../Type/Thing.mdx)
- Outputs:
- a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) [true](../Instance/op_Coredollar_true.mdx) if the given representation of `M` is a free module and [false](../Instance/op_Coredollar_blockMatrixForm.mdx) otherwise
