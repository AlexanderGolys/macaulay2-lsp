# baseRing

**baseRing  -- produce the ring from which a ring was formed**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

The base ring of a ring `R`  is the ring from which `R`  was formed. For example if `R`  is a quotient ring of the form `S/I`  or if `R`  is a fraction ring of the form `frac S`  or if `R`  is a polynomial ring over `S`  then the base ring is `S` .The entire chain of base rings can be obtained under the key [baseRings](../Instance/baseRings.mdx) .
