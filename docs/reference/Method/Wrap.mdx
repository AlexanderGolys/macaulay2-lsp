# Wrap

**Wrap  -- a key for methods for wrapping printed output**

**Type:** [Symbol](../Type/Symbol.mdx)

## Description

 The default method for printing results of computations (stored in `Thing#{Standard,Print}` ) searches for a method for wrapping the output by search in the class of the result (and its ancestors) for a function stored under the key `Wrap` .  The preinstalled wrapping methods use [wrap](../Function/op_Coredollar_wrap.mdx)  they differ in their choice of separator between wrapped lines or in whether to wrap at all.
