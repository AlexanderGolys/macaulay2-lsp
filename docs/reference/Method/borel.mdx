# borel

**borel  -- make a Borel fixed submodule**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

`borel m`  -- make a Borel fixed submodule Yields the matrix with the same target as the matrix `m`  whose columns generate the smallest Borel fixed submodule containing the lead monomials of the columns of `m` .  If `m`  is a monomial ideal then the minimal Borel fixed monomial ideal containing it is returned. For example if R = ZZ/101[a..f] then
