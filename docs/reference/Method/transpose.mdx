# transpose

**transpose  -- transpose a matrix or table**

**Type:** [MethodFunctionSingle](../Type/MethodFunctionSingle.mdx)

## Description

 Here is an example. The output of `transpose`  is a map between the duals of the original source and target free modules. See:

### transpose([List](../Type/List.mdx))

### transpose([Matrix](../Type/Matrix.mdx)) -> [Matrix](../Type/Matrix.mdx)

### transpose([MutableMatrix](../Type/MutableMatrix.mdx))

## Examples

```macaulay2
transpose f
```

```macaulay2
g = transpose f

```

```text
{-3} | x3  x2y |
     {-3} | xy2 y3  |
     {-1} | x   y   |

             3      2
Matrix S  <-- S
```

```macaulay2
transpose entries f

        3   2        2   3
```

```text
{{x , x y}, {x*y , y }, {x, y}}

List
```

## Additional Information

- Inputs:
- `f` a [ matrix](../Type/op_Coredollar_Matrix.mdx) or a [ list](../Type/op_Coredollar_List.mdx) which is a table
- Outputs:
- a [ matrix](../Type/op_Coredollar_Matrix.mdx) the transpose of `f`


### Caveat

`transpose`  works only for maps between free modules. Use `dual`  for more general maps.
