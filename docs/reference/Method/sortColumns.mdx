# sortColumns

**sortColumns  -- permutation giving sort order**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

 See [sort(Matrix)](../Instance/sort(Matrix).mdx)  for the ordering used.  The meanings of the optional parameters is also the same.

## Installed For

### sortColumns([Matrix](../Type/Matrix.mdx))

## Options

- [MonomialOrder](../Option/MonomialOrder.mdx) => Ascending
- [DegreeOrder](../Option/DegreeOrder.mdx) => null
