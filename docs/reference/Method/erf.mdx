# erf

**erf  -- error function**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

The https://en.wikipedia.org/wiki/error_function error function \(\operatorname{erf} x = \frac{2}{\sqrt\pi}\int_0^x e^{-t^2}\dt\).
