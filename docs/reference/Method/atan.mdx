# atan

**atan  -- compute the arctangent of a number**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

atan  -- compute the arctangent of a number

### atan([Number](../Type/Number.mdx))

### atan([RR](../Type/RR.mdx)) -> [RR](../Type/RR.mdx)

## Examples

```macaulay2
atan x
atan I
```

```macaulay2
atan 1

```

```

```

```text
true
```

## Additional Information

- Inputs:
- `x` a [ real number](../Type/op_x226_x132_x157.mdx)
- `I` a [ real interval](../Type/RRi.mdx)
- Outputs:
- a [ real number](../Type/op_x226_x132_x157.mdx) the arctangent (in radians) of `x`
- a [ real interval](../Type/RRi.mdx) an interval containing the arctangents of the points of `I`
