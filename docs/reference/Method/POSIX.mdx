# POSIX

**POSIX  -- evaluate a regular expression search**

**Type:** [Symbol](../Type/Symbol.mdx)

## Description

The value returned is a list of pairs of integers corresponding to the parenthesized subexpressions successfully matched suitable for use as the first argument of [substring](../Function/op_Coredollar_substring.mdx). The first member of each pair is the offset within `str` of the substring matched and the second is the length.See [regular expressions](../Instance/regular expressions.mdx) for a brief introduction to the topic.By default the regular expressions are interpreted using the Perl flavor which supports features such as lookaheads and lookbehinds for fine-tuning the matches. This syntax is used in Perl and JavaScript languages.Alternatively one can choose the POSIX Extended flavor of regex using ``. This syntax is similar to the one used by the Unix utilities `egrep` and `awk` and enforces the leftmost longest rule for finding matches. If there's a tie the rule is applied to the first subexpression.In the Perl flavor one can specify whether repetitions should be possessive or non-greedy.

## Examples

```macaulay2
regex(re str)
regex(re start str)
regex(re start range str)
```

## Additional Information

- Inputs:
- `re` a [ string](../Type/op_Coredollar_String.mdx) a [ regular expression](../Instance/regular expressions.mdx) describing a pattern
- `start` an [ integer](../Type/ZZ.mdx) positive the position in `str` at which to begin the search. when omitted the search starts at the beginning of the string.
- `range` an [ integer](../Type/ZZ.mdx) restricts matches to those beginning at a position between `start` and `start + range`; when 0 the pattern is matched only at the starting position; when negative only positions to the left of the starting position are examined for matches; when omitted the search extends to the end of the string.
- `str` a [ string](../Type/op_Coredollar_String.mdx) the subject string to be searched
- [ Optional inputs](../Instance/using functions with optional inputs.mdx):
- `POSIX```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value false if true interpret the `re` using the POSIX Extended flavor otherwise the Perl flavor
- Outputs:
- a [ list](../Type/op_Coredollar_List.mdx) a list of pairs of integers; each pair denotes the beginning position and the length of a substring. Only the leftmost matching substring of `str` and the capturing groups within it are returned. If no match is found the output is [null](../Instance/null.mdx).
