# saturate

**saturate  -- saturation of ideal or submodule**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

If $I$ is either an ideal or a submodule of a module $M$ the saturation $I : J^\infty$ is defined to be the set of elements $f$ in the ring or $M$ such that $f J^N$ is contained in $I$ for some $N$ large enough.For example one way to homogenize an ideal is to homogenize the generators and then saturate with respect to the homogenizing variable.We can use this command to remove graded submodules of finite length.If $I$ and $J$ are both monomial ideals then a faster algorithm is used. Otherwise when needed Gröbner bases will be computed and if the computation succeeds the result is cached inside the first argument. Partial computations are not yet cached but this may change in a future version.

## Additional Information

- Inputs:
- `I` an [ ideal](../Type/op_Coredollar_Ideal.mdx) a [ monomial ideal](../Type/op_Coredollar_MonomialIdeal.mdx) or a [ module](../Type/op_Coredollar_Module.mdx)
- `J` an [ ideal](../Type/op_Coredollar_Ideal.mdx) a [ monomial ideal](../Type/op_Coredollar_MonomialIdeal.mdx) a [ module](../Type/op_Coredollar_Module.mdx) or a [ ring element](../Type/RingElement.mdx) if not present then the ideal generated by the variables of the ring is used
- [ Optional inputs](../Instance/using functions with optional inputs.mdx):
- [](../Instance/saturate(....mdx)``a [ thing](../Type/Thing.mdx) default value null specifies the algorithm
- `MinimalGenerators```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value true indicates whether the output should be [ trimmed](../Method/op_Coredollar_trim.mdx)
- `BasisElementLimit```an [ integer](../Type/ZZ.mdx) default value infinity passed onto [gb(...](../Instance/gb(....mdx);
- `DegreeLimit```a [ list](../Type/op_Coredollar_List.mdx) default value {} passed onto [gb(...](../Instance/gb(....mdx);
- `PairLimit```an [ integer](../Type/ZZ.mdx) default value infinity passed onto [gb(...](../Instance/gb(....mdx);
- Outputs:
- an [ ideal](../Type/op_Coredollar_Ideal.mdx) or a [ module](../Type/op_Coredollar_Module.mdx) the saturation $I:J^\infty = \{f | f J^N\subset I \text{ for some } N>0\}$
