# switch

**switch  -- copy a list switching two elements**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

A negative value of `i`  or `j`  is taken relative to the end of the list.

## Installed For

### switch([ZZ](../Type/ZZ.mdx), [ZZ](../Type/ZZ.mdx), [BasicList](../Type/BasicList.mdx)) -> [BasicList](../Type/BasicList.mdx)

## Examples

```macaulay2
switch(i j L)
```

```macaulay2
switch(3 9 L)
```

## Additional Information

- Inputs:
- `i` an [ integer](../Type/ZZ.mdx)
- `j` an [ integer](../Type/ZZ.mdx)
- `L` a [ basic list](../Type/op_Coredollar_BasicList.mdx)
- Outputs:
- `L2` a [ basic list](../Type/op_Coredollar_BasicList.mdx) a copy of the list `L` with the elements in positions `i` and `j` interchanged.
