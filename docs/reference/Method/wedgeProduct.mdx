## Additional Information

- Inputs:
- `p` an [ integer](../Type/ZZ.mdx)
- `q` an [ integer](../Type/ZZ.mdx)
- `F` a [ module](../Type/op_Coredollar_Module.mdx) a free module
- Outputs:
- a [ matrix](../Type/op_Coredollar_Matrix.mdx) representing the multiplication map from `exteriorPower(pM) ** exteriorPower(qM)` to `exteriorPower(p+qM)`
