# promote

**promote  -- promote to another ring**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

Promote the given ring element or matrix `f`  to an element or matrix of `R`  via the natural map to `R` . This is semantically equivalent to creating the natural ring map from `ring f --> R`  and mapping f via this map.Promotion of real numbers to rational numbers is accomplished by using all of the bits of the internal representation.For promotion of ring elements there is the following shorter notation.If you wish to promote a module to another ring either promote the corresponding matrices use the natural ring map or use tensor product of matrices or modules. A special feature is that if `f`  is rational and `R`  is not an algebra over [QQ](../Type/op_x226_x132_x154.mdx)  then an element of `R`  is provided by attempting the evident division.
