## Additional Information

- Inputs:
- `M` a [ module](../Type/op_Coredollar_Module.mdx) or an [ ideal](../Type/op_Coredollar_Ideal.mdx)
- Outputs:
- a [ module](../Type/op_Coredollar_Module.mdx) the quotient module `N/M` if `M` is given as a submodule $M \subset N$ where `N` is either a free module or a quotient of a free module.
