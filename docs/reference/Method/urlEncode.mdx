# urlEncode

**urlEncode  -- URL encoding**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

Encode all of the characters in a URL except for "/" ":" "#" and the "unreserved characters" specified by https://www.rfc-editor.org/rfc/rfc3986.html RFC 3986 i.e. the alphanumeric characters "-" "." "_" and "~" using https://en.wikipedia.org/wiki/percent-encoding percent-encoding a "%" followed by two hexadecimal digits representing the ASCII encoding of the character.

## Installed For

### urlEncode([Nothing](../Type/Nothing.mdx))

### urlEncode([String](../Type/String.mdx)) -> [String](../Type/String.mdx)

## Examples

```macaulay2
urlEncode s
```

```macaulay2
urlEncode "https://en.wikipedia.org/wiki/Gröbner basis"

```

```text
https://en.wikipedia.org/wiki/Gr%C3%B6bner%20basis
```
