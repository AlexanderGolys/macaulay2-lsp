# sublists

**sublists  -- process interspersed subsequences of a visible list**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

In the first example consecutive odd elements are grouped into sublists while each even element is negated.If `g`  or `h`  is omitted the [identity](../Function/identity.mdx) function is used in its place.The sublists will belong to the same class as `L` .Note that `g`  acts on the *sublists*  not their elements.Because of the grouping of consecutive elements that return `true`  when input to `f`  `sublists(L f g h)`  is NOT the same as applying `g`  to elements returning `true`  and applying `h`  to elements returning false. This could be achieved with a simple [if](../Method/if.mdx)-then-else loop or with [apply](../Function/op_Coredollar_apply.mdx).On the other hand if we want to group both "true" and "false" elements into sublists we can achieve this with a second call to `sublists`  selecting those elements not already grouped by the first `sublists`  command *as long as the original list was not nested* .

## Additional Information

- Inputs:
- `L` a [ visible list](../Type/VisibleList.mdx)
- `f` a [ function](../Type/Function.mdx) returning Boolean values
- `g` a [ function](../Type/Function.mdx) which acts on VisibleLists applied to sublists of `L` with `f(i)` true for each `i` in the sublist
- `h` a [ function](../Type/Function.mdx) which acts on elements of `L` applied to the elements `i` of `L` with `f(i)` false
- Outputs:
- a [ list](../Type/op_Coredollar_List.mdx) the result obtained by applying `g` to each of the maximal nonempty sequences of consecutive elements with `f` true and applying `h` to the other elements
