# isQuotientModule

**isQuotientModule  -- whether something is evidently a quotient of a free module**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

 This function checks if the module `M`  is a quotient of its [ambient](../Method/op_Coredollar_ambient.mdx)  free module by examining its matrix of [ generators](../Instance/generators(Module).mdx) . The image of a map from a free module to the first generator of `M`  yields an equivalent module that is *not*  presented as a quotient.
