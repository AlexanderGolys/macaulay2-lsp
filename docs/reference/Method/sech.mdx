- `x`
- `I` a [ real interval](../Type/RRi.mdx)

- a [ real number](../Type/op_x226_x132_x157.mdx) the hyperbolic secant of `x`
- a [ real interval](../Type/RRi.mdx) an interval containing the hyerbolic secants of the points of `I`
