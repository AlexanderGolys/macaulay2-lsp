# homomorphism

**homomorphism  -- get the homomorphism from element of Hom**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

When `H = Hom(MN)` is computed information about computing the morphisms corresponding to its elements is stored in `H`.The source and target are what they should be.Except for a possible redistribution of degrees between the map and modules we can undo the process with [homomorphism'](../Method/op_Coredollar_homomorphismprime.mdx).After [ pruning](../Instance/minimalPresentation(Module).mdx) a Hom module one cannot use homomorphism directly. Instead first apply the pruning map:

## Additional Information

- Inputs:
- `f` a [ vector](../Type/op_Coredollar_Vector.mdx) or a [ matrix](../Type/op_Coredollar_Matrix.mdx) corresponding to an element in $\mathrm{Hom}(MN)$ or a map $R^1 \to \mathrm{Hom}(MN)$
- Outputs:
- a [ matrix](../Type/op_Coredollar_Matrix.mdx) the map $M \to N$ corresponding to the element $f \in \mathrm{Hom}(MN)$
