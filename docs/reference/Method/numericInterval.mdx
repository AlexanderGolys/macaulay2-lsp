# numericInterval

**numericInterval  -- convert a constant to an interval**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

Constructs an interval containing `c`  of either the [defaultPrecision](../Instance/defaultPrecision.mdx) or precision `prec`

## Installed For

### numericInterval([Constant](../Type/Constant.mdx))

### numericInterval([ZZ](../Type/ZZ.mdx), [Constant](../Type/Constant.mdx))

## Examples

```macaulay2
I = numericInterval(c)
I = numericInterval(precc)
```

## Additional Information

- Inputs:
- `c` an instance of the type [Constant](../Type/Constant.mdx)
- `prec` an [ integer](../Type/ZZ.mdx)
- Outputs:
- `I` a [ real interval](../Type/RRi.mdx)
