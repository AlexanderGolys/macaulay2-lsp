# Heading

**Heading  -- a standardized synopsis for use in documentation nodes**

**Type:** [Symbol](../Type/Symbol.mdx)

## Description

This function prepares a standardized synopsis in hypertext for use in documentation nodes. Here is an empty template for use with `SYNOPSIS`.The options are used just as with [document](../Method/document.mdx). Here is an example of its use.See the `Synopsis` keyword in [doc(String)](../Instance/doc(String).mdx) for usage as a keyword in that format.

## Examples

```macaulay2
SYNOPSIS ( ... ... )
```
