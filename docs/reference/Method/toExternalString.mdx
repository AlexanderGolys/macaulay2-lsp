# toExternalString

**toExternalString  -- convert to a readable string**

**Type:** [MethodFunctionSingle](../Type/MethodFunctionSingle.mdx)

## Description

 See also [toString](../Method/toString.mdx)  which simply converts `x`  to a string that can be displayed meaningfully. Matrices and ring elements are linearized

## Examples

```macaulay2
toExternalString x
```

```macaulay2
toExternalString R

```

```text
QQ[x_1..x_5
```

```macaulay2
toExternalString oo

```

```text
x_1^3-(3/4)*x_3*x_5
```

## Additional Information

- Inputs:
- `x` any Macaulay2 object
- Outputs:
- a [ string](../Type/op_Coredollar_String.mdx) a string representation of `x` which can be used in conjunction with [value](../Method/value.mdx) to read the object back into the program later


### Caveat

 Not everything can be converted to a string in such a way that it can be read back into the program later.
