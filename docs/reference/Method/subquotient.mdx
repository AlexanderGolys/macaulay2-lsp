# subquotient

**subquotient  -- make a subquotient module**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

If `g`  is omitted then the identity map on the target of `r`  is used as `g`  and the cokernel of `r`  is returned. If `r`  is omitted (but not the comma) then a zero map to the target of `g`  is used as `r`  and the image of `g`  is returned. If both are omitted then `M`  is returned.See [subquotient modules](../Instance/subquotient modules.mdx)  for an overview of subquotient modules in Macaulay2.The general form in which modules are represented in Macaulay2 is as subquotients and subquotient modules are often returned as values of computations as in the example below.

## Additional Information

- Inputs:
- `g` the matrix of generators
- `r` the matrix of relations with the same target as `g`
- `M` a [ module](../Type/op_Coredollar_Module.mdx) if given must be the common target of g and r
- Outputs:
- the image of `g` in the cokernel of `r`
