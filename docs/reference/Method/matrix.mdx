# matrix

**matrix  -- make a matrix**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

 The simplest use of this function is to define a matrix by giving a doubly nested list of ring elements.  One may also explicitly provide the ring or give a matrix as a doubly-nested list of matrices. The [map](../Method/op_Coredollar_map.mdx)  function provides other methods to define a matrix.

## Examples

```macaulay2
matrix{{1,2,3},{4,5,6}}

```

```text
| 1 2 3 |
     | 4 5 6 |

              2       3
Matrix ZZ  <-- ZZ
```

```macaulay2
matrix{{x,0,2},{1,2,y}}

```

```text
| x 0 2 |
     | 1 2 y |

             2      3
Matrix R  <-- R
```
