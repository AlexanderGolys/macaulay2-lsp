# generator

**generator  -- provide a single generator**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

If the number of apparent generators is greater than 1 then [trim](../Method/op_Coredollar_trim.mdx)  will be called.

## Installed For

### generator([Ideal](../Type/Ideal.mdx))

### generator([Module](../Type/Module.mdx))

## Examples

```macaulay2
generator I
```

```macaulay2
generator I

```

```text
2
```

```macaulay2
generator M

```

```text
| 2 |
     | 0 |

Vector
```

## Additional Information

- Inputs:
- `I` an [ ideal](../Type/op_Coredollar_Ideal.mdx) or a [ module](../Type/op_Coredollar_Module.mdx)
- Outputs:
- the single generator of `I` if it has just one
