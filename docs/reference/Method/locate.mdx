# locate

**locate  -- locate source code**

**Type:** [MethodFunctionSingle](../Type/MethodFunctionSingle.mdx)

## Description

For a symbol interpreted function `f`  returns a `nicjdke`  describing the location of the definition in the source code:The name of the source file is `n` ;the code occupies line `i`  column `c`  through line `j`  column `d` ;the central point of interest located at line `k`  column `e` .If `f`  is a sequence then [lookup](../Function/op_Coredollar_lookup.mdx) is applied first and the location of the resulting function is provided.In particular the output of [methods](../Method/op_Coredollar_methods.mdx) can be used as an input to `locate`.If the function `f`  is compiled or if `f`  is [null](../Instance/null.mdx) then a location is not available and [null](../Instance/null.mdx) is returned.

## Examples

```macaulay2
locate f
```

```macaulay2
locate needs

```

```text
/usr/share/Macaulay2/Core/Core.m2:148:8-148:68

FilePosition
```


```text
FilePosition
```


```text
FilePosition
```
