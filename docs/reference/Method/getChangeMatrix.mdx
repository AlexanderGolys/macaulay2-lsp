# getChangeMatrix

**getChangeMatrix  -- get the change of basis matrix**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

`getChangeMatrix G`  -- for a Gröbner basis G return the change of basis matrix from the Gröbner basis to another generating set usually a minimal or original generating set. The option [ChangeMatrix](../Method/op_Coredollar_ChangeMatrix.mdx)  can be used with [gb](../Method/gb.mdx)  to enable the computation of the change of basis matrix.
