# AfterPrint

**AfterPrint  -- top level method applied after printing**

**Type:** [Symbol](../Type/Symbol.mdx)

## Description

 This method is used to print the type of the result of a computation. We could suppress that output for a single type as follows.

## Examples

```macaulay2
X#{topLevelMode,AfterPrint} = f
```

```macaulay2
QQ#{topLevelMode,AfterPrint} = r -> r;
```

## Additional Information

- Inputs:
- `f` a function to be applied after printing a top-level evaluation result `r` of type `X`.
- Outputs:
- The value returned by `f` is discarded.
