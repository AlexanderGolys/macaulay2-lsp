# findHeft

**findHeft  -- find a heft vector for a list of degrees**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

`findHeft` returns a weight co-vector whose dot product with each member of `degs` is strictly positive.

## Installed For

### findHeft([List](../Type/List.mdx)) -> [List](../Type/List.mdx)

## Options

- [DegreeGroup](../Option/DegreeGroup.mdx) => null
- [DegreeRank](../Method/DegreeRank.mdx) => null

## Examples

```macaulay2

```

```macaulay2
findHeft({{-1,0}, {2,1}}
```

```macaulay2
findHeft({}
```
