# newCoordinateSystem

**newCoordinateSystem  -- change variables**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

`newCoordinateSystem(Sm)`  -- takes a one-rowed matrix `m`  of independent linear forms over a ring `R`  and returns a pair `(fg)`  where `f`  is a ring map given by some linear change of coordinates from `R`  to `S`  which sends the last variables of `R`  to the forms in `m`  and `g`  is the inverse of `f` . The ring `S`  should have the same number of variables as `S` .

## Installed For

### newCoordinateSystem([PolynomialRing](../Type/PolynomialRing.mdx), [Matrix](../Type/Matrix.mdx))

## Examples

```macaulay2
(fg) = newCoordinateSystem(Smatrix{{a+2*b,3*c-d}});
```
