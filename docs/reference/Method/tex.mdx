# tex

**tex  -- convert to $\TeX$ format**

**Type:** [MethodFunctionSingle](../Type/MethodFunctionSingle.mdx)

## Description

tex  -- convert to $\TeX$ format

## Installed For

### tex([Net](../Type/Net.mdx))

### tex([Nothing](../Type/Nothing.mdx))

### tex([RowExpression](../Type/RowExpression.mdx))

### tex([String](../Type/String.mdx))

### tex([Thing](../Type/Thing.mdx))

## Examples

```macaulay2
tex x
```

```macaulay2
tex matrix {{a^2+2,b,c},{d,e,f^3-a}}

```

```text
$\left(\!\begin{array}{ccc}
     a^{2}+2&b&c\\
     d&e&f^{3}-a
     \end{array}\!\right)$
```

## Additional Information

- Inputs:
- `x` any Macaulay2 object
- Outputs:
- a [ string](../Type/op_Coredollar_String.mdx) `x` converted to $\TeX$ format


### Caveat

 No attempt is made to wrap large matrices or equations.
