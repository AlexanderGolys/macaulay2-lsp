# monoid

**monoid  -- make or retrieve a monoid**

**Type:** [MethodFunctionSingle](../Type/MethodFunctionSingle.mdx)

## Description

The function [monoid](../Method/monoid.mdx) is called whenever a polynomial ring is created see [Ring Array](../Instance/Ring Array.mdx) or when a local polynomial ring is made see [Ring List](../Instance/Ring List.mdx). Some of the options provided when making a monoid don't take effect until the monoid is made into a polynomial ring.Let's make a free ordered commutative monoid on the variables `abc` with degrees 2 3 and 4 respectively.Call [use](../Method/op_Coredollar_use.mdx) to assign the variables their values in the monoid.The options used when the monoid was created can be recovered with [options](../Method/op_Coredollar_options.mdx).The variables listed may be symbols or indexed variables. The values assigned to these variables are the corresponding monoid generators. The function [baseName](../Method/baseName.mdx) may be used to recover the original symbol or indexed variable.The [monoid(...](../Instance/monoid(....mdx) option is used for instance by [Ext(Module](../Instance/Ext(Module.mdx).By default (multi)degrees are concatenated when forming polynomial rings over polynomial rings as can be seen by examining the corresponding flattened monoid which displays information about all of the variables.That behavior can be overridden with the [monoid(...](../Instance/monoid(....mdx) option.
