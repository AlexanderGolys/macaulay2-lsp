# hilbertSeries

**hilbertSeries  -- compute the Hilbert series**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

 The Hilbert series is the formal power series in the variables of the degrees ring whose coefficients are the dimensions of the corresponding graded component. Note that the series is provided as a type of expression called a [Divide](../Type/op_Coredollar_Divide.mdx) .
