# Complement

**Complement  -- a Strategy option value**

**Type:** [Symbol](../Type/Symbol.mdx)

## Description

 The standard (default) strategy for [mingens](../Method/op_Coredollar_mingens.mdx)  or [trim](../Method/op_Coredollar_trim.mdx)  is [Complement](../Method/op_Coredollar_Complement.mdx)  at least in the case where the module (or ideal) is homogeneous and the ring is (quotient ring of) a polynomial ring over a field.  The other strategy [Inhomogeneous](../Method/op_Coredollar_Inhomogeneous.mdx)  is experimental.
