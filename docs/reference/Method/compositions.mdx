# compositions

**compositions  -- list the compositions of an integer**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

To find all unordered compositions we can use [sort](../Method/op_Coredollar_sort.mdx) or [rsort](../Method/op_Coredollar_rsort.mdx) to put each composition into a standard form then use the function [unique](../Method/op_Coredollar_unique.mdx) to remove duplicates.In the next example we use [select](../Method/select.mdx) to find all the compositions of 18 into 5 parts with each part greater than or equal to 3.For partitions of `n`  into unordered *strictly positive*  parts use [partitions](../Method/op_Coredollar_partitions.mdx) instead.If a negative integer is given for `n`  an empty list is returned. If a negative integer is given for `k`  it will cause an error.

## Additional Information

- Inputs:
- `k` an [ integer](../Type/ZZ.mdx) a nonnegative integer the number of parts in each composition
- `n` an [ integer](../Type/ZZ.mdx) a nonnegative integer the sum of each composition (if omitted assumed to be also $k$)
- Outputs:
- a [ list](../Type/op_Coredollar_List.mdx) of all ordered lists of `k` nonnegative integers that sum to `n`
