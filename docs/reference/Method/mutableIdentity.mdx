## Additional Information

- Inputs:
- `R` a [ ring](../Type/Ring.mdx)
- `nrows` an [ integer](../Type/ZZ.mdx)
- [ Optional inputs](../Instance/using functions with optional inputs.mdx):
- `Dense````...` default value true whether the encoding of the matrix should be dense or not: see [MutableMatrix](../Type/op_Coredollar_MutableMatrix.mdx)
- Outputs:
- a [ mutable matrix](../Type/op_Coredollar_MutableMatrix.mdx) an `nrows` by `nrows` mutable identity matrix filled with elements of the ring `R`
