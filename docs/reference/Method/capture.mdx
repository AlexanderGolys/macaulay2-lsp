# capture

**capture  -- evaluate Macaulay2 code and capture the output**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

This function evaluates the given Macaulay2 code within the same process in order to speed up tasks such as generating example results or checking the package tests.If `` given the dictionaries available to the user will not be affected by the evaluation and [collectGarbage](../Function/collectGarbage.mdx) is called afterwards.Errors occurred while evaluating `str` do not cause an error outside of `capture`.Certain examples or tests might not be compatible with `capture`. In such cases use the string `-* no-capture-flag *-` somewhere within `str` so that the code is run in a separate Macaulay2 subprocess instead.

## Additional Information

- Inputs:
- `str` a [ net](../Type/op_Coredollar_Net.mdx) a [ list](../Type/op_Coredollar_List.mdx) a [ string](../Type/op_Coredollar_String.mdx) or a [ test input](../Type/op_Coredollar_TestInput.mdx) the Macaulay2 code to be evaluated
- [ Optional inputs](../Instance/using functions with optional inputs.mdx):
- `UserMode```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value true indicates whether currently loaded packages and exported symbols should be accessible while `str` is being evaluated.
- `PackageExports```a [ list](../Type/op_Coredollar_List.mdx) default value null of packages to be loaded before evaluating `str`. The current package as given by [Macaulay2Doc](../Instance/Macaulay2Doc.mdx) will be included.
- Outputs:
- `err` a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) whether the evaluation was interrupted because of an error
- `output` a [ string](../Type/op_Coredollar_String.mdx) the result of the evaluation
