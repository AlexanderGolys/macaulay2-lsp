# leadCoefficient

**leadCoefficient  -- the coefficient of the leading term**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

The leading term is with respect to the monomial ordering in the ring. See [monomial orderings](../Instance/monomial orderings.mdx) for details.

## Installed For

### leadCoefficient([RingElement](../Type/RingElement.mdx)) -> [RingElement](../Type/RingElement.mdx)

## Examples

```macaulay2
leadCoefficient f
```

```macaulay2
leadCoefficient f

```

```text
     ZZ
--
      5
```

```macaulay2
leadCoefficient g

```

```text
1

     ZZ

      5
```

## Additional Information

- Inputs:
- `f` a [ ring element](../Type/RingElement.mdx) a polynomial
- Outputs:
- a [ ring element](../Type/RingElement.mdx) an element of the [coefficientRing](../Method/op_Coredollar_coefficientRing.mdx) of the ring of `f`
