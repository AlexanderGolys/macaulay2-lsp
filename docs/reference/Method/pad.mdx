# pad

**pad  -- pad a string or net with spaces**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

`pad(sn)` pads the string or net `s` to length `n` with spaces on the right.`pad(ns)` pads the string or net `s` to length `n` with spaces on the left.

## Installed For

### pad([Net](../Type/Net.mdx), [ZZ](../Type/ZZ.mdx))

### pad([String](../Type/String.mdx), [ZZ](../Type/ZZ.mdx))

### pad([ZZ](../Type/ZZ.mdx), [Net](../Type/Net.mdx))

### pad([ZZ](../Type/ZZ.mdx), [String](../Type/String.mdx))

## Examples

```macaulay2
pad(sn)
pad(ns)
```

```macaulay2
pad(6 "foo")

```

```text
foo
```

```macaulay2
pad("foo" 6) | "bar"

```

```text
foo   bar
```

## Additional Information

- Inputs:
- `s` a [ net](../Type/op_Coredollar_Net.mdx)
- `n` an [ integer](../Type/ZZ.mdx)
