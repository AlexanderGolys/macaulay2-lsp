# columnPermute

**columnPermute  -- permute some columns**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

columnPermute  -- permute some columns

## Installed For

### columnPermute([MutableMatrix](../Type/MutableMatrix.mdx), [ZZ](../Type/ZZ.mdx), [List](../Type/List.mdx))

## Examples

```macaulay2
columnPermute(mi{...})
```

```macaulay2
columnPermute(m1{2,0,1})

```

```text
| 0   3   1   2   4   5   |
     | 100 103 101 102 104 105 |
     | 200 203 201 202 204 205 |
     | 300 303 301 302 304 305 |
     | 400 403 401 402 404 405 |

MutableMatrix
```

## Additional Information

- Inputs:
- `m` a [ mutable matrix](../Type/op_Coredollar_MutableMatrix.mdx)
- `i` an [ integer](../Type/ZZ.mdx) starting column
- a list of integers denoting a permutation of `0..d` for some number `d`
- Consequences:
- If the permutation is `{p0,p1,...,pd}` then `m` is modified so that the `i+j` column becomes the `i+pj` column of the original matrix for `j=0..d`
