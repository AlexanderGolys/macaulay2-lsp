# SVD

**SVD  -- singular value decomposition of a matrix**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

 If `Sigma`  is the diagonal `m`  by `n`  matrix whose `(ii)`  entry is the `i` -th element of `S`  then `M = U Sigma Vt` .  This is the singular value decomposition of `M` .  The entries of `S`  are (up to roundoff error) the eigenvalues of the Hermitian matrix `M * (conjugate transpose M)` M may also be a [MutableMatrix](../Type/op_Coredollar_MutableMatrix.mdx)  in which case the returned values `U`  and `Vt`  are also [ mutable matrices](../Type/op_Coredollar_MutableMatrix.mdx) . If `M`  is over [CC](../Type/op_x226_x132_x130.mdx)  then `U`  and `Vt`  are unitary matrices over [CC](../Type/op_x226_x132_x130.mdx) . If `M`  is over [RR](../Type/op_x226_x132_x157.mdx)  `U`  and `Vt`  are orthogonal over `RR` . We can clean the small entries from the result above with [clean](../Method/clean.mdx) . Alternatively if the only issue is display of the matrix we may set the printing accuracy. Now let's try the divide and conquer algorithm and compare answers. The SVD routine calls on the SVD algorithms in the LAPACK and eigen libraries.

## Additional Information

- Inputs:
- `M` a [ matrix](../Type/op_Coredollar_Matrix.mdx) over [RR](../Type/op_x226_x132_x157.mdx) or [CC](../Type/op_x226_x132_x130.mdx) of size `m` by `n`
- [ Optional inputs](../Instance/using functions with optional inputs.mdx):
- [](../Instance/SVD(....mdx)```...` default value true whether to use the LAPACK divide and conquer SVD algorithm
- Outputs:
- `S` a [ vertical list](../Type/VerticalList.mdx) the list of singular values
- `U` a [ matrix](../Type/op_Coredollar_Matrix.mdx) an orthogonal (unitary) matrix of size `m` by `m`
- `Vt` a [ matrix](../Type/op_Coredollar_Matrix.mdx) an orthogonal (unitary) matrix of size `n` by `n`
