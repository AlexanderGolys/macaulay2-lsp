# Gamma

**Gamma  -- Gamma function**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

With one argument this is the https://en.wikipedia.org/wiki/gamma_function gamma function \(\Gamma(x) = \int_0^\infty t^{x-1}e^{-t}\dt\).With two arguments it is the (upper) https://en.wikipedia.org/wiki/incomplete_gamma_function incomplete gamma function \(\Gamma(s x) = \int_x^\infty t^{s-1}e^{-t}\dt\).
