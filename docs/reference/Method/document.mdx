# document

**document  -- create a documentation node**

**Type:** [MethodFunctionSingle](../Type/MethodFunctionSingle.mdx)

## Description

There are two basic types of documentation:- Documenting a function or a method as in [ideal(List)](../Instance/ideal(List).mdx).
- documenting an overview or functions with methods as in [ideals](../Instance/ideals.mdx) or [ideal](../Method/op_Coredollar_ideal.mdx) respectively.
The headings [Usage](../Method/op_Coredollar_Usage.mdx)[BaseFunction](../Instance/BaseFunction.mdx)[Inputs](../Method/op_Coredollar_Inputs.mdx)[Outputs](../Instance/Outputs.mdx) and [Consequences](../Method/op_Coredollar_Consequences.mdx) are useful only for documentation of the first type as well as in a call to [SYNOPSIS](../Method/SYNOPSIS.mdx).Templates for using the [document(List)](../Instance/document(List).mdx) method
- Macaulay2Doc:: package documentation template
- Macaulay2Doc:: function documentation template
- Macaulay2Doc:: optional argument documentation template
- Macaulay2Doc:: overview documentation template

Here is a basic template:Other Functions generating [hypertext list format](../Instance/hypertext list format.mdx) that you may use:
- Macaulay2Doc:: SYNOPSIS
- Macaulay2Doc:: EXAMPLE
