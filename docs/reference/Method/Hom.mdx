# Hom

**Hom  -- module of homomorphisms**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

If $M$ or $N$ is an ideal or ring it is regarded as a module in the evident way.To recover the modules used to create a Hom-module use the function [formation](../Method/op_Coredollar_formation.mdx).Specific homomorphisms may be obtained using [homomorphism](../Method/op_Coredollar_homomorphism.mdx) as follows.In the example above`f0` is the identity map and `f1` maps $x$ to $y$ and $y$ to $x^2$.

## Additional Information

- Inputs:
- `M` a [ ring](../Type/Ring.mdx) an [ ideal](../Type/op_Coredollar_Ideal.mdx) or a [ module](../Type/op_Coredollar_Module.mdx)
- `N` a [ ring](../Type/Ring.mdx) an [ ideal](../Type/op_Coredollar_Ideal.mdx) or a [ module](../Type/op_Coredollar_Module.mdx)
- [ Optional inputs](../Instance/using functions with optional inputs.mdx):
- `DegreeLimit```an [ integer](../Type/ZZ.mdx) or a [ list](../Type/op_Coredollar_List.mdx) default value null if set stop after homomorphisms in this degree have been computed
- `MinimalGenerators```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value true whether to [trim](../Method/op_Coredollar_trim.mdx) the resulting module
- `Strategy```a [ thing](../Type/Thing.mdx) default value null
- Outputs:
- a [ module](../Type/op_Coredollar_Module.mdx) isomorphic to $\mathrm{Hom}_R(MN)$ where $M$ and $N$ are both $R$-modules
