# next

**next  -- get the next object from an iterator**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

This gets the next object from an iterator i.e. something returned by [iterator](../Method/iterator.mdx).If the iterator is exhausted then the symbol [StopIteration](../Method/op_Coredollar_StopIteration.mdx) is returned.

## Installed For

### next([Iterator](../Type/Iterator.mdx))
