# ultimate

**ultimate  -- ultimate value for an iteration**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

`ultimate(fx)`  -- yields the value ultimately obtained by applying the function `f`  to `x` . Iteration ceases when an error occurs during application of the function or the result is the same.  Errors are not reported. It's a bad idea to use this function because unexpected errors will produce unexpected results silently.
