# cohomology

**cohomology  -- general cohomology functor**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

`cohomology`  -- a method name available for computing expressions of the forms `HH^i(X)`  and `HH^i(MN)` . If it is intended that `i`  be of class [ZZ](../Type/ZZ.mdx)  `M`  be of class `A`  and `N`  be of class `B`  then the method can be installed with 
```
     cohomology(ZZ A B) := opts -> (iMN) -> ...
```
