# solve

**solve  -- solve linear equation(s)**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

Over `53`  or `53`  if the matrix A is non-singular and square then highly optimized LAPACK routines will be called.If you know that your matrix is square and invertible it should not be too noticeable but for large matrices the difference in time taken can be dramatic.Over higher precision RR or CC these routines will be much slower than the lower precision LAPACK routines. in the case when the field is RR or CC uses a least squares algorithm to find a best fit solution.Giving both options ClosestFit and MaximalRank allows Macaulay2 to call a faster algorithm.

## Additional Information

- Inputs:
- `A` a [ matrix](../Type/op_Coredollar_Matrix.mdx) or a [ mutable matrix](../Type/op_Coredollar_MutableMatrix.mdx) of size m by n over a field R which can be one of: ZZ/p GF(p^n) QQ RR CC
- `B` of the same type of matrix as `A` over the same ring of size m by r
- [ Optional inputs](../Instance/using functions with optional inputs.mdx):
- `ClosestFit```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value false whether to use the least squares method in the case when the ring is `RR` or `CC`
- `MaximalRank```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value false declares to the system that the matrix is full rank. In some cases this can dramatically speed up the computation. If the matrix is not full rank then the results are potentially meaningless.
- `Invertible````...` default value false
- `Precision````...` default value 0
- Outputs:
- `X` of the same type of matrix as `A` over the same ring such that $AX=B$


### Caveat

(1) This function is limited in scope but has been designed to be much faster than generic algorithms. (2) If the matrix is a square invertible matrix this function is only currently implemented for densely encoded matrices.
