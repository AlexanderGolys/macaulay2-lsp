# isSquareFree

**isSquareFree  -- whether something is square free monomial ideal**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

 A square free [ monomial ideal](../Type/op_Coredollar_MonomialIdeal.mdx)  is an ideal generated by products of variables; in other words a radical monomial ideal. Square free monomial ideals correspond both to simplicial complexes and to unions of coordinate subspaces. Implemented by Greg Smith.
