## Additional Information

- Inputs:
- `m` a [ matrix](../Type/op_Coredollar_Matrix.mdx) a [ mutable matrix](../Type/op_Coredollar_MutableMatrix.mdx) or a [ list](../Type/op_Coredollar_List.mdx)
- [ Optional inputs](../Instance/using functions with optional inputs.mdx):
- `Dense````...` default value true whether the encoding of the matrix should be dense or not: see [MutableMatrix](../Type/op_Coredollar_MutableMatrix.mdx)
- Outputs:
- a new mutable matrix whose entries are obtained from `m`. If `m` is a list it should be a doubly nested list (table) of ring elements all from the same ring.
