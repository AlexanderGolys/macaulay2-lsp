# norm

**norm**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

 The norm of a polynomial is the norm of the vector of its coefficients.

## Additional Information

- Inputs:
- `M` a [ mutable matrix](../Type/op_Coredollar_MutableMatrix.mdx) a [ matrix](../Type/op_Coredollar_Matrix.mdx) a [ ring element](../Type/RingElement.mdx) a [ number](../Type/op_Coredollar_Number.mdx) a [ vector](../Type/op_Coredollar_Vector.mdx) or a [ list](../Type/op_Coredollar_List.mdx)
- `p` a [ real number](../Type/op_x226_x132_x157.mdx) or an [ infinite number](../Type/InfiniteNumber.mdx) specifying which norm to compute. Currently only `p=infinity` is accepted.
- Outputs:
- the $L^p$-norm of `M` computed to the minimum of the precisions of `M` and of `p`.
