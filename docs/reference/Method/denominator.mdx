# denominator

**denominator  -- denominator of a fraction**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

`denominator`  also works with Hilbert series.For a Laurent polynomial in a ring with inverses of variables it gives the monomial needed to clear all the denominators in each of the terms.

## Installed For

### denominator([Divide](../Type/Divide.mdx))

### denominator([QQ](../Type/QQ.mdx))
