# Beta

**Beta  -- Beta function**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

This is the https://en.wikipedia.org/wiki/beta_function beta function \(B(xy) = \int_0^1 t^{x - 1}(1 - t)^{y - 1}\dt\).
