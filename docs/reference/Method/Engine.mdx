# Engine

**Engine  -- specify whether a ring is handled by the engine**

**Type:** [Symbol](../Type/Symbol.mdx)

## Description

`Engine`  -- a key for rings that yields the value `true`  if this ring is supported by the [the engine of Macaulay2](../Instance/the engine of Macaulay2.mdx) .
