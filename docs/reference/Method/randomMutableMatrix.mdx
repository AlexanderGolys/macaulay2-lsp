# randomMutableMatrix

**randomMutableMatrix  -- a random mutable matrix of integers**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

 This function has been superseded by [fillMatrix](../Method/op_Coredollar_fillMatrix.mdx)  which works over more rings is much faster for large matrices and is more flexible.

## Installed For

### randomMutableMatrix([ZZ](../Type/ZZ.mdx), [ZZ](../Type/ZZ.mdx), [RR](../Type/RR.mdx), [ZZ](../Type/ZZ.mdx)) -> [MutableMatrix](../Type/MutableMatrix.mdx)

## Options

- [Dense](../Option/Dense.mdx) => false

## Additional Information

- Inputs:
- `nrows` an [ integer](../Type/ZZ.mdx)
- `ncols` an [ integer](../Type/ZZ.mdx)
- `zerof` a [ real number](../Type/op_x226_x132_x157.mdx) between 0 and 1
- `max` an [ integer](../Type/ZZ.mdx)
- [ Optional inputs](../Instance/using functions with optional inputs.mdx):
- `Dense````...` default value false whether the encoding of the matrix should be dense or not: see [MutableMatrix](../Type/op_Coredollar_MutableMatrix.mdx)
- Outputs:
- a [ mutable matrix](../Type/op_Coredollar_MutableMatrix.mdx) a random mutable `nrows` by `ncols` matrix of integers. The absolute value of the entries is less than `max` and the frequency of entries equal to zero is given by `zerof`.
