# gb

**gb  -- compute a Gröbner basis**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

 See [Gröbner bases](../Instance/Gröbner bases.mdx)  for more information and examples. The returned value is not the Gröbner basis itself.  The matrix whose columns form a sorted auto-reduced Gröbner basis are obtained by applying [generators](../Method/gens.mdx)  (synonym: `gens` ) to the result of `gb` .When `I`  is a subquotient module `M/N`  of a free module `F`  then `N`  is generated by `relations I`  and `M`  is generated by the concatenated matrix `generators I || relations I`  -- it is the Gröbner basis of that matrix which is computed so that reduction modulo the Gröbner basis can be used to determine membership in `M` .  When relations are present the option [SyzygyRows](../Method/op_Coredollar_SyzygyRows.mdx)  is set to the number of columns of `generators I`  so that if ``  is used then division by the Gröbner basis can be to express an element of `F`  as a linear combination of columns of `generators I`  avoiding the computation of the coefficients of the columns of `relations I`  leaving all the information that is required to specify an element of `I` .

## Additional Information

- Inputs:
- `I` an ideal module or matrix
- [ Optional inputs](../Instance/using functions with optional inputs.mdx):
- [](../Instance/gb(....mdx)``a [ symbol](../Type/op_Coredollar_Symbol.mdx) default value Inhomogeneous possible values: `Homogeneous` `Inhomogeneous` `Homogeneous2` and `Sugarless`. Experimental options include `LinearAlgebra` and `Toric`.
- `BasisElementLimit```an [ integer](../Type/ZZ.mdx) default value infinity stop when this number of (nonminimal) Gröbner basis elements has been found
- `ChangeMatrix```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value false whether to compute the change of basis matrix from Gröbner basis elements to original generators. Use [getChangeMatrix](../Method/op_Coredollar_getChangeMatrix.mdx) to recover it.
- `CodimensionLimit```an [ integer](../Type/ZZ.mdx) default value infinity stop computation once codimension of submodule of lead terms reaches this value (not functional yet)
- `DegreeLimit```a [ list](../Type/op_Coredollar_List.mdx) default value {} stop after the Gröbner basis in this degree has been computed
- `GBDegrees```a [ list](../Type/op_Coredollar_List.mdx) default value null a list of positive integer weights one for each variable in the ring to be used for organizing the computation by degrees (the 'sugar' ecart vector)
- `HardDegreeLimit````...` default value null throws away all S-pairs of degrees beyond the limit. The computation will be re-initialized if higher degrees are required.
- `Hilbert````...` default value null informs Macaulay2 that this is the [poincare](../Method/op_Coredollar_poincare.mdx) polynomial and can be used to aid in the computation of the Gröbner basis (Hilbert driven)
- `MaxReductionCount```an [ integer](../Type/ZZ.mdx) default value 10 the maximum number of reductions of an S-pair done before requeueing it if the `Inhomogeneous` algorithm is in use
- `PairLimit```an [ integer](../Type/ZZ.mdx) default value infinity stop after this number of spairs has been considered
- `StopBeforeComputation```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value false whether to initialize the Gröbner basis engine but return before doing any computation (useful for using or viewing partially computed Gröbner bases)
- `StopWithMinimalGenerators```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value false whether to stop as soon as the minimal set (or a trimmed set if not homogeneous or local) of generators is known. Intended for internal use only
- `Strategy````...` default value {} either [LongPolynomial](../Instance/LongPolynomial.mdx) [Sort](../Method/op_Coredollar_Sort.mdx) or a list of these. [LongPolynomial](../Instance/LongPolynomial.mdx): use a geobucket data structure while reducing polynomials; `Sort`: sort the S-pairs by lead term (usually this is a bad idea). Another symbol usable here is `UseSyzygies`. Usually S-pairs are processed degree by degree in the order that they were constructed.
- `SubringLimit```an [ integer](../Type/ZZ.mdx) default value infinity stop after this number of elements of the Gröbner basis lie in the first subring
- `Syzygies```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value false whether to collect syzygies on the original generators during the computation. Intended for internal use only
- `SyzygyLimit```an [ integer](../Type/ZZ.mdx) default value infinity stop when this number of non-zero syzygies has been found
- `SyzygyRows```an [ integer](../Type/ZZ.mdx) default value infinity for each syzygy and change of basis element keep only this many rows of each syzygy
- Outputs:
- a [ Gröbner basis](../Type/op_Coredollar_GroebnerBasis.mdx) a Gröbner basis computation object
