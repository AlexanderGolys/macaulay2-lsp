# hilbertPolynomial

**hilbertPolynomial  -- compute the Hilbert polynomial**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

 In a singly graded ambient ring the [ Hilbert function](../Method/hilbertFunction.mdx)  eventually is a polynomial called the Hilbert polynomial. By default this polynomial is written in terms of the Hilbert polynomials of projective spaces because it is a good form for extracting geometric information from the polynomial. The Hilbert polynomial of `P^i`  is `z |--> binomial(z + i i).`
