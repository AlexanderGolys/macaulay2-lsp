# contract'

**contract'  -- contract a matrix by a matrix the dual notion**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

 This function is identical to [diff'(Matrix](../Instance/diff'(Matrix.mdx)  except that the multiplication by integers that occurs during differentiation is omitted.

## Installed For

### contract'([Matrix](../Type/Matrix.mdx), [Matrix](../Type/Matrix.mdx)) -> [Matrix](../Type/Matrix.mdx)

## Examples

```macaulay2
h = contract'(mn)
```

## Additional Information

- Inputs:
- `m` a [ matrix](../Type/op_Coredollar_Matrix.mdx) a map `m: F <--- P` between free modules of ranks f and p.
- `n` a [ matrix](../Type/op_Coredollar_Matrix.mdx) a map `n: G <--- Q` between free modules of ranks g and q.
- Outputs:
- `h` a [ matrix](../Type/op_Coredollar_Matrix.mdx) a matrix with the shape `h: F ** dual G <--- P ** dual Q` whose entry in the slot `h_{g*i+jq*k+l}` is the result of contracting `m_{ik}` by `n_{jl}.`
