# genericSkewMatrix

**genericSkewMatrix  -- make a generic skew symmetric matrix of variables**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

 A square [ matrix](../Type/op_Coredollar_Matrix.mdx)  `M`  is *skew symmetric*  if `transpose(M) + M == 0` . Omitting the input `r`  is the same as having `r`  be the first variable in `R` .

## Additional Information

- Inputs:
- `R` a [ ring](../Type/Ring.mdx)
- `r` a [ ring element](../Type/RingElement.mdx) which is a variable in the ring `R` (this input is optional)
- `n` an [ integer](../Type/ZZ.mdx)
- Outputs:
- a skew symmetric [ matrix](../Type/op_Coredollar_Matrix.mdx) with `n` rows whose entries above the diagonal are the variables of `R` starting with `r`
