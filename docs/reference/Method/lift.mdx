# lift

**lift  -- lift to another ring**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

(Disambiguation: for division of matrices which is thought of as lifting one homomorphism over another see instead [Matrix // Matrix](../Instance/Matrix // Matrix.mdx) .  For lifting a map between modules to a map between their free resolutions see [extend](../Method/extend.mdx) .)The ring `R`  should be one of the base rings associated with the ring of `f` .  An error is raised if `f`  cannot be lifted to `R` .The first example is lifting from the fraction field of R to R.Another use of lift is to take polynomials in a quotient ring and lift them to the polynomial ring.Elements may be lifted to any base ring if such a lift exists.The functions `lift`  and [substitute](../Method/sub.mdx)  are useful to move numbers from one kind of coefficient ring to another.A continued fraction method is used to lift a real number to a rational number whereas [promote](../Method/op_Coredollar_promote.mdx)  uses the internal binary representation.For numbers and ring elements an alternate syntax with [^](../Method/op_Coredollar_caret.mdx)  is available analogous to the use of [_](../Method/op_Coredollar_underscore.mdx)  for [promote](../Method/op_Coredollar_promote.mdx) .
