# format

**format  -- format a string or real number**

**Type:** [MethodFunctionSingle](../Type/MethodFunctionSingle.mdx)

## Description


### Synopsis


- Inputs:
- `s` a [ string](../Type/op_Coredollar_String.mdx)
- Outputs:
- a [ string](../Type/op_Coredollar_String.mdx) obtained from `s` by inserting escape sequences thereby preparing it for printing in a format suitable for reading in again

The characters that are escaped are double quotes backslashes and all https://en.wikipedia.org/wiki/control_characters control characters.  In particular the outputted string will be valid https://en.wikipedia.org/wiki/JSON JSON.
### Synopsis


- Inputs:
- `s` an [ integer](../Type/ZZ.mdx) the maximum number of significant decimal digits (default: [printingPrecision](../Instance/printingPrecision.mdx)). The special value `0` imposes no limit.
- `k` an [ integer](../Type/ZZ.mdx) how far to the right of the decimal point to go at most (default: [printingAccuracy](../Instance/printingAccuracy.mdx)). The special value `-1` imposes no limit.
- `l` an [ integer](../Type/ZZ.mdx) maximum number of leading zeroes (default: [printingLeadLimit](../Instance/printingLeadLimit.mdx)).
- `t` an [ integer](../Type/ZZ.mdx) maximum number of trailing zeroes (default: [printingTrailLimit](../Instance/printingTrailLimit.mdx))
- `e` a [ string](../Type/op_Coredollar_String.mdx) the separator between the mantissa and the exponent (default: [printingSeparator](../Instance/printingSeparator.mdx))
- `x` a [ real number](../Type/op_x226_x132_x157.mdx) the number to be converted to a string
- Outputs:
- a [ string](../Type/op_Coredollar_String.mdx) the decimal representation of the number `x` prepared according to the parameters above
