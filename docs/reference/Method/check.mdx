# check

**check  -- perform tests of a package**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

It is important for package authors to provide tests to ensure that the package is functioning properly. One provides tests using the [TEST](../Method/TEST.mdx) function following the [beginDocumentation](../Function/beginDocumentation.mdx) call in the source of the package.Optionally one can add files to the `tests` directory under the auxiliary subdirectory of the package.  The contents of each file will automatically be included as one of the package's tests.For example to run the tests for the [FirstPackage](../Instance/FirstPackage.mdx) package use:Alternatively if the package is installed somewhere accessible one can do the following.A [TestInput](../Type/op_Coredollar_TestInput.mdx) object (or a list of such objects) can also be run directly.If only an integer is passed as an argument then the test with that index from the last call to [tests](../Method/op_Coredollar_tests.mdx) is run.

## Additional Information

- Inputs:
- `pkg` a [ package](../Type/op_Coredollar_Package.mdx) or a [ string](../Type/op_Coredollar_String.mdx) the package to test
- `i` an [ integer](../Type/ZZ.mdx) the index of a test to run
- `L` a [ list](../Type/op_Coredollar_List.mdx) containing indices of tests to run or `{}` to run all tests
- [ Optional inputs](../Instance/using functions with optional inputs.mdx):
- `UserMode```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value null if true do not use the `-q` in arguments to the Macaulay2 executable when running tests thereby allowing it to load the user's [initialization file](../Instance/initialization file.mdx) allowing it to load packages previously installed in the user's [ application directory](../Function/applicationDirectory.mdx) and allowing packages it loads to read their configuration files from the user's [ application directory](../Function/applicationDirectory.mdx). If false the `-q` argument is added. If [null](../Instance/null.mdx) then add `-q` if it appears as an option in [commandLine](../Instance/commandLine.mdx).
- `Verbose```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value false if true then print the output of all failing tests
- Consequences:
- the tests in the package `pkg` are run (in separate Macaulay2 processes with the random number seed initialized to 0) and any errors are reported.
- if `i` is given only the i-th test in the package is run and any errors are reported.


### Caveat

Currently if the package was only partially loaded because the documentation was obtainable from a database (see [beginDocumentation](../Function/beginDocumentation.mdx)) then the package will be reloaded this time completely to ensure that all tests are considered; this may affect user objects of types declared by the package as they may be not usable by the new instance of the package. In a future version either the tests and the documentation will both be cached or neither will.
