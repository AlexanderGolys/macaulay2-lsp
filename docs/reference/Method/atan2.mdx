## Additional Information

- Inputs:
- `y` a [ real number](../Type/op_x226_x132_x157.mdx)
- `x` a [ real number](../Type/op_x226_x132_x157.mdx)
- `J` a [ real interval](../Type/RRi.mdx)
- `I` a [ real interval](../Type/RRi.mdx)
- Outputs:
- a [ real number](../Type/op_x226_x132_x157.mdx) the angle (in radians) formed with the x-axis by the ray from the origin to the point `(xy)`
- a [ real number](../Type/op_x226_x132_x157.mdx) an interval containing the angles (in radians) formed with the x-axis by the rays from the origin to the points of `(Iy)(xJ)(IJ)`
