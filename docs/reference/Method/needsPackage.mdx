# needsPackage

**needsPackage  -- load a package if not already loaded**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

For example to load the sample package `FirstPackage`:The second time the package was not reloaded.

## Installed For

### needsPackage([String](../Type/String.mdx)) -> [Package](../Type/Package.mdx)

## Options

- [LoadDocumentation](../Option/LoadDocumentation.mdx) => false
- [Configuration](../Method/Configuration.mdx) => {}
- [FileName](../Option/FileName.mdx) => null
- [Reload](../Method/Reload.mdx) => null
- [DebuggingMode](../Method/DebuggingMode.mdx) => null

## Examples

```macaulay2
needsPackage PackageName
```

```macaulay2
needsPackage "FirstPackage"
 -- loading FirstPackage.m2
 -- opening database /usr/lib/Macaulay2/FirstPackage/cache/rawdocumentation-dcba-8.db
 -- beginDocumentation: using documentation database skipping the rest of /usr/share/Macaulay2/FirstPackage.m2
 -- package "FirstPackage" loaded
 -- loaded /usr/share/Macaulay2/FirstPackage.m2

```

```text
FirstPackage

Package
```

```macaulay2
needsPackage "FirstPackage"

```

```text
FirstPackage

Package
```

## Additional Information

- Inputs:
- `PackageName` a [ string](../Type/op_Coredollar_String.mdx) the name of the package
- [ Optional inputs](../Instance/using functions with optional inputs.mdx):
- `FileName```a [ string](../Type/op_Coredollar_String.mdx) default value null the name of the file containing the source code of the package from which it should be loaded
- `LoadDocumentation```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value false whether to load the documentation of the package too; see [beginDocumentation](../Function/beginDocumentation.mdx)
- `DebuggingMode```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value null the value of the variable [debuggingMode](../Instance/debuggingMode.mdx) during loading the package; specifying it here overrides the value specified as an option to [newPackage](../Method/op_Coredollar_newPackage.mdx) by the package itself
- `Configuration```a [ list](../Type/op_Coredollar_List.mdx) default value {} the entries are options `` overriding the defaults specified in the source code of the package and the (possibly updated) values in the file in the user's application directory.
- `Reload```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value null whether to reload the package if it has been loaded from a different source before
- Outputs:
- a [ package](../Type/op_Coredollar_Package.mdx) the package requested
- Consequences:
- loads the package `PackageName` by loading the file `PackageName.m2` which should appear in one of the directories occurring in the list [path](../Instance/path.mdx) unless it has already been loaded in which case it ensures that the package's dictionary of exported symbols occurs in [dictionaryPath](../Instance/dictionaryPath.mdx) and are thus available to the user. In addition the function [needsPackage](../Method/op_Coredollar_needsPackage.mdx) is applied to each of the packages whose names are specified by the [newPackage(...](../Instance/newPackage(....mdx) option for the requested package. If the variable [notify](../Instance/notify.mdx) is set to true then an informational message is displayed after the file is loaded.
