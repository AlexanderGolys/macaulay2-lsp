# generators

**generators  -- provide matrix or list of generators**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

 Produces the generators of a Gröbner basis a polynomial ring an ideal a free module a free group a submodule given by means of generators (or for which generators have been computed) or a free monoid. Usually the result is a list of generators but the generators of a module or Gröbner basis are provided as the columns in a matrix. The matrix is stored in a module M under M.generators unless the matrix is the identity matrix. The symbol `gens`  is a synonym for `generators` .
