# degreesMonoid

**degreesMonoid  -- the ring or monoid of degrees**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

Given a ring or monoid `A` with [ degree length](../Method/degreeLength.mdx) $n$`degreesRing` and `degreesMonoid` produce a Laurent polynomial ring or monoid of Laurent monomials in $n$ variables respectively whose monomials correspond to the degrees of elements of `A`. The variable has no subscript when $n=1$.Note that in the last example the ring does not have a [ heft vector](../Instance/heft vectors.mdx).[ Hilbert series](../Method/op_Coredollar_hilbertSeries.mdx) and [ polynomials](../Method/hilbertPolynomial.mdx) of modules over `A` are elements of its degrees ring over [ZZ](../Type/ZZ.mdx).  The monomial ordering is chosen so that the Hilbert series which has an infinite number of terms is bounded above by the weight. Elements of this ring are also used as variables for Poincare polynomials generated by [poincare](../Method/op_Coredollar_poincare.mdx) and [poincareN](../Method/op_Coredollar_poincareN.mdx).
