# formation

**formation  -- recover the methods used to make a module**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

If the module was created as a direct sum tensor product of Hom-module then the expression will reflect that. In each case the result is a function application and the sequence of arguments is easily obtained.If the module was not obtained that way then [null](../Instance/null.mdx)  is returned.The same remarks apply to certain other types of objects such as chain complexes.
