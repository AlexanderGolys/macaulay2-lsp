# pack

**pack  -- pack elements of a list or string into several shorter lists or strings**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

The commands `pack(A n)`  and `pack(n A)`  produce identical results.If `n`  doesn't divide the length of `A`  the last list will have fewer than `n`  elements.`pack`  and [mingle](../Function/op_Coredollar_mingle.mdx) can be used together to take a transpose of lists

## Additional Information

- Inputs:
- `A` a [ basic list](../Type/op_Coredollar_BasicList.mdx) or a [ string](../Type/op_Coredollar_String.mdx)
- `n` an [ integer](../Type/ZZ.mdx) how many elements of `A` to put in each new list or string
- Outputs:
- `L` a [ list](../Type/op_Coredollar_List.mdx) a list of lists or strings with the elements of `A` taken `n` at a time.
