# minimalPresentationMap

**minimalPresentationMap  -- compute a minimal presentation of a quotient ring**

**Type:** [Symbol](../Type/Symbol.mdx)

## Description

 The computation is accomplished by considering the relations of `R` . If a variable occurs as a term of a relation of `R`  and in no other terms of the same polynomial then  the variable is replaced by the remaining terms and removed from the ring.  A minimal generating set for the resulting defining ideal is then computed and the new quotient ring is returned. If `R`  is not homogeneous then an attempt is made to improve the presentation. If the Exclude option is present then those variables with the given indices are not simplified away (remember that ring variable indices start at 0).

## Examples

```macaulay2
S = minimalPresentation R
S = prune R
```

```macaulay2
R.minimalPresentationMap

           ZZ
          ---[x u w]
          101                     2       3    2
```

```text
map (------------ R {x, - x  + x, x  - x , u, w})
               2    2
            - u  + w

              ZZ
             ---[x u w]
             101
RingMap ------------ <-- R
                  2    2
               - u  + w
```

## Additional Information

- Inputs:
- `R` a [ ring](../Type/Ring.mdx) a quotient ring
- [ Optional inputs](../Instance/using functions with optional inputs.mdx):
- `Exclude````...` default value {}
- Outputs:
- `S` a [ ring](../Type/Ring.mdx) a quotient ring minimally presented if `R` is homogeneous isomorphic to `R`
- Consequences:
- the isomorphism from `R` to `S` is stored as `R.minimalPresentationMap` and the inverse of this map is stored as `R.minimalPresentationMapInv`
