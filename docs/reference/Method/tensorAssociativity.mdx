# tensorAssociativity

**tensorAssociativity  -- associativity isomorphisms for tensor products**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

`tensorAssociativity(ABC)`  -- produces the isomorphism from A**(B**C) to (A**B)**C. Currently implemented for modules and chain complexes.
