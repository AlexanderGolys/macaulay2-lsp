# divideByVariable

**divideByVariable  -- divide all columns by a (power of a) variable**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

`divideByVariable(mv)`  -- divide each column of the matrix 'm' by as high a power of the variable 'v' as possible.`divideByVariable(mvd)`  -- divide each column of the matrix 'm' by as high a power of the variable 'v' as possible but divide by no more than v^d. We may eliminate this routine.

## Additional Information

### Caveat

 You can only divide by a variable not a monomial and you have little control on what power will be divided.  This routine is mostly used by the saturation commands as a fast internal way of dividing.
