# compose

**compose  -- composition as a pairing on Hom-modules**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

In the following example we check that the map does implement the composition map $$ \mathrm{Hom}(MN) \otimes \mathrm{Hom}(NP) \to \mathrm{Hom}(MP). $$The modules should be defined over the same ring.

## Installed For

### compose([Module](../Type/Module.mdx), [Module](../Type/Module.mdx), [Module](../Type/Module.mdx)) -> [Matrix](../Type/Matrix.mdx)

## Examples

```macaulay2
compose(M N P)
```

```macaulay2
f = compose(MMM);

```

```text
Matrix
```

## Additional Information

- Inputs:
- `M` a [ module](../Type/op_Coredollar_Module.mdx)
- `N` a [ module](../Type/op_Coredollar_Module.mdx)
- `P` a [ module](../Type/op_Coredollar_Module.mdx)
- Outputs:
- a [ matrix](../Type/op_Coredollar_Matrix.mdx) the composition map of homomorphism modules $\mathrm{Hom}(MN)$ and $\mathrm{Hom}(NP)$
