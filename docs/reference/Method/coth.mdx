**coth  -- hyperbolic cotangent**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

See https://en.wikipedia.org/wiki/Hyperbolic_function Hyperbolic function .

## Additional Information

- Inputs:
- `x`
- `I` a [ real interval](../Type/RRi.mdx)
- Outputs:
- a [ real number](../Type/op_x226_x132_x157.mdx) the hyperbolic cotangent of `x`
- a [ real interval](../Type/RRi.mdx) an interval containing the hyperbolic cotangents of the points of `I`
