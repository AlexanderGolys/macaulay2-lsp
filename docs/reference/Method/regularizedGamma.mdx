# regularizedGamma

**regularizedGamma  -- upper regularized gamma function**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

This is the (upper) regularized gamma function \(Q(s x) = \frac{\Gamma(s,x)}{\Gamma(s)}\).
