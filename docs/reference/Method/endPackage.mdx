# endPackage

**endPackage  -- end a new package**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

A package writer need not call this function explicitly since the end of file hook for the file containing the [newPackage](../Method/op_Coredollar_newPackage.mdx) command that opened the package will call [endPackage](../Method/op_Coredollar_endPackage.mdx).This function is called automatically at the end of a file so package authors don't need to explicitly call `endPackage`.

## Installed For

### endPackage([String](../Type/String.mdx)) -> [Package](../Type/Package.mdx)

## Examples

```macaulay2
endPackage pkgname
```

```macaulay2
endPackage "Foo"

```

```text
Foo

Package
```

## Additional Information

- Inputs:
- `pkgname` a [ string](../Type/op_Coredollar_String.mdx) the name of the package
- Outputs:
- a [ package](../Type/op_Coredollar_Package.mdx) the new package
- Consequences:
- The package named should have been opened with [newPackage](../Method/op_Coredollar_newPackage.mdx). The package is closed and the former value of [dictionaryPath](../Instance/dictionaryPath.mdx) is restored with the global dictionary (containing the exported symbols) of the package prepended.
