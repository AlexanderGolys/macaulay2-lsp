## Additional Information

- Inputs:
- `src` a [ string](../Type/op_Coredollar_String.mdx) the filename or path to an existing regular file
- `dst` a [ string](../Type/op_Coredollar_String.mdx) the filename or path to the copy to be made
- [ Optional inputs](../Instance/using functions with optional inputs.mdx):
- `UpdateOnly```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value false whether to copy file only if the destination file does not exist or is older than the source file
- `Verbose```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value false whether to report individual file operations
- Consequences:
- the file may be copied
