# graphIdeal

**graphIdeal  -- the ideal of the graph of the regular map corresponding to a ring map**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

graphIdeal  -- the ideal of the graph of the regular map corresponding to a ring map

## Installed For

### graphIdeal([RingMap](../Type/RingMap.mdx)) -> [Ideal](../Type/Ideal.mdx)

## Options

- [MonomialSize](../Option/MonomialSize.mdx) => 32
- [VariableBaseName](../Method/VariableBaseName.mdx) => p
- [MonomialOrder](../Option/MonomialOrder.mdx) => {GRevLex, Position => Up}

## Examples

```macaulay2
graphIdeal f
```

```macaulay2

```


- Inputs:

- [ Optional inputs](../Instance/using functions with optional inputs.mdx):
- `MonomialOrder````...` default value a monomial ordering see [monomial orderings](../Instance/monomial orderings.mdx)
- `MonomialSize```an [ integer](../Type/ZZ.mdx) default value 32 the monomial size see [MonomialSize](../Instance/MonomialSize.mdx)
- `VariableBaseName```a [ symbol](../Type/op_Coredollar_Symbol.mdx) default value "p" the variable base name see [VariableBaseName](../Method/op_Coredollar_VariableBaseName.mdx)
- Outputs:
