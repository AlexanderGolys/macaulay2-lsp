# commonest

**commonest  -- the most common elements of a list or tally**

**Type:** [MethodFunctionSingle](../Type/MethodFunctionSingle.mdx)

## Description

If a single element is the most common a list of length one is the output.In the case of a tie all commonest elements are returned.`commonest`  works on [Tally](../Type/Tally.mdx)s and [Set](../Type/op_Coredollar_Set.mdx)s as well.(Since every element of a set is unique it is unclear why one would need `commonest(Set)` .)

## Installed For

### commonest([Set](../Type/Set.mdx))

### commonest([Tally](../Type/Tally.mdx))

### commonest([VisibleList](../Type/VisibleList.mdx)) -> [List](../Type/List.mdx)
