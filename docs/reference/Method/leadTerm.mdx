# leadTerm

**leadTerm  -- get the greatest term**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

 Every polynomial ring in Macaulay2 comes equipped with a monomial ordering. For ring elements and matrices this function returns the greatest term in this order. For an ideal a Gröbner basis is first computed and the ideal of lead terms is returned. If an initial integer `n`  is specified then the returned value contains the sum of all of the terms with the greatest value on the first `n`   parts of the monomial order.
