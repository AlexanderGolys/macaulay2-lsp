# positions

**positions  -- which elements of a list satisfy a condition**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

The indices are listed in ascending order. If no element satisfies the condition an empty list is returned.To find the first or last index of an element satisfying the condition see [position](../Method/position.mdx). To return the elements rather than their indices see [select](../Method/select.mdx). The function [number](../Function/number.mdx) counts the number of elements satisfying the condition.
