# insert

**insert  -- copy a list inserting an element**

## Description

insert  -- copy a list inserting an element

## Additional Information

- Inputs:
- `i` an [ integer](../Type/ZZ.mdx)
- `x` a [ thing](../Type/Thing.mdx)
- `L` a [ basic list](../Type/op_Coredollar_BasicList.mdx)
- Outputs:
- `L2` a [ basic list](../Type/op_Coredollar_BasicList.mdx) a copy of `L` in which `x` has been inserted into position `i`
