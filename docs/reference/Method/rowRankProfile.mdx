rowRankProfile  -- find the row rank profile of a mutable matrix

## Additional Information

- Inputs:
- `m` a [ mutable matrix](../Type/op_Coredollar_MutableMatrix.mdx) over [RR](../Type/op_x226_x132_x157.mdx) or [CC](../Type/op_x226_x132_x130.mdx)
- Outputs:
- a [ list](../Type/op_Coredollar_List.mdx) the lexicographically smallest list of indices of linearly independent rows generating the row space of `m`
