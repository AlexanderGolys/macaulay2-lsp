# WebApp

**WebApp  -- the web app top level printing method**

**Type:** [Symbol](../Type/Symbol.mdx)

## Description

 This symbol is used (tentatively) as the first element of a pair to specify various top level interpreter methods in connection with the use of the (currently developed) web app with (Ka)TeX output as front end.
