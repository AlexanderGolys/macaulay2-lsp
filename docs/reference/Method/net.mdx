# net

**net  -- format for printing as a net**

**Type:** [MethodFunctionSingle](../Type/MethodFunctionSingle.mdx)

## Description

This function is the primary function called upon by [<<](../Method/op_Coredollar_lt_lt.mdx) to format expressions for printing. The default method provided by the system is to convert `o` to an [Expression](../Type/op_Coredollar_Expression.mdx) with [expression](../Method/op_Coredollar_expression.mdx) and then to convert that to a [Net](../Type/op_Coredollar_Net.mdx).A new method for formatting expressions of type `T` may be installed as follows:The function provided by the user should return a [Net](../Type/op_Coredollar_Net.mdx) or a [String](../Type/op_Coredollar_String.mdx).There are various such methods for formatting but we don't document them separately.
