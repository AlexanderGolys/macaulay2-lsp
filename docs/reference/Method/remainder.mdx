# remainder

**remainder  -- matrix remainder**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

This operation is the same as [Matrix % GroebnerBasis](../Instance/Matrix % GroebnerBasis.mdx) .The equation `g*q+r == f`  will hold where `q`  is the map provided by [quotient](../Method/quotient.mdx) .  The source of `f`  should be a free module.

## Additional Information

- Inputs:
- `f` a [ matrix](../Type/op_Coredollar_Matrix.mdx)
- `g` a [ Gröbner basis](../Type/op_Coredollar_GroebnerBasis.mdx) or a [ matrix](../Type/op_Coredollar_Matrix.mdx) with the same target as `f`
- Outputs:
- `r` the remainder of `f` upon division by `g`
