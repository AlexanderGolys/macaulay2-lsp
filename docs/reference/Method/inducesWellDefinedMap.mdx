# inducesWellDefinedMap

**inducesWellDefinedMap  -- whether a map is well defined**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

`inducesWellDefinedMap(MNf)`  -- tells whether the matrix `f`  would induce a well defined map from `N`  to `M` .
