# isInjective

**isInjective  -- whether a map is injective**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

 This function computes the kernel and checks whether it is zero. Similarly for ring maps:

## Installed For

### isInjective([Matrix](../Type/Matrix.mdx)) -> [Boolean](../Type/Boolean.mdx)

### isInjective([RingMap](../Type/RingMap.mdx))

## Examples

```macaulay2
isInjective f
```

```macaulay2
isInjective F

```

```text
true
```

```macaulay2
isInjective G

```

```text
false
```

```macaulay2
isInjective phi

```

```text
false
```

```macaulay2
isInjective phi'

```

```text
true
```

## Additional Information

- Inputs:
- `f` a [ matrix](../Type/op_Coredollar_Matrix.mdx) or a [ ring map](../Type/op_Coredollar_RingMap.mdx)
- Outputs:
- a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) whether the kernel is zero
