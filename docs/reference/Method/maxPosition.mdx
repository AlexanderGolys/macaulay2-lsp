# maxPosition

**maxPosition  -- position of the largest element**

**Type:** [MethodFunctionSingle](../Type/MethodFunctionSingle.mdx)

## Description

If the largest element occurs more than once the index of its first occurrence is used.If `L`  contains elements in a polynomial ring the [MonomialOrder](../Instance/MonomialOrder.mdx) of the ring is used for comparisons.More generally the order of the elements is determined using the [?](../Method/op_Coredollar_question.mdx) operator.

## Installed For

### maxPosition([BasicList](../Type/BasicList.mdx)) -> [ZZ](../Type/ZZ.mdx)

## Examples

```macaulay2
maxPosition L
```

```macaulay2
maxPosition {1, 6, 4, 2, 6}

```

```text
1
```

```macaulay2
maxPosition {x*y^2, x*y^2 + z^2, y^4, y*z^5}

```

```text
1
```

```macaulay2
maxPosition (x*y^2 x*y^2 + z^2 y^4 y*z^5)

```

```text
3
```

## Additional Information

- Inputs:
- `L` a [ basic list](../Type/op_Coredollar_BasicList.mdx)
- Outputs:
- `i` an [ integer](../Type/ZZ.mdx) the index of the largest element in the list `L`
