# basis

**basis  -- basis or generating set of all or part of a ring ideal or module**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

The function `basis`  finds a basis or generating set of a module over a coefficient ring either for the full module or for a degree range or for a specific (multi-)degree. A ring or ideal may also be provided instead of a module.  Partial multi-degrees may also be given see below for the usage and meaning.If $M$ is a matrix then the matrix between the corresponding bases of the source and target of $M$ is returned.  This feature should be considered experimental.The following examples show the varied uses of this function.Basis of the whole ringIf no degree or degree range is given then a full basis is given.  In the example below the 12 entries generate $R$ over the base ring ${\mathbb Q}$. If the object is not finite then an error is given.Basis in a degree or range of degreesIf a single degree or degree range is given give a basis (or generating set) of that particular degree (or degree range) of $M$.Notice that `phi`  is a matrix whose source is a free module and whose target is the ideal.  [super](../Method/op_Coredollar_super.mdx) is used to get the actual elements of $I$.Basis in a specific multi-degreeIf a multidegree is given then a range cannot be given. In this example the dimension over QQ of this multigraded piece of R is 2.Partially described multidegreesA partial multidegree can be given.  The given columns generate (form a basis in this case) the degree \{2,*\} part of R over the subring QQ[d] generated by the variables which have degree \{0,*\}.The base ring does not need to be a field.  In these cases the given image vectors might only generate over the base ring not be a basis. For instance in the following example $B$ is generated over $A$ by 4 elements but $B$ is not a free module.If $M$ is an ideal or module the resulting map looks somewhat strange since maps between modules are given from generators in terms of the generators of the target module.  Use [super](../Method/op_Coredollar_super.mdx) or [cover](../Method/cover.mdx) to recover the actual elements.If `Variables`  is given as an optional argument only monomial multiples of the generators which involve these variables will be considered.  In this case the resulting elements might not form a generating set over the coefficient ring.  They do generate over the subring generated by the other variables.If the base ring has a local term order then the generating set or basis will be over this ring.Functoriality`basis`  is functorial meaning that if $M : A \rightarrow B$ is a matrix between two modules then the result is the induced matrix on the images of the result of basis applied to A and B.Obtain the map of free modules using [matrix](../Method/matrix.mdx):

## Additional Information

- Inputs:
- `M` a [ module](../Type/op_Coredollar_Module.mdx) a [ ring](../Type/Ring.mdx) an [ ideal](../Type/op_Coredollar_Ideal.mdx) or a [ matrix](../Type/op_Coredollar_Matrix.mdx)
- `deg` an [ integer](../Type/ZZ.mdx) or a [ list](../Type/op_Coredollar_List.mdx) a degree or degree vector
- `lo` an [ integer](../Type/ZZ.mdx) or an [ infinite number](../Type/InfiniteNumber.mdx) or `-infinity` the low degree
- `hi` an [ integer](../Type/ZZ.mdx) or an [ infinite number](../Type/InfiniteNumber.mdx) or [infinity](../Instance/infinity.mdx) the high degree
- [ Optional inputs](../Instance/using functions with optional inputs.mdx):
- `Limit```an [ integer](../Type/ZZ.mdx) default value infinity an upper bound on the number of basis elements to collect
- `Variables```a [ list](../Type/op_Coredollar_List.mdx) default value null a list of variables or variable indices (defaults to the generators of the ring of M)
- `SourceRing```a [ ring](../Type/Ring.mdx) default value null if not the ring (of) M then returns a module map whose target and source have different rings
- `Strategy```a [ thing](../Type/Thing.mdx) default value null specifies the algorithm
- `Degree```an [ integer](../Type/ZZ.mdx) or a [ list](../Type/op_Coredollar_List.mdx) default value null sets the degree of the resulting matrix. Default is 0. Seldom Used
- `Truncate```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value false internal use only. Used to implement [truncate(ZZ](../Instance/truncate(ZZ.mdx)
- Outputs:
- `f` a [ matrix](../Type/op_Coredollar_Matrix.mdx) a map from a free module over the ring of `M` (or by the ring specified with the `SourceRing` option if given) to `M` which sends the basis elements of the free module to a basis (over the coefficient field) of the specified part of `M`


### Caveat

If the base ring is not a field then the result is only a generating set.  If the optional argument Variables is provided then even this might not be correct.
