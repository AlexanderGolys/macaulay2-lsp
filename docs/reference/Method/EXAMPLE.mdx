# EXAMPLE

**EXAMPLE  -- construct a hypertext item from a Macaulay2 input string**

**Type:** [MethodFunctionSingle](../Type/MethodFunctionSingle.mdx)

## Description

If the table is included in the input provided to [document](../Method/document.mdx) the input string will be evaluated by [installPackage](../Method/installPackage.mdx) and the result will be displayed in the documentation. Each object of class [PRE](../Instance/PRE.mdx) will be inserted unchanged into the documentation as example output. For example the code
```
 "1+1" 
```

## Installed For

### EXAMPLE([String](../Type/String.mdx))

### EXAMPLE([VisibleList](../Type/VisibleList.mdx))

## Examples

```macaulay2
EXAMPLE x
```

## Additional Information

- Inputs:
- `x` a [ string](../Type/op_Coredollar_String.mdx) a [ visible list](../Type/VisibleList.mdx) or an instance of the type [PRE](../Instance/PRE.mdx) containing strings or objects of class [PRE](../Instance/PRE.mdx)
- Outputs:
- an instance of the type [TABLE](../Instance/TABLE.mdx) a table containing the examples
