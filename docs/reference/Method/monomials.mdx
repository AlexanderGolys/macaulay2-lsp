# monomials

**monomials  -- matrix of monomials in a ring element or matrix**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

 Each monomial only appears once and the monomials are sorted in what order? If the monomials in only some of the variables are desired use the optional argument [monomials(...](../Instance/monomials(....mdx) .

## Installed For

### monomials([Matrix](../Type/Matrix.mdx)) -> [Matrix](../Type/Matrix.mdx)

### monomials([RingElement](../Type/RingElement.mdx))

## Options

- [Variables](../Option/Variables.mdx) => null

## Examples

```macaulay2
monomials f
```

```macaulay2
monomials m

```

```text
| ax3 bx2y cxy2 dy3 ax2 bxy cy2 |

             1      7

```
