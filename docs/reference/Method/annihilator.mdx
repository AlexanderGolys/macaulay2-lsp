# annihilator

**annihilator  -- the annihilator ideal**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

You may use `ann` as a synonym for `annihilator`.As an example we compute the annihilator of the canonical module of the rational quartic curve.For another example we compute the annihilator of an element in a quotient ring.Currently two algorithms to compute annihilators are implemented. The default is to compute the annihilator of each generator of the module `M` and to intersect these two by two. Each annihilator is done using a submodule quotient. The other algorithm computes the annihilator in one large computation and is used if `` is specified.
