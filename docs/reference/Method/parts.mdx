# parts

**parts  -- display terms of a polynomial degree by degree**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

By default `Macaulay2`  displays a polynomial [RingElement](../Type/RingElement.mdx) by putting its terms in decreasing order with respect to the [MonomialOrder](../Instance/MonomialOrder.mdx) of the ambient ring. On the other hand `parts`  will display the terms in order of increasing degree regardless of the term order of the ring. Parentheses group together all terms of the same degree.The output is an [Expression](../Type/op_Coredollar_Expression.mdx) of a special class[Parenthesize](../Type/Parenthesize.mdx). Accessing the individual parenthesized parts of this expression is difficult so for this purpose it may be better to use [part](../Method/op_Coredollar_part.mdx).

## Installed For

### parts([RingElement](../Type/RingElement.mdx)) -> [Expression](../Type/Expression.mdx)

## Examples

```macaulay2
parts f
```

```macaulay2
parts f

                         2           2
```

```text
(1) + (2x + 2y) + (x  + 2x*y + y )

Expression of class Sum
```

```macaulay2
parts f

                         2           2
```

```text
(1) + (2x + 2y) + (x  + 2x*y + y )

Expression of class Sum
```

## Additional Information

- Inputs:
- `f` a [ ring element](../Type/RingElement.mdx)
- Outputs:
- an [ expression](../Type/op_Coredollar_Expression.mdx) with the terms of `f` parenthesized degree by degree. The degrees are given in increasing order
