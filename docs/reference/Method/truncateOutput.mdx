## Examples

```macaulay2
truncateOutput w
```

## Additional Information

- Inputs:
- `w` an [ integer](../Type/ZZ.mdx)
- Consequences:
- The maximum output line width is set to `w` which should be an integer or [infinity](../Instance/infinity.mdx). This function works by assigning a value to `Thing#{Standard,BeforePrint}` which may conflict with other [BeforePrint](../Instance/BeforePrint.mdx) methods installed by the user or those installed by the system that do line wrapping.
