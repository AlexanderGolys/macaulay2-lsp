# tensor

**tensor  -- tensor product**

**Type:** [MethodFunctionBinary](../Type/MethodFunctionBinary.mdx)

## Description

This function calculates the tensor product of a list or sequence of compatible objects.This method is declared as a [MethodFunctionBinary](../Type/MethodFunctionBinary.mdx)  so for two or more argument the product is computed iteratively from the binary tensor products working from left to right. For two arguments this is the same as `A ** B`  except that options are allowed.
