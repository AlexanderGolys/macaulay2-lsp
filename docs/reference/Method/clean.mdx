# clean

**clean  -- set to zero elements that are approximately zero**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

If the input is a [ matrix](../Type/op_Coredollar_Matrix.mdx)  or a [ ring element](../Type/RingElement.mdx)  then the result has the same type where each real or complex number coefficient that is less than `epsilon`  in absolute value is replaced with zero. Cleaning a polynomial is a way to get rid of small terms.
