# InverseMethod

**InverseMethod  -- compute reciprocals**

**Type:** [Symbol](../Type/Symbol.mdx)

## Description

`InverseMethod`  -- a key used under which is stored a method for computing multiplicative inverses. Internal routines for computing powers call upon that method when the exponent is negative.
