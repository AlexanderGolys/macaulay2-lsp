# symmetricPower

**symmetricPower  -- symmetric power**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

There is currently one restriction: if $f$ is a matrix then it must have only one row and be a map of free modules as in this example.If G --> F --> M --> 0 is a presentation for the module M = coker(f:G-->F) then symmetricPower(if) is the cokernel of the map symmetricPower(i-1F) ** G --> symmetricPower(iF).
