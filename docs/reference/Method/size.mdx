# size

**size  -- the size of an object**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

`size x`  -- returns the size of `x`  which usually gives a rough indication of memory space required to store the object `x` . For a polynomial the size is the number of terms. This function should be replaced by something more generally useful.
