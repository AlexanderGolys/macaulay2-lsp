# isUnit

**isUnit  -- whether a ring element is a unit**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

isUnit  -- whether a ring element is a unit

## Installed For

### isUnit([Number](../Type/Number.mdx))

### isUnit([RingElement](../Type/RingElement.mdx)) -> [Boolean](../Type/Boolean.mdx)

## Examples

```macaulay2
isUnit r
```

## Additional Information

- Inputs:
- `r` a [ ring element](../Type/RingElement.mdx)
- Outputs:
- a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) [true](../Instance/op_Coredollar_true.mdx) if the [ ring element](../Type/RingElement.mdx) `r` generates an ideal containing the multiplicative identity `1` and `false` otherwise
