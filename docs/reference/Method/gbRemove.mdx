# gbRemove

**gbRemove  -- remove Gröbner basis**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

 This is a simple way to remove the space associated with large Gröbner bases that are no longer needed.

## Installed For

### gbRemove([Ideal](../Type/Ideal.mdx))

### gbRemove([Matrix](../Type/Matrix.mdx))

### gbRemove([Module](../Type/Module.mdx))

## Examples

```macaulay2
gbRemove M
```

```macaulay2
gbRemove J
```

## Additional Information

- Inputs:
- `M` an [ ideal](../Type/op_Coredollar_Ideal.mdx) a [ matrix](../Type/op_Coredollar_Matrix.mdx) or a [ module](../Type/op_Coredollar_Module.mdx)
- Consequences:
- all Gröbner bases computed for M are removed
