# roots

**roots  -- compute the roots of a polynomial**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

The roots are computed using [MPSolve](../Instance/MPSolve.mdx) .

## Additional Information

- Inputs:
- `p` a [ ring element](../Type/RingElement.mdx) a univariate polynomial over ZZ QQ RR or CC.
- [ Optional inputs](../Instance/using functions with optional inputs.mdx):
- `Precision````...` default value -1 the number of precision bits used to compute the roots. The default [precision](../Method/op_Coredollar_precision.mdx) is 53 bits for polynomials over [ZZ](../Type/ZZ.mdx) or [QQ](../Type/op_x226_x132_x154.mdx) and the same as the coefficient ring for `RR[x]` or `CC[x]`.
- `Unique```a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) default value false whether to return multiple roots one or multiple times.
- Outputs:
- a [ list](../Type/op_Coredollar_List.mdx) The roots of p each one represented as an elements of [CC](../Type/op_x226_x132_x130.mdx).
