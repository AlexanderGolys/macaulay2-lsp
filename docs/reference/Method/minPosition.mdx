# minPosition

**minPosition  -- position of the smallest element**

**Type:** [MethodFunctionSingle](../Type/MethodFunctionSingle.mdx)

## Description

If the smallest element occurs more than once the index of its first occurrence is used.If `L`  contains elements in a polynomial ring the [MonomialOrder](../Instance/MonomialOrder.mdx) of the ring is used for comparisons.More generally the order of the elements is determined using the [?](../Method/op_Coredollar_question.mdx) operator.

## Installed For

### minPosition([BasicList](../Type/BasicList.mdx)) -> [ZZ](../Type/ZZ.mdx)

## Examples

```macaulay2
minPosition L
```

```macaulay2
minPosition {2, 1, 6, 4, 1}

```

```text
1
```

```macaulay2
minPosition {x*y^2, x*y^2 + z^2, y^4, y*z^5}

```

```text
3
```

```macaulay2
minPosition (x*y^2 x*y^2 + z^2 y^4 y*z^5)

```

```text
0
```

## Additional Information

- Inputs:
- `L` a [ basic list](../Type/op_Coredollar_BasicList.mdx)
- Outputs:
- `i` an [ integer](../Type/ZZ.mdx) the index of the smallest element in the list `L`
