# flattenRing

**flattenRing  -- write a ring as a (quotient of a) polynomial ring**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

Use `flattenRing`  to get an isomorphic representation of a ring over a different coefficient ring.For instance the following ring $R$ is defined to have indeterminates $yz$ and coefficients in the quotient ring $\mathbb{Z}[x]/(x^2-3)$.To work with the isomorphic ring $S = \mathbb{Z}[xyz]/(x^2-3x*y^2-z^2y^3)$ instead use `flattenRing` .The default output is the sequence $(S F)$ where $S$ is the flattened ring and $F$ is the [RingMap](../Type/op_Coredollar_RingMap.mdx) from $R$ to $S$. Here we demonstrate how to store and use the map $F$.Flattening an ideal instead of a quotient ring can save a lot of time spent computing the Gröbner basis of the resulting ideal if the flattened quotient is not needed. Notice that the ring map in the following example is *not*  the same as the previous example; the following ring map is from $R$ to $\mathbb{Z}[xyz]$ while the previous map was from $R$ to $\mathbb{Z}[xyz]/(x^2-3x*y^2-z^2y^3)$.`flattenRing`  can also be used to represent [GaloisField](../Type/GaloisField.mdx)s as quotients of polynomial rings. If $K$ is the Galois field of order $p^n$ `flattenRing(K)`  will represent $K$ as a quotient of $\mathbb{Z}_p[a]$.Or if a different variable was specified in the construction of $K$ `flattenRing K`  will follow suit.Use ``  to return the ring only. The default behavior is equivalent to `` . Use ``  to return the ring the isomorphism $F:R\to S$ and the inverse map $F^{-1}:R\to S$.These are the only numeric options for `Result` . However we can also specify the output(s) desired with a sequence of length 1 2 or 3. The elements of the sequence correspond to the ``  ``  and ``  output sequences respectively. Any element of the sequence can be suppressed by asking for `Nothing`  instead. For example to return the map $F$ only we ask for the sequence of length 2 $(S F)$ but suppress $S$:Note that ``  is NOT a valid way to return $F$ only because an output of length 1 can only have a ring or an ideal.Similarly to return $S$ and $F^{-1}$ only:Omitting an element of the sequence is equivalent to asking for it to be returned.When running `flattenRing(Ideal)`  there are additional choices for the `Result`  option: the first element of the sequence which is always the ring in the `flattenRing(Ring)`  case can now be either the new ring or the corresponding new ideal. The default is to return the ideal including when using numeric options for `Result`  or omitting an object type in the sequence.By default `flattenRing`  attempts to define a new ring over either `ZZ`  or a base field.In the following example the coefficient ring of the result is the fraction field $K$.Once a ring has been declared to be a field with [toField](../Method/op_Coredollar_toField.mdx) then it will be used as the coefficient ring.Use the `CoefficientRing`  option to specify a different base field or ring.Here is a more complicated example.Multiple calls to `flattenRing`  may result in defining multiple rings that are regarded as different objects by `Macaulay2` . (See [rings](../Instance/rings.mdx) or [working with multiple rings](../Instance/working with multiple rings.mdx) for more information.)

## Additional Information

- Inputs:
- `R` a [ ring](../Type/Ring.mdx) OR
- `I` an [ ideal](../Type/op_Coredollar_Ideal.mdx) OR
- `G` a [ Galois field](../Type/GaloisField.mdx)
- [ Optional inputs](../Instance/using functions with optional inputs.mdx):
- [](../Instance/flattenRing(....mdx)```...` default value null specify the coefficient ring of the flattened ring
- [](../Instance/flattenRing(....mdx)```...` default value (ThingRingMap) specify which output(s) to return
- Outputs:
- `S` a [ ring](../Type/Ring.mdx) a ring isomorphic to `R` but represented as a (quotient of a) polynomial ring or
- `J` an [ ideal](../Type/op_Coredollar_Ideal.mdx) the ideal of `S` corresponding to (isomorphic to) `I`
- `F` a [ ring map](../Type/op_Coredollar_RingMap.mdx) the isomorphism from `R` to `S`
- `G` a [ ring map](../Type/op_Coredollar_RingMap.mdx) the isomorphism from `S` to `R`
