# liftable

**liftable  -- whether lifting to another ring is possible**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

 The ring `R`  should be one of the base rings associated with the ring of `f` .

## Examples

```macaulay2
liftable(fR)
```

```macaulay2
liftable ((x-1)*(x+1)-x^2 ZZ)

```

```text
true
```

```macaulay2
liftable(3/4ZZ)

```

```text
false
```

```macaulay2
liftable((3/4)*4ZZ)

```

```text
true
```

## Additional Information

- Inputs:
- `f` a [ ring element](../Type/RingElement.mdx) or a [ matrix](../Type/op_Coredollar_Matrix.mdx)
- `R` a [ ring](../Type/Ring.mdx)
- Outputs:
- a [ Boolean value](../Type/op_Coredollar_Boolean.mdx) whether `f` can be lifted to the ring `R`
