# describe

**describe  -- real description**

**Type:** [MethodFunctionSingle](../Type/MethodFunctionSingle.mdx)

## Description

`describe X` returns an `Expression` containing the real description of `X` bypassing the feature that causes certain types of things to acquire for brevity the names of global variables to which they are assigned.For example it also displays the options used at creation of polynomial rings.
