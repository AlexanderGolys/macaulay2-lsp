# modulo

**modulo  -- find the pre-image (pullback) of image of a map (low level version)**

**Type:** [MethodFunctionWithOptions](../Type/MethodFunctionWithOptions.mdx)

## Description

The maps `f`  and `g`  must have the same target and their sources and targets must be free. If `f`  is [null](../Instance/null.mdx)  then it is taken to be the identity.  If `g`  is [null](../Instance/null.mdx)  it is taken to be zero.This function is mainly for internal use.

## Additional Information

- Inputs:
- `f`
- `g`
- Outputs:
- a [ matrix](../Type/op_Coredollar_Matrix.mdx) whose image is the pre-image (pullback) of the image of `g` under `f`
