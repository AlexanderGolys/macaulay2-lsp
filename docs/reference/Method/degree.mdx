# degree

**degree**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

 Degree is a common name meaning different things for different kinds of mathematical objects. In Macaulay2 there are currently three related yet different notions of degree: 
#### Degree of polynomials or vectors of such


- Macaulay2Doc:: degree(RingElement)
- Macaulay2Doc:: degree(Vector)
- Macaulay2Doc:: degree(RingElementRingElement)
- Macaulay2Doc:: degree(ProjectiveHilbertPolynomial)


#### Degree of ideals varieties and modules


- Macaulay2Doc:: degree(Ideal)
- Macaulay2Doc:: degree(Ring)
- Macaulay2Doc:: degree(Module)
- Varieties:: degree(ProjectiveVariety)


#### Degree of homomorphisms


- Macaulay2Doc:: degree(Matrix)
