# round

**round  -- round a number**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description


### Synopsis


- Inputs:
- `x` a number
- Outputs:
- the integer nearest to `x`


### Synopsis


- Inputs:
- `n` an [ integer](../Type/ZZ.mdx)
- `x` a [ real number](../Type/op_x226_x132_x157.mdx)
- Outputs:
- the real number with just n decimal digits to the right of the decimal point nearest to `x`
