# part

**part  -- select terms of a polynomial by degree(s) or weight(s)**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

To select terms of a single degree use `part(deg f)` . An alternate syntax uses an underscore.To select terms within a range of degrees use `part(lo hi f)` .In the next example we apply the weights `\{2,3\}`  before selecting terms. In other words the term `x^ay^b`  is considered to have degree `2a+3b` .If the generators of the ring were defined to have non-unit degrees the weights *override*  those degrees.By omitting `lo`  or `hi`  but providing a comma indicating the omission the range of degrees will be unbounded in the appropriate direction.Infinite numbers may also be given for the bounds.For multigraded rings  use a list to specify a single multidegree in the first argument. The underscore syntax works here too.A range of degrees cannot be asked for in the multigraded case. Polynomial rings over polynomial rings are multigraded so either use a multidegree or specify weights to avoid errors.

## Additional Information

- Inputs:
- `f` a [ ring element](../Type/RingElement.mdx) a polynomial
- `deg` an [ integer](../Type/ZZ.mdx) in which degree to select terms from `f`
- `lo` an [ integer](../Type/ZZ.mdx) or [InfiniteNumber](../Type/InfiniteNumber.mdx) the lower bound of degrees to select
- `hi` an [ integer](../Type/ZZ.mdx) or [InfiniteNumber](../Type/InfiniteNumber.mdx) the upper bound of degrees to select
- `wt` a [ list](../Type/op_Coredollar_List.mdx) (optionally) a list of integers to use as weights before selecting degrees
- `mdeg` a [ list](../Type/op_Coredollar_List.mdx) a multidegree in the case that `f` is defined in a multigraded ring
- Outputs:
- a [ ring element](../Type/RingElement.mdx) the sum of all terms of `f` matching the specified degree or range of degrees (after weighting if weights given)
