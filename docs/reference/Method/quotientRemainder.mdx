# quotientRemainder

**quotientRemainder  -- matrix quotient and remainder**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

 The equation `g*q+r == f`  will hold.  The source of `f`  should be a free module.

## Additional Information

- Inputs:
- `f` a [ matrix](../Type/op_Coredollar_Matrix.mdx)
- `g` a [ Gröbner basis](../Type/op_Coredollar_GroebnerBasis.mdx) or a [ matrix](../Type/op_Coredollar_Matrix.mdx) with the same target as `f`
- Outputs:
- `q` the quotient of `f` upon division by `g`
- `r` the remainder of `f` upon division by `g`
