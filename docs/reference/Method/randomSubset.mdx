# randomSubset

**randomSubset**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

When n is given then a random subset x of cardinality n is returned.Otherwise a random subset of arbitrary cardinality is returned.If x is an integer then a subset of $\{0,\ldots,x - 1\}$ is returned.
