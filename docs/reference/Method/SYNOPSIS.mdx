# SYNOPSIS

**SYNOPSIS  -- a standardized synopsis for use in documentation nodes**

**Type:** [MethodFunctionSingle](../Type/MethodFunctionSingle.mdx)

## Description

This function prepares a standardized synopsis in hypertext for use in documentation nodes. Here is an empty template for use with `SYNOPSIS`.The options are used just as with [document](../Method/document.mdx). Here is an example of its use.See the `Synopsis` keyword in [doc(String)](../Instance/doc(String).mdx) for usage as a keyword in that format.

### SYNOPSIS([Sequence](../Type/Sequence.mdx))

### SYNOPSIS([Thing](../Type/Thing.mdx))

## Options

- [Consequences](../Method/Consequences.mdx) => {}
- [Inputs](../Method/Inputs.mdx) => {}
- [BaseFunction](../Option/BaseFunction.mdx) => null
- [Usage](../Method/Usage.mdx) => 
- [Outputs](../Option/Outputs.mdx) => {}
- [Heading](../Method/Heading.mdx) => Synopsis

- [ Optional inputs](../Instance/using functions with optional inputs.mdx):
- `BaseFunction```a [ function](../Type/Function.mdx) default value null see Macaulay2Doc:: document(...
- `Heading```a [ list](../Type/op_Coredollar_List.mdx) default value "Synopsis" see [document(...](../Instance/document(....mdx) -- specifies a subheading for the synopsis
- `Usage```a [ list](../Type/op_Coredollar_List.mdx) default value "" see Macaulay2Doc:: document(...
- `Inputs```a [ list](../Type/op_Coredollar_List.mdx) default value {} see Macaulay2Doc:: document(...
- `Outputs```a [ list](../Type/op_Coredollar_List.mdx) default value {} see Macaulay2Doc:: document(...
- `Consequences```a [ list](../Type/op_Coredollar_List.mdx) default value {} see Macaulay2Doc:: document(...

- a [ markup list](../Instance/Hypertext.mdx) usable as an input of [document(List)](../Instance/document(List).mdx)
