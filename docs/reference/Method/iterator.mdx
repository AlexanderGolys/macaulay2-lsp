# iterator

**iterator  -- get an iterator**

**Type:** [MethodFunctionSingle](../Type/MethodFunctionSingle.mdx)

## Description

An iterator is an object that is used to traverse through `x`. Usually but not necessarily this will be an instance of the [Iterator](../Type/Iterator.mdx) class.The class of an iterator should have a [next](../Method/op_Coredollar_next.mdx) method installed that gets the next element of `x`.If `x` contains only a finite number of elements then [next](../Method/op_Coredollar_next.mdx) should return the symbol [StopIteration](../Method/op_Coredollar_StopIteration.mdx) after exhausting them all.Instances of classes with this method installed can be used like lists in [for](../Method/op_Coredollar_for.mdx) loops and [scan](../Function/op_Coredollar_scan.mdx).They can also be passed to [apply](../Function/op_Coredollar_apply.mdx) and [select](../Method/select.mdx).  In each case an [Iterator](../Type/Iterator.mdx) object will be returned that is an iterator for itself.
