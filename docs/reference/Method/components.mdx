# components

**components  -- list the components of a direct sum**

**Type:** [MethodFunction](../Type/MethodFunction.mdx)

## Description

`components x`  -- produces a list of the components of an element of a free module.`components M`  -- the list of components for a module `M`  which was formed as a direct sum or `{M}`  if `M`  was not formed as a direct sum. Works also for matrices chain complexes etc.
